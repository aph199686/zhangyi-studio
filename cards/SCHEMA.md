# 观点卡片 Schema（cards/SCHEMA.md）

观点卡片是张翼知识库的最小单位。一张卡片 = 一个被提炼过的**判断**，不是一段摘抄。

## 字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | 是 | `card-<主题缩写>-<序号>`，如 `card-gd-001` |
| `claim` | string | 是 | 论点。**必须用自己的话复述**，是一句可以指导行动的判断，不是内容摘要 |
| `scenarios` | string[] | 是 | 适用场景标签（受控词表见下），检索与按需加载的依据 |
| `note` | string | 是 | 批注：适用范围、反对意见、反例、与其他卡片的张力。写"我怎么看这个论点" |
| `crossref` | string | 否 | 互引行（2026-09-30 B4 裁定新增）：以「另一卡号｜」开头写清两卡分工与并读方式，用于同源两切面、同词不同物等候选重复卡；渲染在论点之后，不进长行防呆扫描。 |
| `source.title` | string | 是 | 原文标题 |
| `source.url` | string | 是 | 原文链接；无法公开的来源按脱敏纪律使用占位值（`（内部资料·脱敏）` 或 `（本地全文库）银河系洞察基地内容合集`），占位值不算违规 |
| `source.platform` | string | 是 | 来源平台（机核 / 微信公众号·银河系洞察基地 / …） |
| `source.date` | string | 否 | 原文发布日期（YYYY-MM-DD；只有年份或年月时可写 YYYY 或 YYYY-MM） |
| `added` | string | 是 | 卡片入库日期（YYYY-MM-DD） |

## scenarios 受控词表（v0.1）

阶段维度：`立项` / `机制` / `叙事` / `验证` / `收尾`
主题维度：`核心循环` / `难度曲线` / `信息设计` / `经济系统` / `叙事结构` / `角色塑造` / `玩家动机` / `体验节奏` / `用户研究` / `市场定位` / `团队协作`

每张卡片至少 1 个阶段标签 + 1 个主题标签。

## 版权红线（硬性）

1. **卡片不含原文段落。** `claim` 必须是提炼后的复述。
2. 直接引用原文**不得超过一句**（≤50 字），且必须加引号。
3. 原文永远不进本仓库。原文在贡献者本地，卡片只给出处链接。
4. `tools/validate.py` 会扫描卡片文件中的超长连续文本块，作为防呆。

## 文件组织

- 卡片按主题分文件存放：`cards/<主题>.md`；单文件张数不设上限（现库单册最多 94 张），但每册应保持单一主题与清晰的卡号段。
- 单张卡片的 Markdown 格式：

```markdown
## card-gd-001 · <claim 的一句话标题>

- **论点**：……
- **互引**：<另一卡号｜分工与并读方式>（可选行，缺省不写）
- **场景**：立项 / 核心循环
- **批注**：……
- **出处**：[《原文标题》](https://…) · 机核 · 2023-05-12
- **入库**：2026-09-23
```

- `cards/index.json` 是全量索引（字段同上 schema），由入库流程维护。

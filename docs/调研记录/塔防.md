# 调研记录：塔防（品类包）

- **检索日期**：2026-09-29
- **包标识**：`genre.towerdefense`（`shortTitle` 塔防）
- **轴**：品类。与战棋包划界：战棋管回合制单位走位（决策主体是单位），塔防管实时波次中的建造取舍（决策主体是阵地与经济）；共用 gd-061 的信息可算清标准，但验收口径不同（战棋=行动前算得出结果，塔防=建造前算得出这波守不守得住、漏了能归因）。

## 六个关键问题

1. 玩家要什么？——控制兵线的情绪曲线：敌离终点远了无聊、近了紧张；其上叠空间智力、对策克制、经济雪球。
2. 第一局该发生什么？——平衡基准单位是"一波怪"：第一关=一条路+一种塔+稀疏波次，让玩家亲眼验证"放一座塔能不能消化一波"。
3. 流派分叉？——路径（固定解谜/开放造路）、塔深（少而深/多而克制）、阻截层（纯塔/可动单位/减速软阻截）、经济（紧凑/宽松）；变体反向塔防。
4. 新手死法？——数值崩坏（零容忍品类）、难度尖刺、全能塔/唯一最优解、后期垃圾时间、塔种堆砌无定位。
5. 怎么算对？——漏怪原因可口述、同一预算换布局成绩差一档、波次松紧交替有建设喘息。
6. 第一版暂缓什么？——无尽模式、科技树局外养成、塔种图鉴、多地图、英雄与多路出怪。

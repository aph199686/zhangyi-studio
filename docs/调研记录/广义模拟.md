# 调研记录：广义模拟（genre.simulation）

- 检索日期：2026-09-28
- 检索执行者：AI 陪练（非人工试玩），检索手段为公开网页抓取 + 卡片库蒸馏
- 本包用途：**张翼通用品类包**（与任何具体项目无关）；「广义模拟」= 扮演具体职业/系统角色、按现实流程作业的模拟器（洗车模拟器、小偷模拟器、翻修、维修、运输等）
- 结论一句话：广义模拟的最小闭环是「**接单 → 按现实流程作业 → 验收 → 结算并解锁更好的工具**」，成败全押在**把现实流程砍到只剩爽点**：删掉繁琐、把反馈拉满、让完成度永远可见。这是最容易做成「真实但无聊」的品类，也是最容易靠「主题即动作」零成本教会玩家的品类。

---

## 0. 划界（这个包吃什么、不吃什么）

**属于本包**：
- 玩家扮演一个**具体职业/系统角色**（清洁工、翻修工、机修师、司机、小偷、太空清洁工），以**作业单（job）**为最小单位。
- 作业按**现实流程**组织：接单 → 执行若干步骤 → 验收 → 结算/解锁。
- 核心乐趣来自**流程熟练化 + 工具与进度的可视成长 + 低压力执行**，而不是对抗、构筑或叙事。

**明确排除（避免与相邻包重叠）**：
- **经营/种田/餐厅** → 已有 `genre.management`。判据：那类产品的核心是**双系统联动与资源经营**（买卖/种植与另一套玩法互为门槛，B2 的"店铺模拟"分析），本包核心是**单次作业的执行手感与流程熟练**，不做双系统互为门槛。
- **人生模拟/生活模拟**（如 inZOI、模拟人生）→ 是仓库里**另一个候选包方向**（见内容包清单「模拟人生/生活模拟」），本包不考虑。
- **硬核专业模拟**（航电级飞行模拟、手术级医学模拟的拟真侧）→ 更接近「专业训练模拟」，不属「按流程作业」。
- **纯沙盒建造**（无作业流程，只有自由搭建）→ 不属本包；沙盒只能作为作业之后的附加模式（A5 明确：沙盒是二代才敢做的东西）。
- 运输驾驶类只吃 **「运输作业」子集**（接单—送达—结算，如 ETS2），不吃竞速/物理驾驶模拟。

**边界声明（用于包数据 `boundary` 字段）**：
> 依据公开检索与卡片库蒸馏（2026-09-28），未运行、未试玩、未平衡、未做真实玩家测试。扮演具体职业/系统角色、按现实流程作业的模拟器归本包；经营/种田/餐厅归经营包，人生模拟（模拟人生类）归候选生活模拟包，不做硬核专业训练模拟与竞速驾驶。

## 1. 六个关键问题（含划界问题）

1. **玩家要什么**：扮演职业/系统角色的玩家真正追求什么？什么会让老玩家立刻反感？
2. **第一小时**：开局第一单必须多短？第一小时必须给出哪种「熟练上手」的感觉？
3. **流派分叉**：原型期通常会裂成哪 3–4 条路线？各自首局目标是什么？
4. **新手真实死法**：新人做这类游戏最常见的失败方式（可被外部观察的那种）？
5. **验收判据**：什么能证明「首局骨架对」？可被外部观察、不靠「我觉得好玩」。
6. **暂缓范围**：第一个原型**明确不做**什么？
7. **划界**：与 `genre.management`、人生模拟包如何切分？（见 §0）

## 5. 按六问蒸馏的判断

### Q1 玩家要什么

**要**（四条，均有独立来源）：
1. **「主题即动作」的直觉爽点 + 近乎连续的正反馈**——玩家看标题就知道要干什么，动作本身就是奖励。
   - 依据：A2（「theme is also its primary action」；清洗 input-intensive、反馈近连续）；A1（把清洁过程做成「理想化的、几乎梦一样的版本」，凡挡路的都砍掉，连水电管理都删）。
2. **低压 / 无失败条件的空间**——「今天很糟，洗点东西会好受些」。
   - 依据：A3（无时限、无失败条件，从第一天就是设计前提）；A4（Marsden：「soothe the soul」）；C4（「when life just gets too much」）；C5（「zen-like experience」）。
   - **交叉验证**：A3/A4（开发者自述）× C4/C5（玩家/社区原话）→ 两方独立，进默认建议（但标注为"单作品样本，非品类通则"，见 §7）。
3. **看得见的工具与进度成长**——钱不是数字，是「下一把更强的工具」。
   - 依据：A1（多层污垢逼你升级装备）；A6（军衔 + 升级解锁更快拆装；里程碑可见）；A5（技能树分档、可随时开关）。
4. **秩序感 / 熟练带来的掌控感**——从混乱到整洁、从陌生到熟练。
   - 依据：C4（「create order from chaos」）；A6（「你总能看见下一个里程碑就在前方」）；A1（同一最终状态，没有唯一正确方法 → 玩家有自己的方式）。

**不要（会立刻反感）**：
1. **找不到「最后一块」而卡在 99%**——最高频痛点。
   - 依据：C1（「that 1% left to clean will just not 'ping'」）；C2（「NOTHING there to be cleaned」）；A1（承认 element 命名就是为了最后一块脏）。
2. **物理/操作摩擦导致已清区域返工**。
   - 依据：C2（Gravity Drive Buckets）；百科背景（VCD：掉脏物/踩到血会二次扩散）。
3. **拟真过度变繁琐**。
   - 依据：A6（几千颗螺丝 → 只留几百颗）；A1（清洁 8/10、被清洁物 4/10）；A5（动作太长会变无聊）。
4. **音效/动作重复到刺耳**。
   - 依据：A5（吸尘器音不能「drill your head」）。**仅 1 条来源 → 标低证据。**
5. **内容枯竭、作业重复无新意**。
   - 依据：C1（「Some games die from lack of content…」）；A1（清洗过程本身统一，**变化必须来自被清洗的东西**）；A3（车辆关趋同，二代减少车辆）。**

### Q2 第一小时

**必须做到**：
1. **第一单是一个「封闭小场景」且四步全通**：接单 → 执行 → 验收 → 结算/解锁。这是本包唯一不可省的骨架。
   - 依据：A1、A2、A5、A6 四处的作业结构一致；A2（把物件切成有意义的 section）；A6（拆壳 → 找坏件 → 换件 → 交付）。
   - **交叉验证**：4 条独立来源 → 进默认建议。
2. **第一分钟就必须用真实工具做真实动作**，不要为「展示成长」先把玩家削残。
   - 依据：A2（主题即动作）；A3（无时限无失败条件）；A7（Job Simulator 直接抓取，去了抽象）。
3. **秒级回执 + 单局回执 + 中期回执三层都要在首小时内出现**：一个 section 完成的白闪/音效（秒级）→ 一张作业单结清（单局）→ 第一件工具升级（中期）。
   - 依据：A1/A2（白闪 + Ding）；A6（升级解锁更快拆装）；卡片 `card-gd-003` 的三层赏罚框架与之同构。
4. **首单时长：5–10 分钟量级**。
   - 依据：反推自 A1（关卡「authentic but feasible」、比现实快「好几个数量级」）+ C1（玩家把「一张 40 分钟的图」读作过长而抱怨）。
   - **只有间接证据 → 标「低证据，仅作起点参考」。**
5. **第一小时给的是「工具够用 + 反馈立刻 + 我知道自己在变强」的熟练感**，不是「我学会了复杂系统」。
   - 依据：A6（目标近在咫尺则没人中途放下）；A7（去抽象化、反复试玩清掉卡点）。

### Q3 流派分叉（3–4 条路线 + 2 条变体）

原型期通常会裂成这四条，**每条的首局目标不同**：

| 路线 | 首局目标 | 代表 | 出处 |
|---|---|---|---|
| **清洗清洁类** | 把一个**脏/净对比极强**的封闭小场景洗到 100%，拿到第一次装备升级 | PowerWash Simulator、Viscera Cleanup Detail | A1、A2、A3、C1、C2 |
| **翻修整理类** | 一个房间/一间小屋：清垃圾 → 刷墙/铺地 → 装家具 → 卖给 NPC 收钱 | House Flipper 1/2 | A5、B1、C4、百科背景 |
| **维修拆装类** | 一台设备：拆开 → 诊断故障件 → 换件 → 试机 → 交付 | Rover Mechanic Simulator、Car Mechanic Simulator | A6、百科背景 |
| **运输驾驶类** | 一趟短途接单：取货 → 按路线送达 → 结算 + 升技能点 | Euro Truck Simulator 2 | C5、百科背景 |

**两条变体（同属本包）**：
- **潜入偷盗类**：一栋小房子：踩点 → 潜入 → 取物 → 撤离销账（Thief Simulator）。依据：百科背景（上线周末登顶 Steam 畅销榜）+ C3（该作玩家日常被 bug 占据，说明这条路线对**系统稳定性**的要求远高于其他路线）。**首单只做一栋房子，并加稳定性红线。**
- **VR 手部作业类**：一个小工位的班次流程，全部靠手部抓取/投掷/使用完成（Job Simulator）。依据：A7。其「去抽象化」原则对非 VR 作品同样成立，原则收进包内。

**交叉验证**：五条路线各有 ≥2 条独立来源（清洗：A1/A2/A3 + C1/C2；翻修：A5 + B1 + C4；维修：A6 + 百科；运输：C5 + 百科；潜入：百科 + C3）。

### Q4 新手真实死法（按「死在哪个环节」排序，均可外部观察）

1. **做成「真实但无聊」的仿真**：把现实里的微观操作照搬。
   - 依据：A6（「真车有几千颗螺丝，我们只留几百颗」——这就是解药本身）；A1（清洁 8/10 vs 被清洁物 4/10 的取舍）；B1（一整篇实证：擦洗「slow and fairly dull」，最后还要找门框上看不清的痕）。
2. **作业重复度饿死后劲**：清洗/翻修动作本身是统一的，**变化只能来自作业对象**，而对象做不了那么快。
   - 依据：A1（「因为清洗过程本身相当统一，变化必须由被清洗的东西提供」）；C1（玩家原话点名内容枯竭）；A3（承认车辆关趋同）。
3. **「最后一块脏」找不到**：收尾阶段变成像素猎杀。
   - 依据：C1（99% 卡死帖）；C2（机器响但没东西可清）；A1（命名 element 的补救动作正说明问题真实存在）。
4. **完成规则不透明 / 无教程**：玩家不知道评分怎么算、为什么被降级。
   - 依据：C2（「Demoted?」+「No Tutorial or Instructions?」两条并列）；A7（「失败几乎总在可读性上」）。
5. **物理/操作摩擦制造返工**：辛苦清好的区域被自己的操作弄脏。
   - 依据：C2（Gravity Drive Buckets，社区解法是关掉重力）；百科背景（VCD 机制）。
6. **音效/动作重复到刺耳**。
   - 依据：A5（唯一来源）。**低证据。**
7. **成功之后没有下一件可做的事** → 玩家关机。
   - 依据：A6（破产/资源框架给「必须往前看几个任务」的压力）；A5（技能树必须能持续升级）。
8. **工作室层面押错资源**：把宝押在多人/续作上，结果影响力下滑 + 组织承压。
   - 依据：A8（Bossa：续作影响力远不如前作、裁员、加班）。

### Q5 验收判据（可外部观察，不靠「我觉得好玩」）

**作业结构层（能在设计文档/灰盒上数出来）**：
- [ ] 首单闭环四步齐全：接单 → 执行 → 验收 → 结算/解锁。（A1/A2/A5/A6，4 处）
- [ ] 首单可在 **5–10 分钟**内完成。→ **低证据（间接），仅作起点参考。**
- [ ] 场景内每个「可操作单元」有名字，且名字带**地理线索**，玩家能用名字推出位置。（A1，唯一直接来源 → 标「单来源但为厂商实证」；C1/C2 的 99% 痛点反证其必要）
- [ ] 至少两级「脏/坏」难度类型，**第一级无法用初始工具高效处理**。（A1 多层污垢系统）
- [ ] 存在一条**可升级链**（工具/喷嘴/技能/军衔），且第一件升级在首单之后立刻可买。（A1/A5/A6，3 处）
- [ ] 有**完成度可视**的度量（进度条、剩余高亮、单元清单）。（A1、百科背景）
- [ ] 首单不含任何**载具/趋同形态**作业。（A3 明确说车辆类最难做变化）
- [ ] 启动即作业：**无教程条件下玩家能独立做完第一单**（反例即 C2「No Tutorial or Instructions?」）。

**体验层（试玩可观察行为，非感受）**：
- [ ] 玩家能**复述正确的作业顺序**（设计目标依据 A6 的里程碑可见性）。
- [ ] 每完成一个 section，玩家**立刻**得到视听回执（A1/A2 白闪 + Ding）——观察：玩家是否在完成瞬间出现「松一口气」的停顿。
- [ ] 第二单里玩家**主动换工具或换做法**（A1「没有唯一正确方法」；A6 升级解锁更快拆装）。
- [ ] 完成单局后玩家**自发开始下一单**（目标感观察法，钩 `card-ur-003`）。
- [ ] 收尾最后 10% 期间**没有出现超过约定时长的原地打转**（对照 C1/C2 反例）。

**反例红线（触发即判负）**：
- ✗ 首单内存在「看不见的脏/坏」且**没有任何定位辅助**。（C1/C2）
- ✗ 无教程则第一单做不完。（C2）
- ✗ 完成判定/评分规则对玩家不可见（玩家会问「我为什么被降级」）。（C2）
- ✗ 玩家操作会把已清区域弄脏且**无法预防**。（C2）
- ✗ 首发只有 1–2 个作业量。（C1）
- ✗ 首单还要求玩家阅读大段文字才能开始。（A5：避免「walls of text」）

### Q6 暂缓范围（第一个原型明确不做）

- ✗ **开放世界自由漫游**（A1：关卡是封闭 job；parkour 是玩家自发行为、甚至一度是被容忍的意外，不是设计目标）。
- ✗ **物理硬核拟真**（A6 明确简化；A1 的 8/10 vs 4/10 分制；A2 把水电管理全砍）。
- ✗ **多人/联机经济**（A3：合作被设计成「只能贡献、不能拖后腿」的安全空间；C2：VCD 多人 bug 是玩家常年抱怨源 → 首原型不做）。
- ✗ **几十种职业铺量**（A3：每个作业要「独特剪影」，变化成本极高；先做一条职业线）。
- ✗ **叙事主线/大地图剧情**（A3：故事是「几乎可选」的后台元素；A5 用环境叙事，避免文字墙）。
- ✗ **沙盒/关卡编辑器**（A5：HF2 的 Sandbox 是公司史上最大开发挑战，且是二代才敢做）。
- ✗ **载具类作业**（A3：元素扁平、最难做出差异，二代反而减少）。
- ✗ **深度经济/破产系统**（A6 的破产框架是服务长期动机的，首原型先不做）。
- ✗ **失败惩罚机制**（A3：无失败条件是刻意的设计选择；首原型不要引入「洗不够干净会被解雇」这类惩罚）。

## 7. 证据强度自评

**总评：充分（对「结构与死法」的判断）／有限（对「时长与数值」的判断）**

| 被判断的字段 | 强度 | 依据 |
|---|---|---|
| 品类划界（扮演职业 + 按流程作业） | 充分 | A2/A3/A6 三处「主题即主玩法 + 作业单结构」独立表述一致；B2 提供了与经营管理类的清晰对照面 |
| 「首单必须四步闭环」 | 充分 | A1 + A2 + A5 + A6 四处独立 |

| 「不要拟真过度」 | 充分 | A1（8/10 vs 4/10）+ A6（螺丝数量取舍）+ A5（动作时长风险），三处独立 |
| 「装备/技能升级链是动机主轴」 | 充分 | A1 + A5 + A6 三处独立 |
| 「低压无失败条件」 | **有限** | A3/A4 是开发者自述的**本作选择**，不是品类通则；C4/C5 是玩家侧佐证。两方独立但均属单作品样本 |

| 「音效重复不能刺耳」 | **低证据** | 仅 A5 一处开发者自述 |
| 「首单 5–10 分钟」具体数值 | **低证据** | 无直接来源，由 A1 的关卡时长哲学 + C1 玩家对 40 分钟单人图的抱怨反推 |
| 「潜入偷盗路线」 | 有限 | 百科（畅销登顶，三手）+ C3（稳定要求高，玩家日常）两处，但缺一手开发者设计复盘 |
| 失败案例成立（Bossa/Surgeon Simulator 2） | 有限 | A8 单条长文报道，含当事方访谈，但**无官方复盘文档** |

**低证据清单（不得作为默认推荐）**：
- 「首单 5–10 分钟」→ **低证据**，仅作起点参考。
- 「音效纪律（不能刺耳）」→ **低证据**，建议给成「可选优化项」。
- 「载具类不做」→ **有限**，可作为方向而不要写成硬禁止。
- 「无失败条件/低压」→ **有限（单作品样本）**，建议写成「首原型默认不开失败惩罚」而非「本包不应有惩罚」。

## 8. 没能回答的缺口

1. **「首单最优时长」没有权威数字。** 所有来源只给哲学（比现实快几个数量级、authentic but feasible）与玩家抱怨，没有可执行阈值。故本包**只给「5–10 分钟量级」这一低证据起点，不给硬线**。
2. **「作业重复多少算过量」没有量化。** 玩家反复抱怨内容量，但无人给出「第几小时开始厌」的阈值；A1/A3 只说「变化必须来自作业对象」。**保持为缺口。**
3. **失败/惩罚机制的设计原则近乎空白。** 唯一一处机制记录（VCD 低于 75% 被解雇）只来自百科三手，且该作本身争议不小。首原型的「要不要惩罚」目前**无来源支撑，本包默认不做**。
4. **中文一手来源几乎为零。** 检索受限（中文搜索引擎全部被验证码拦截），未找到可打开的中文开发者复盘或中文玩家抱怨原文。属**检索覆盖缺口，不等于不存在**。
5. **「多人合作」在本包里到底是加分还是陷阱**，只有 A3（作成功方：安全协作空间）与 C2（作玩家长期抱怨源）两条相反方向的少量证据，**无法定论**。
6. **潜入偷盗路线缺少开发者一手复盘**：畅销数据与玩家口碑都有，但没有像 PowerWash/Frozen District 那样的设计访谈，该路线的设计结论证据等级整体低于清洗/翻修/维修三条线。
7. **本包所有判断均来自公开检索与卡片库蒸馏，未经任何真实玩家试玩验证。** 任何「这局会好玩」的说法都超出证据范围。

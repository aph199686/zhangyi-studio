# 调研记录：增量挂机/放置（genre.idle 候选）

- 检索日期：2026-09-29
- 检索执行者：AI 陪练（非人工试玩）
- 本包用途：**张翼通用品类包**（与任何具体项目无关），来源均为公开检索 + 卡片库蒸馏
- 结论一句话：增量/放置的最小闭环是「**生产速率 vs 成本**的跷跷板 → 撞到等待墙 → **重置（prestige）换永久乘数** → 下一轮更快地爬同一根曲线」，成败押在**等待上限与重置时机的可读性**上，而不是美术量或系统数量；**轴归属裁决：独立品类包（genre.idle）成立，同时保留 `mgmt_pacing` 现状——离线生产作为「可移植的节奏属性」的说法只解释了离线，解释不了 prestige 时机、增量曲线与零玩家型首局。**

## 0. 划界（这个包吃什么、不吃什么）

**属于本包**：
- 核心承诺是「**你在不在，数字都在涨**」：主循环为产能/成本博弈 + 累积 + 自动化 + 重置。
- 具备**重置型长线结构**（prestige / ascension / 转生 / 换蛋）：主动清零换永久乘数或永久货币。
- 数值以指数/多项式增长为骨架，成本随持有量指数上涨（本条由 A1 给出可复算模型）。

**明确排除（避免与相邻包重叠）**：
- **模拟经营/建造**：核心是需求、人手、库存、交付与扩张 → 已有 `genre.management`。本包与它的交集是「管理型放置」（Idle Miner Tycoon / AdVenture Capitalist 一类），**同一项目不同时打两个包**。
- **放置只是省时功能的非放置游戏**（例如带 AFK 模式的 MMO、带离线收益的 SLG）：离线生产是**可移植属性**，不构成品类。判据见 §5-Q7。
- **肉鸽/DBG 构筑**：局内随机构筑 + 永久成长属 `genre.rogue`；本包的永久成长来自**重置换乘数**，不是构筑。
- **赌博/抽卡经济**：本包首原型不含付费点与概率变现。
- **纯叙事/氛围作品**：若「放置」只是载体、核心是叙事，归叙事包。

**边界声明（用于包数据 `boundary` 字段）**：
> 依据公开检索与卡片库蒸馏（2026-09-29），未运行、未试玩、未平衡、未做真实玩家测试。属「产能成本跷跷板＋自动化发放＋重置型长线」的独立品类；离线生产作为可移植节奏属性仍由经营包 `mgmt_pacing` 承担；与经营包重叠区（管理型放置）同一项目不同时打两包。

## 1. 六个关键问题（先写在检索之前）

1. **玩家要什么**：这个品类里玩家真正追求什么体验？什么会让老玩家立刻反感？
2. **第一小时**：开局第一小时必须让玩家感受到什么、拿到什么，才算「入门了这个品类」？「放置≠无事可做」的第一小时怎么做？
3. **流派分叉**：原型期通常裂成哪 3–4 条路线？各自的首局目标是什么？
4. **新手真实死法**：新人做这个品类，最常见、且可外部观察的失败方式是什么？
5. **验收判据**：什么能证明「这个首局骨架是对的」？可被外部观察、不靠「我觉得好玩」。
6. **暂缓范围**：第一个原型**明确不做**什么？
7. **轴归属裁决**：独立品类包，还是并入 `genre.management` 的节奏题？

## 5. 按六问蒸馏的判断

### Q1 玩家要什么

**要**：
1. **踩油门看数字涨**的即时爽，以及「**自动化 = 复利**」那一击——从手动到自动的那一刻最有价值。（A3；B2「每一步都感觉自己在飞」）
2. **等待期里真有得选**：买哪个生成器、买倍率还是存钱、何时重置。（A1 倍率门槛制造取舍；A4 存/花二选一；C2 玩家写月球最优购买数学）
3. **prestige 滚雪球**：主动清零换永久乘数，下一轮把同一根曲线爬得更快。（A2；B2 ascension；B3 天使投资人）

**不要（会立刻反感）**：
1. **等待上限失控**：成本曲线把产出甩开，等待「prohibitively long」。（A1；C3「repetitive and boring over time」）
2. **纯挂机、无事可做、没有张力**。（A4「没有任何东西能反击」；C7 无人可做的抱怨）
3. **prestige 清零挫败 + 时机不可读**：不知道何时该重置，或规则一分钟读不懂。（C2 重置指南；A2 四作翻倍目标 4×→128× 量级差 32 倍）
4. **大数字新鲜感耗尽 / 内容枯竭**。（A2「大数字本身的新鲜感已经基本用尽」；C3 长线单调）
5. **换皮同质**。（C6 定性；定量作废）

### Q2 第一小时

**必须做到**：
1. **十几分钟内第一台自动生成器**——把手动点击换成自动产出，是第一口糖。（A3；B8 零玩家谱系「开局需干预、之后才可放手」）
2. **一小时内至少一次「明显提速」**。（A3 Candy Box 1 根/分钟→100 根/秒；A2 单轮要有快慢段）
3. **给出可见的下一个里程碑**，让「贵得不可能」持续变成「够得着」。（A3；B2 为里程碑制造预期）
4. **每次等待里留一个决策**；自动化按顺序当奖励发放。（A4；A1；C2）
5. **别依赖点击**：若第一小时必须狂点，说明核心循环没设计好。（B1 转引 Pecorella 2016 → **单条，标低证据**）

**交叉验证**：「第一小时给自动产出 + 一次明显提速」由 A3 与 A2 两路独立 → 进默认建议。「等待期必须有决策」由 A1 + A4 两路 → 进默认建议。「auto-clicker 是设计缺陷」仅 B1 一处 → **低证据**。

### Q3 流派分叉（4 条路线）

| 路线 | 首局目标 | 代表 | 出处 |
|---|---|---|---|
| **经典点击器** | 把「点一下得 1」换成「不点也在涨」；以第一次自动化与第一个里程碑收束 | Cookie Clicker | A1、A3、B2、B8 |
| **增量成长 / 分层 prestige** | 冲到**第一次 reset**，并把下一轮做得明显更快 | Antimatter Dimensions、Universal Paperclips | A2、B6 |
| **放置 RPG / 技能养成** | 用**离线时间**同时推多条技能/战斗线，第一次「离线回来有明确收获」 | Melvor Idle、Clicker Heroes、NGU Idle | B4、B5、C4、C5 |
| **零玩家 / 陪伴型** | 回来后**读一段「我不在时发生的故事」**；玩家目标是旁观与轻度干预 | Godville、Progress Quest | B7、B8、C7 |

交叉验证：经典/增量分野按 prestige 货币基准（A2 终身累计 vs 单轮独立两族）；放置 RPG 存在（B4 Hero Souls、B5 永久史诗研究、C4/C5 Melvor）；零玩家独立分支（B8 定义 + B7/C7 玩家原话）。四分支均有独立来源。

**首原型三选一**：经典点击器 / 增量成长 / 放置 RPG；零玩家型作备注不进首局默认。

### Q4 新手真实死法

1. **首小时无爆点 / 等待上限失控**：产出追不上成本，等待从「3 秒」滑向「30 分钟」。（A1；A2）
2. **prestige 时机不可读 / 倍率曲线量级失衡**：翻倍目标 4×→128×，玩家只能查攻略。（A2；C2）
3. **把「放置」做成「无事可做」**：没有张力、没有对抗、没有决策。（A4；C7）
4. **靠点击却没料理 auto-clicker**：承认循环没成立。（B1，**低证据**）
5. **离线收益失衡**：离线太强在线无意义；被硬砍则回来没收获。（A2 Egg, Inc. 2 小时上限 vs Clicker Heroes 无上限）
6. **换皮同质**：同数值骨架、同题材扎堆。（C6，定性、低证据）

### Q5 验收判据（可外部观察）

**数值骨架层（可在表格/脚本上算出来）**：
- [ ] 单台生成器 `成本 = 基价 × 增长率^持有数` 与 `产出 = 基产 × 持有数 × 倍率` 成表（A1；AdCap 增长率 1.07）。
- [ ] 「最新生成器一旦可买就近乎统治」已被错位倍率门槛处理（A1）。
- [ ] 单轮内存在快段与慢段，重置之间也有变奏（A2）。
- [ ] 每个爆点可预先列出：生成器首购点、倍率门槛达成点、第一次 reset 点（A1 + A2 的 bumpy 要求）。

**首局体验层（可脚本模拟 / 可观察）**：
- [ ] **用脚本跑前 60 分钟**，输出爆点间隔与最大等待时长，且最大等待不超过约定上限（A1 模型可直接模拟；**具体秒数无来源，按探针纪律自定义验收口径**）。
- [ ] **第一次 prestige 发生在可承诺的时间点**，规则玩家 1 分钟读懂（反例基准：C2 玩家靠指南）。
- [ ] **离线收益 : 在线收益**有明确比值或硬上限，且是设计选择而非事故（先例：A2 的 Egg, Inc. 2 小时）。
- [ ] 每个等待段至少一个可做决策（A4）。
- [ ] 存在张力来源（boss 计时、primal 概率、限时事件、大里程碑）而非纯挂机（A4、B4）。
- [ ] 自动化按顺序作为奖励发放，不是开局全自动（A3）。
- [ ] 大数字可读（科学计数/后缀命名；无需另写指南）（反例：C2 的 Large Number Names）。

**反例红线（触发即判负）**：前 60 分钟无任何明显提速；存在超上限且无决策的等待段；prestige 收益规则玩家 1 分钟读不懂；后期越依赖离线、在线无意义，或回归无可感知收获。（依据 A1/A2/A3/A4/C2/B4/C3）

### Q6 暂缓范围（第一个原型明确不做）

- ✗ **不做多人/排行榜经济**（成就感来自单体数字曲线；社交竞技另属一个量级）。
- ✗ **不做几十个系统铺量**（A2：先确定乐子在哪，别靠系统多撑）。
- ✗ **不做复杂战斗**（B4/B5：战斗是后置深水区）。
- ✗ **不做成就大礼包/网格打卡铺量**（过量重复会厌，见 §6 `card-ns-039`）。
- ✗ **不把离线收益做成主玩法**（A2 的 Egg, Inc. 反证：靠硬限离线推主动玩）。
- ✗ **不做付费点与回归激励**（运营期，进 defer）。
- ✗ **不做多套 prestige 货币/多层好感系统**（先证一层重置闭环）。

### Q7 轴归属裁决

**裁决：独立品类包（`genre.idle`）成立；同时保留 `genre.management` 的 `mgmt_pacing` 题不动。**

**支持独立（判据 + 来源）**：
1. **首局存在独立于经营循环的可验证目标——第一次 prestige 的时机**：多家来源给出可计算的重置目标（Realm Grinder 4×、AdCap 3–4×、Cookie Clicker ≈8×、Egg, Inc. ≈128×），属于**重置系统的数学**，不属于「排产—交付」的经营闭环（A2；B2 ascension；B3 天使投资人）。
2. **存在自成一体、非经营子集的决策面**：生成器组合与购买顺序、倍率门槛临界点、存钱 vs 花钱、离线/online 收益上限、重置时机（A1；A2；A4；C2 玩家自发写最优购买数学）。
3. **第一小时形态不同**：放置是「踩油门 → 自动化 → 第一次提速 → 第一道等待墙 → 第一次 reset」；经营包是「看见需求 → 排产 → 交付 → 收益扩张」（对照 `mgmt_pacing`/`mgmt_goal` 题面）。
4. **失败模式不同**：放置核心风险是「无事可做/等待上限/曲线与重置失衡」；经营包的失败模式是「任务断档、惩罚过重」，两者不重合（A1/A2/A4/C2/C3 vs 现有 management 包 why）。
5. **流派分叉独立**：点击器 / 增量成长 / 放置 RPG / 零玩家，首局目标各不相同（Q3）。

**维持现状的反证**：离线生产是可移植节奏属性（B1 记录它被 Hay Day、Mafia Wars、Game of War 等借用），`mgmt_pacing` 把它当开关**有依据**；若项目核心是「可离线运转的厂子」会同时命中两包。

**裁决理由**：反证只说明「离线」可被借走，**解释不了 prestige 时机、增量曲线与零玩家型首局**；第 1–5 条判据显示放置具备独立首局骨架。故取独立。**交叉处置**：两包重叠区（管理型放置）沿用既有边界规则——**同一项目不同时打两包**；`mgmt_pacing` 题不删、不改默认值，仅在 `why` 中补一句指向 `genre.idle` 的边界。

## 8. 没能回答的缺口

1. **「最优等待上限」与「爆点间隔」没有权威数字**：来源只说等待会变「prohibitively long」、单轮要有快慢起伏（A1/A2），无人给出「单次等待不超过 X 秒」「每 Y 分钟一个爆点」的可执行阈值。本包**只给方法（脚本模拟出间隔与上限）与红线形态，不给数字**。
2. **「离线收益应占多大比重」无标准**：只有 Egg, Inc. 2 小时（A2）一个先例与 Clicker Heroes 无上限一个反向选择，够不上规则。
3. **第一次 reset 应在「第几个节点」触发，无来源**：只知各作翻倍目标差异极大（4×→128×）。
4. **「管理型放置」与纯经营包的首局分界只有定性判断**，缺一手对照案例 → 影响 Q7 交叉处置的强度。
5. **失败案例偏「口碑走弱」而非「明确崩坏」**：缺少一个被公开弃坑/差评清零的放置作品的一手页面（Clicker Heroes 2 的「Mixed / 2823 条」只在搜索摘要看到，未打开按铁律不计）。
6. **本包所有判断均来自公开检索与卡片库蒸馏，未经任何真实玩家试玩验证。**

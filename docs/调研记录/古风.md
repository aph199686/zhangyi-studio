## 零、开工前先立六个关键问题

风格包与品类包不同：它**只改呈现、文本与反馈，不定胜负与回合规则**。所以六个问题要按表现层改写：

1. **玩家要什么**：玩家在古风产品里真正买单的是哪一层——考据、美感、氛围，还是"被看见在玩也不尴尬"的体面感？
2. **第一小时看到什么**：外国/新玩家进门的第一屏，哪些文化符号必须立刻出现，哪些可以慢热？
3. **流派分叉（3–4 条）**：写实考据、唯美写意、水墨留白、国潮混搭——各自对表现层的要求差在哪？
4. **新手真实死法**：风格做砸时玩家真实在抱怨什么（土、廉价、串味、出戏、认不出）？
5. **验收判据**：怎么证明"风格传达成功"而不是"我觉得传达到了"？
6. **暂缓范围**：首版不该投的表现层军备竞赛是什么？

## 四、逐题蒸馏结论

### Q1 玩家要什么

风格是**辨识度资产，不是精致度竞赛**（A3/D3）。玩家在古风产品里买单的顺序是：先认出"这是什么文化调性"（联想层）→ 再感受到体面感（"被人看见在玩也不尴尬"，A2 里最易漏测的维度）→ 最后才是考据深度。考据在大盘里是**中等加分项**而非门槛项（A2 注）。结论：首版把预算压在**辨识度与记忆点**上。

### Q2 第一小时看到什么

**硬菜提前上**（P1，双源印证 A2 的"故事性"维度）：新玩家对异域新鲜感的兴趣在第一小时处于峰值，那是兑现文化卖点的窗口，不是铺垫世界观的窗口。首版界面就该打出最独特的文化符号；文化底蕴慢热对新玩家是死刑。

### Q3 流派分叉

- **写实考据**：符号密度高、可信度优先；风险是门槛与成本双高。
- **唯美写意**：意境优先、留白多；风险是辨识度不足（"潮而不国"病灶，A2）。
- **水墨留白**：辨识度最强、成本相对可控；江南百景图证明**独卖日常烟火**也能立业（D3）。
- **国潮混搭**：现代载体＋传统元素；最容易"国而不潮"或"潮而不国"（A2），必须过联想测试（A1）与维度评分（A2）。

### Q4 新手真实死法（反面证据）

1. **串味**：混入他国元素稀释国风感，被读成日式二次元等（A2 反向对照维度）。
2. **土与廉价**：低俗／廉价联想单独拖死"自豪感"（A2）。
3. **死元素**：元素堆砌但唤不起联想，等于没做（A1）。
4. **出戏**：角色与世界调性冲突（A4）；随机名连词硬拼当场沦为社区笑料（P2）。
5. **硬菜上晚了**：精华在后期的产品，海外玩家撑不到（P1/P4）。

### Q5 验收判据

两条独立方法，互相交叉验证：
- **自由联想测试**（A1）：把成品画面给代表性用户看，收第一反应关键词，检查联想是否稳定指向预期调性。**联想测试必须在目标市场分别做**（同一元素在不同人群联想不同）。
- **维度化评分**（A2）：把调性拆成可独立打分的感知维度（国风感、潮流感、异国风格联想、自豪感、故事性），逐维打分、象限归因，病灶不同、处方不同。
- 二者关系：**自由联想是发散对照，维度评分是收敛验收**（A1 注）。另有"拿掉这个文化元素后体验是否塌了一块"作为文化传达的质检验收（D2）。

### Q6 暂缓范围

精致度军备竞赛（A3/D3）、全体系考据还原（A2 中"考究是加分非门槛"）、把文化当解说硬塞（D2 反例）、生僻字堆砌装逼格（P2）。

## 五、契约验证结论（风格包首次施工的关键判断）

开工前逐条核对风格契约 `presentation.visual / text / feedback` 三槽是否装得下上述结论：

| 结论 | 归属槽位 | 结论 |
| --- | --- | --- |
| 辨识度优先、首屏硬菜、流派分叉、死元素、串味 | `visual` | ✅ 装得下 |
| 随机名池管线、系统一句话包装、文化说明的取舍 | `text` | ✅ 装得下 |
| 操作反馈要"带文化味"、状态变化的文化表达 | `feedback` | ✅ 装得下 |
| **联想测试、维度化评分、拿掉元素是否塌方** | 无 | ❌ **三槽装不下——这是"怎么验收风格"，不是"风格长什么样"** |

**判断：三槽作为"表现指导"够用，但风格包还需要一个验收维度。** 契约第 16 行只定义了 `presentation`，未给风格包任何验收位。强行把验收方法塞进 `visual` 的文本里会让"表现指导"和"验证动作"混为一谈，违反契约第 21 行"推荐理由由调用规则生成"的分工精神，也与引擎包已经分设 `capabilities` ＋ `verification` 的既有设计不一致。

**因此本包先改契约**：为风格包增加 `verification`（呈现核验动作），与引擎包同构。这是"契约不够用时先改契约，而不是硬塞"（本次任务纪律）的直接应用。

## 七、尚未回答的缺口

1. **feedback 层缺一手对照**：没有"同一玩法、两种文化化反馈"的 A/B 证据，`feedback` 槽的结论多为外推，已如实标低证据。
2. **海外受众的联想分布**：A1 指出同一元素在不同人群联想不同，但缺分组量化数据，只能给出"必须分市场测"的方法而非结论。
3. **写实考据流的成本曲线**：只知"成本高"，无公开的成本结构数据。
4. **国潮混搭在游戏（非海报/服饰）上的成功因子**：A3 明确指出载体迁移成本，游戏画面上的可复制因子仍待实测。
5. **付费皮肤与风格预算的关系**：玩家侧对"古风皮肤该多贵"的预期无检索到可靠数据。

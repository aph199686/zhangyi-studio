# 调研记录：赛博朋克（style.cyberpunk）

- 检索日期：2026-09-28
- 检索执行者：AI 陪练（WorkBuddy 会话），非人工试玩
- 本包用途：**张翼通用风格包**（与任何具体项目无关），来源均为公开检索 + 卡片库蒸馏
- 结论一句话：赛博朋克的字面配方（霓虹、雨夜、义体、巨型企业）已经被用烂到**构成品类惯性的程度**，所以「做得很赛博朋克」不是加分项，而是**入门门槛**；真正决定成败的是**「高生活 vs 低生活」的反差有没有被具体地做出来**——本包因此把验收全部押在「反差是否可被外部观察」上，而不是「霓虹够不够多」。本包**画面层证据充分、文本层（语言/黑话）证据有限但可操作、反馈层证据单薄**，反馈层如实标低证据、不得用常识填充。

## 0. 划界（这个包吃什么、不吃什么）

**属于本包**：
- 题材落在「近未来地球、义体与网络、巨型企业下的社会分层」这一脉。
- 核心不是「有没有高科技」，而是 CDPR 美术总监引述其游戏总监的那句准则：**「一个塞满看起来很未来之物的环境不是赛博朋克，那只是科幻。」** 判据是**未来技术与日常生活的并置**（旧木门上装着 LED 门禁、老式餐馆用现代点单设备）。
- 覆盖三个近邻形态：**经典霓虹都市（Blade Runner 系）**、**企业压迫 / 反乌托邦（近未来写实向）**、**日光赛博 / 非典型配色（反刻板印象向）**——同一风格包内共存，差异在配色与时间感。

**明确排除（避免与相邻风格包重叠）**：
- **西幻** → `style.western-fantasy`。西幻是自然主义与材质可信度，赛博朋克是人工化与高对比霓虹，两者是对立的呈现语法。
- **古风** → `style.guofeng`。文化联想链条指向东亚传统，而非「未来东亚符号」——注意：赛博朋克里的和风/汉字招牌是**他者化的未来符号**，不等于古风。
- **日式幻想／二次元** → `style.anime`。二次元是程式化与记忆点夸张；赛博朋克若用二次元画法，呈现语法以二次元为准。
- **蒸汽朋克 / 柴油朋克**：不在本包。判据是技术底座——数字/网络/义体归本包，蒸汽/黄铜/维多利亚归朋克旁支（清单里另列）。
- **纯科幻（太空歌剧、外星、乌托邦）**：不属本包。本包要求「近未来地球 + 社会分层 + 低生活视角」。

**边界声明（用于包数据 `boundary` 字段）**：
> 离线设计预设；依据公开检索与卡片库蒸馏（2026-09-28），未运行、未平衡、未试玩。只改呈现、文本与反馈，不定义胜负与回合规则。

## 1. 六个关键问题（先写在检索之前）

1. **玩家要什么**：玩家选这个风格时真正在买的是什么？什么会让他们一眼判定「又一个霓虹雨夜 GTA」并划走？
2. **第一小时**：开场第一小时，画面/文本/反馈各要让玩家感受到什么，才算「这是一部赛博朋克」而不是「这是一部有霓虹的科幻」？
3. **流派分叉**：这类风格在做呈现时，通常裂成哪 3–4 条视觉路线？各自第一屏的取舍是什么？
4. **新手真实死法**：新人用这个风格，最常见的翻车方式是什么（不是「画得丑」，而是「上线被骂没特色/被指认为抄袭某作/世界不可信」）？
5. **验收判据**：什么能证明「这个风格的呈现是对的」？可被外部观察，不靠「我觉得很赛博」。
6. **暂缓范围**：第一个原型**明确不做**什么？（用来防守风格投入失控，尤其是霓虹铺量与资产密度）

## 5. 按六问蒸馏的判断

### Q1 玩家要什么

**要**：
1. **一种「被具体化的未来日常」**——A3 的一手准则是本包的地基：「塞满看起来很未来之物的环境不是赛博朋克，只是科幻」；玩家要看到的是「未来技术渗透进旧日生活」（旧木门 + LED 门禁）。
2. **反差被叙述出来，而不只是被布景**——B2 把 low-life / high-tech 拆成具体清单；A4/B4 给出「不用说明性对话讲出阶层故事」的正例；C1 给出反面（只做布景 → 住久了不信）。
3. **能立刻认出「我在城市的哪里」**——A4 原话：各城区风格必须真的不同，「如果只有同一种建筑，城市很快就无聊了」；对应 B1 的批评（到处都是同一套霓虹）。
4. **可读的视觉层级**——A1 自承翻车：细节过密、缺少留白时「玩家视线更难找到重点」；资料片为此订了留白规则。这与卡 `card-ns-062`（差评从指向「精度不够」转向「读不出重点」）完全同构。

**不要（会立刻出戏/划走）**：
1. **泛泛的「霓虹雨夜」**——B1（静态类型批评）+ C3（雷同集合）+ B3（拼贴无理由）。
2. **世界不可信**——C1：第一眼震撼、第二眼是胶合板布景；可复现证据是「同一段 NPC 对话听五十次」。
3. **黑话堆砌到不像人说话**——C2：原话「像让 14 岁小孩写硬汉台词」；C4 指出症结在语域而非有无黑话。
4. **只为炫技的「rule of cool」拼贴**——B3：抽掉原作者做选择时的理由，只留「看起来很酷」。
5. **美学挤掉主题**——B2：「美学有成为王的倾向」，结果是权力幻想而非社会洞察。
6. **霓虹铺满、没有阴影**——A1（视觉噪音）+ 卡 `card-gd-051`（特效预算要不对称）同理：光要有对比才有意义。

### Q2 第一小时

**必须做到**：
1. **第一屏就示范「未来与平凡并置」**，而不是先给一片纯霓虹——依据 A3 的一手准则（含具体做法：旧门装 LED、老餐馆用现代点单设备）。
2. **用反差讲阶层，而不是用标签讲阶层**——A4/B4：让场景自己说「这里是谁的、什么时候建的」，玩家读到的是权力关系而不是设定说明。
3. **给一个可辨认的空间身份**：第一小时内应能认出「这是哪个区、谁住这里」——A4 的城区差异原则在国内区域与国际都市的对照里成立；依据 B4「不用说明性对话就能讲故事」。
4. **视觉层级要留白**：第一屏就要能指出「眼睛第一落点在哪、它把人带去哪」——A1 的翻车教训 + 卡 `card-ns-062` 的评审口径。
5. **语言要有语域分层但读得懂**——A5：出身/阶层对应不同说话方式；同时 C2/C4 警示别堆到不像人话。

**交叉验证**：「未来与平凡并置是赛博朋克 vs 科幻的分界」有 A3（一手准则）单独但极强的一手来源；「反差当叙事载体」有 A4（一手）+ B4（一手转述）+ B2（口号拆解）三处独立 → 进默认建议。
「城区/空间必须可辨认」有 A4（一手）+ B1（雷同批评的反面）两处独立 → 进默认建议。
「视觉层级与留白」有 A1（开发者自承翻车）+ 卡 `card-ns-062`（玩家盲评）两处独立 → 进默认建议。

### Q3 流派分叉（4 条视觉路线）

原型期通常会裂成这几条，**各自第一屏的取舍不同**：

| 路线 | 第一屏 / 首个取舍 | 代表 | 出处 |
|---|---|---|---|
| **经典霓虹都市** | 用雨夜、霓虹倒影、纵向压迫建身份；代价是最容易撞进「静态类型」雷同区，必须先想清楚自己的差异点 | Blade Runner 一脉 | A3（准则）、B1（雷同警示）、A5（影响来源自述） |
| **日光／非典型配色** | 用「本该阴暗的题材偏要走晴天」建身份，直接反刻板印象；代价是失去默认氛围的免费加成 | 加州式的晴朗赛博朋克 | 检索中 CDPR 概念美术的明确表态（「人们预期黑暗多雨的赛博朋克，但你可以做加州的赛博朋克城市」） |
| **四年代分层／城市编年史** | 用可辨认的时代层（紧缩／媚俗／企业军事化／新媚俗）建身份，让玩家从建筑读出年代；代价是要先写死一条时间线 | Night City 的四年代 | A1、A4、B4 |
| **反图像／刻意跳开标准符号** | 用「不像赛博朋克的赛博朋克」建身份（灰色办公室、方盒卡通、逻辑解谜）；代价是需要更强的作者意图 | Quadrilateral Cowboy | B1、C3 |

**交叉验证**：四条路线各有独立来源；「非典型配色」这条在检索中只有一处一手表态，**属单薄**，故在包数据里不列为默认推荐，仅作方向；「四年代分层」有 A1+A4+B4 三处一手 → 可作默认方向。

### Q4 新手真实死法

按「死在哪个环节」排序，均可被外部观察：

1. **做成「静态类型」的又一员** → 被指认为某某作的复刻。B1（学术判词 + Gibson 原话）、C3（雷同集合）、B3（无理由拼贴）三处独立，是**第一死因**。
2. **反差只做布景、没做生活** → 第一眼震撼、住久了不信。C1 最清楚（附可复现证据：同一段 NPC 对话重复五十次）。
3. **霓虹铺满、缺留白** → 玩家视线找不到重点。A1（开发者自承）、卡 `card-ns-062`（盲评）、卡 `card-gd-051`（预算不对称）三处。
4. **黑话语域不可信** → 「像 14 岁小孩写硬汉台词」。C2、C4。
5. **美学挤掉主题** → 变成单纯的权力幻想。B2、B3。
6. **只有「酷」没有理由** → 拼贴他作符号而不理解其选择。B3。

### Q5 验收判据（可外部观察，不靠「我觉得很赛博」）

**画面层**：
- [ ] **并置测试**：截图里能否指出至少一处「未来技术与旧日日常同框」的具体实例（旧物上装着新东西）？若全屏都是未来感物件，判为「只是科幻」（A3 一手准则）。
- [ ] **反差测试**：能否从场景本身读出「谁在这里、谁不在这里、谁在建这里」？只靠标签与说明文字才能读出阶层的，判不合格（A4、B4、B2）。
- [ ] **空间辨认测试**：把两个不同区域的截图并排，能否立刻说出它们不是同一个地方？（A4 原话的反向验收）
- [ ] **留白／落点测试**：「这是什么地方、干什么用的、眼睛第一落点在哪、落点把人带去哪」四问能否各自答出；答不出即视觉噪音过量（A1 自承 + 卡 `card-ns-062`）。
- [ ] **雷同自检**：把本作截图与最常被拿来比较的两三部作品并排，能否说出本作「刻意保留的差异点」？说不出的，或者只看得出配色不同的，回到 B1 的清单重做。

**文本层**：
- [ ] **语域分层检查**：不同阶层/出身的角色说话方式在手感上不同，且**每个语域都读得通**（A5 的做法；C2/C4 的反面约束）。
- [ ] **黑话密度检查**：术语在正常对白里被反复使用而不显笨重；**任一关键术语若需要一段解释才明白其社会职能，就应改掉或降级为设定笔记**（与 `style.western-fantasy` 的头衔脚注检查同构；A5 的部分采信同理，**此条在本包为外推**）。
- [ ] **原话回读测试**：把台词读出来，是否像「这个人会说的话」而不是「作者想让他显得酷」？（C2 原话的直接反面）

**反馈层（证据单薄，以下为外推方向，非默认推荐）**：
- [ ] **UI 世界观化自检**：界面是「贴了一层霓虹滤镜」，还是让玩家操作界面的动作本身就在扮演角色？（卡 `card-gd-057` 的三级：隐藏／场景化／风格化，且风格必须与主题同源才成立）
- [ ] **信息密度与题材一致**：本作是低操作密度沉浸向就大胆减 HUD，是高操作密度就按卡 `card-ur-014` 给足信息；不要无条件走「极简」。（`card-ur-014`、`card-gd-070`）
- [ ] **反馈文案语域一致**：反馈文案不混入现代网络语或与世界观不符的腔调（**此条为外推的低证据方向**）。

**反例红线（触发即判负）**：
- ✗ 截图里没有任何「未来与日常并置」的具体实例，全是未来感物件。
- ✗ 两个区域的截图无法分辨是不是同一地点。
- ✗ 场景里读不出阶层关系，只能靠一段说明文字补。
- ✗ 关键术语需要脚注才能读懂；台词读出来不像人会说的话。
- ✗ 说不清本作相对最常被比较作品刻意保留的差异点。
- 依据：A3（并置准则）、A1/A4/B4（四年代与反差叙事）、B1/C3（雷同批评）、C1（世界可信度）、C2/C4（语域）、卡 `card-ns-062`（留白与落点）、卡 `card-gd-057`/`card-ur-014`（UI 世界观化）。

### Q6 暂缓范围（第一个原型明确不做）

- ✗ **不做全城铺量 / 大体量开放街区**（A2：纹素密度是《巫师 3》两倍是 3A 投入；小团队先证反差与落点成立）。
- ✗ **不做全量义体/装备外观库**（身份来自并置与反差，不来自物品数量）。
- ✗ **不做「霓虹堆满」的默认打光**（A1 自承的翻车点；霓虹是点缀不是主光）。
- ✗ **不做完整黑话词典/语言系统**（先把一个语域写可信，再谈分层；C2 警示堆砌）。
- ✗ **不做多城区 + 多群系的大地图**（A4 的城区差异原则要先在两三个区域内验证）。
- ✗ **不做天气/昼夜的完整系统**（先证静态场景的并置与留白达标）。
- ✗ **不做跨题材混搭**（先在一个技术底座内做纯，混搭是身份未立时的稀释行为）。
- ✗ **不做局外长线/外观经济**（属局外系统，先扩局内呈现体量）。

## 8. 没能回答的缺口

1. **「反馈层怎么赛博朋克化」没有可引用的对照证据**。本包只在界面方向上有来源（`card-gd-057`/`card-ur-014`/`card-gd-070`），其余（音效设计、结算演出、状态反馈的题材重构）**无来源**——尽管检索命中的多篇博客都提到「声音是一半的战场」，**均无可核查作者与方法**，故一律不采信。`presentation.feedback` 因此必须标低证据、只给方向。
2. **「并置与反差做到什么密度才够」没有量化标准**。A1/A3/A4 都说要并置、要反差、要留白，但**没有一条说明多少算够、多少算视觉噪音**。本包因此把问题转成可观察的测试（并置测试、落点四问、雷同自检），但**没有阈值**。
3. **「静态类型」的边界在哪、如何证明自己不是**只有方向性表述（B1 说 Quadrilateral Cowboy 是正例），**无判定清单**。
4. **中文一手开发者访谈缺失**：中文侧只有 A1 的中文转述（原始来源仍是英文 80.lv 访谈）。属检索覆盖缺口，非「没有」。
5. **本包所有判断均来自公开检索与卡片库蒸馏，未经任何真实用户样张测试。** 任何「这个调性会被玩家喜欢」的说法都超出证据范围。
6. **风格包与品类包的交互没有验证**：本包只描述呈现层，**「赛博朋克 × 某个品类」组合后的实际效果无任何来源**，属结构性空白，与所有风格包一致。

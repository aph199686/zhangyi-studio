# 调研记录：生存建造（genre.survival）

- 检索日期：2026-09-28
- 检索执行者：AI 陪练（非人工试玩）
- 本包用途：**张翼通用品类包**（与任何具体项目无关），来源均为公开检索 + 卡片库蒸馏
- 结论一句话：生存建造的最小闭环是「**稀缺写出的压力 → 做出能改变处境的第一个物件 → 亲手把一次危机解掉**」；成败押在**第一夜的压迫感是否被一两个可读的机制承载**，而不是地图大小或建造自由度。这是少数**必须先定义"时间这个唯一真资源"再动手做内容**的品类，堆系统只会把压力稀释成忙碌。

---

## 0. 划界（这个包吃什么、不吃什么）

**属于本包**：
- 玩家在**敌对环境**中以**个体**存活为目标；核心情绪是**无力感**（powerlessness / vulnerability）。
- 有**会失败的资源压力**：饿、冷、伤、被袭击，失败有代价（掉进度、掉据点、坏档或重开）。
- 循环为「采集 → 制作 → 建造/使用 → 获得新的生存能力 → 环境压力升级」，且**压力始终在追**（新群系/新灾种制造新一轮稀缺）。
- 成长主要落在**外部资源**（自建农场、据点、装备）而非角色内数值。

**明确排除（避免与相邻包重叠）**：
- **纯生产扩张、无失败惩罚**（把采集/建造当经营，压力来自效率而非死亡）→ 归**经营包 `genre.management`**。判据：核心循环里**有没有一个会输掉的状态**；没有就是经营。依据：学术来源明确把生存与「开发并维持社群」的管理类（如类 Banished / RimWorld 社群经营）与「放松的农场模拟」区分开，分界正是**敌对环境 + 个体存活挑战**（B2）。这一句直接支撑本包 boundary。
- **肉鸽/DBG 构筑** → `genre.rogue`。生存有随机世界，但本包核心是**压力与失败代价**，不是局内构筑。
- **纯 PvP 竞技**（吃鸡类）→ 失败代价是名次不是生存，不属本包；其 PvP 生存分支在本包中**暂缓**（见 §5-Q6）。

**边界声明（用于包数据 `boundary` 字段）**：
> 依据公开检索与卡片库蒸馏（2026-09-28），未运行、未试玩、未平衡、未做真实玩家测试。资源压力＋失败代价（饿死、冻死、被袭击）是品类核心归本包；纯生产扩张、核心循环里没有失败状态归经营包。

## 1. 六个关键问题（先写在检索之前）

1. **玩家要什么**：生存建造玩家真正追求什么体验？什么会让老玩家立刻反感？
2. **第一小时**：开局第一小时必须让玩家感受到什么、拿到什么，才算「进门」？第一晚怎么过、第一件工具是什么、第一个庇护所怎么来？
3. **流派分叉**：原型期通常裂成哪 3–4 条路线？各自首局目标是什么？
4. **新手真实死法**：新人做这个品类最常见的失败方式是什么（可外部观察的那种）？
5. **验收判据**：什么能证明「首局骨架对」？可被外部观察、不靠「我觉得好玩」。
6. **暂缓范围**：第一个原型**明确不做**什么？
7. **划界问题**：资源压力 + 失败代价归本包，纯生产扩张归经营包——这条线画在哪里？（见 §0）

## 5. 按六问蒸馏的判断

### Q1 玩家要什么

**要**：
1. **稀缺写出的故事**——可被自己讲述的「第一夜差点没活下来」。（B3；B2 的 DayZ 案例：饿到快死、在电厂外被玩家打死，「那是我做的有意义的决定，也有有意义的后果」）
2. **从零到有的尺度感**——正因为开局什么都没有，第一把工具、第一面墙、第一堆火才有分量。（B3、B2）
3. **在压力下解决问题的戏剧时刻**——「盘」转动、计划被打乱、临场改方案并活下来。（A1）
4. **一个能守住的据点**——据点是「近乎神圣的安全区」，安全和危险必须**有清晰边界**。（B2）
5. **可见的下一个目标**：能看见的地标、能推断的共同目标，组队时能说清「在哪」。（B1）

**不要（会立刻反感）**：
1. **不靠技巧、只靠时间的重复劳动**（搬矿/烧煤/长途摆渡），且**不给自动化**。（C1、C2、B1）
2. **换皮的新区域**——「更多同类，只是看起来不同」。（C2）
3. **必须外挂外部教程才能玩**——「得在旁边开着 iPad 挂 YouTube 教程」。（B1）
4. **事件吃光资源 / 制作代价不可预判**——一次制作把整筐资源清零。（D1）
5. **做得很"忙"但没有目标、幻想与设定**。（A1）

**交叉验证**：Q1 的「反感纯时间税」由 C1 + C2 + B1 三处独立来源支撑（含两条一手玩家原帖）→ 进默认建议。
Q1 的「稀缺是核心」由 A1（时间是真资源）+ B3（稀缺是叙事者）+ B2（无力感定义品类）三处独立支撑 → 进默认建议。

### Q2 第一小时

**必须做到**：
1. **零起点（裸开局）作为标尺**，但**第一个可玩动作要在第一分钟内完成**，并且立刻**转化成建造或工具**（「砍树」是把整局语法刻进手里的教程）。（B3）
2. **第一分钟就要有一个真实需求在追**——天黑、饿、冷或远方的敌意；需求来自环境，不来自弹窗。（B3、B2）
3. **第一件工具必须立刻改变处境**：它要能让"技巧"在第一个周期内生效，而不是只有数值提升。判据参照——几分钟内能拿到能对抗/能自保的东西（如一把弓），而**不是**开局砍树 20 分钟。（B1）
4. **第一夜/第一波要"可读且可达成"**：玩家能看清威胁是什么、也知道该做什么（火堆/庇护所/封窗），并且**亲手过掉一次**。（B3、A2）
5. **早期要留一道"低压力教学题"**：如一只落单的怪当沙包，让玩家在安全压力下学会战斗、并自证"为什么要为夜晚准备"。（A2）

**交叉验证**：Q2 的「第一分钟可玩并立刻闭环」有 B3（树是老师）与 A2（沙包僵尸给新人低压学习）两处独立表述 → 进默认建议（两条都为"第一小时的第一个动作"服务）。
Q2 的「第一件工具要能立刻改变处境」直接来源仅 B1（H1Z1 的弓）一条 + A1 侧面支持 → **标低证据**（见 §7）。

### Q3 流派分叉（3–4 条路线）

| 路线 | 首局目标 | 代表 | 出处 |
|---|---|---|---|
| **单人硬核模拟** | **活过第一夜**：火堆 + 一处庇护 + 能读懂的饿/冷/伤威胁 | The Long Dark、Project Zomboid、Green Hell | A5、A6、B2、B3 |
| **合作建造生存** | **搭起第一座工作台 + 第一层建造**（把基地变成共享目标） | Valheim、Raft、Grounded | A3、A4、B2 |
| **波次—据点防守** | **撑过第一波/第一夜**：准备期 → 战斗期两段结构 | Survive Another Night、7 Days to Die 类 | A2 |
| **PvP 沙盒** | **拿到能对抗他人的第一件武器**（社交/对抗才是主线） | Rust、DayZ、The Stomping Land | B1、D1 |

**建议首原型三选一（`firstChallenge`）**：单人硬核模拟 / 合作建造生存 / 波次—据点防守。
**PvP 沙盒不进首局方向**：它对**多人同步、反作弊、玩家供给量**有硬依赖，且 D1 说明这类项目一旦支撑不足会直接做死；B1 也指出该分支至今没有解决「共同目标与地标」问题。（→ 移入 `defer`）

### Q4 新手真实死法（可外部观察）

按"死在哪个环节"排序：
1. **把游戏做"忙"了，却没有目标、幻想或设定**——玩家有事做但不知道为什么做。（A1：市场上大量游戏「很忙但缺 richness」）
2. **把稀缺做成纯时间税**——重复采集/搬运/摆渡不产生决策，玩家体感是"耗时间"并主动放弃原版。（C1、C2；B1 的「磨的游戏不是技巧的游戏」）
3. **首原型就做多人同步**——把最金贵的时间花在联网而不是玩法上。（A2：「1.5 天做出了一个不是游戏的东西」）
4. **系统一次上太多、互相拉扯**——每个新系统都要和已有系统"拔河"；同一个坐骑改动会在"走路被罚/没人探索/没人用"之间来回翻。（A3；A6 的分期上线是反面做法）
5. **Early Access 承诺不兑现、被弃更**——内容缩水 + 失联 + 退款风波 = 项目死亡。（D1）
6. **用换皮的新区域充当进度**——玩家读到的不是新内容，是"更长"。（C2）
7. **死亡不可读/不公平**——惩罚没有传达"你偏在哪"，玩家学不到东西。（B4；A2 用低压教学怪预防这一条）
8. **制作代价设计不当**——一次制作吃光全部资源，制造的是烦躁而不是取舍。（D1）

**交叉验证**：Q4 的「纯时间税是主要流失源」由 C1 + C2 + B1 三处独立支撑；「系统耦合/平衡拉锯」由 A3 + A6 两处；「早期做多人是死法」由 A2 + D1（PvP 依赖）两处。

### Q5 验收判据（可外部观察，不靠「我觉得好玩」）

**结构层（可在设计文档/灰盒上数出来）**：
- [ ] **制作链首轮闭环存在**：采集 → 制作 → 使用 → 由此获得新生存能力，全部能在**同一局**内走通。（B5 的基本顺序；A1 的"盘"）
- [ ] **第一个周期可完整走完**：一次「白天准备 → 夜晚压力 → 结果」的循环在首局内被玩家亲身走完 ≥1 次。（B3、A2）
- [ ] **开局指令/教学弹窗 ≤ 3 条**，且基础循环**不依赖外部资料**。（B1）
- [ ] **每个早期威胁都有可读的应对手段**（火堆对应冷、墙/门对应袭击、工具对应饥饿）——不允许"知道要做什么但游戏没给手段"。（B3、B4）
- [ ] **首个原型的压力系统数量有上限**（建议只开 **1–2 个会致命的压力**，其余延后）。（A1 的"盘"要少而精；A6 的分期上线）

**体验层（试玩可观察行为）**：
- [ ] 玩家在**无提示**下自行走向下一个资源点/目标（说明"树是老师"生效）。（B3）
- [ ] 玩家**主动**修建/加固庇护所，动机来自压力而非任务文本。（B2 的基地=安全区）
- [ ] 玩家能**说出自己为什么死**（饿/冷/被怪/走错）——死亡可归因。（B4）
- [ ] 首小时内出现 ≥1 次"计划被打乱后临场改方案并活下来"。（A1）
- [ ] 玩家在没有任何"共同目标"提示时能说出"我接下来想干什么"。（B1）

**反例红线（触发即判负）**：
- ✗ 首小时存在**无操作/纯搬运的时间池**（挖一坨矿只为再挖一坨）。（C1、B1）
- ✗ 出现「**一次制作清空全部资源**」这类不可预判的代价。（D1）
- ✗ 首局**必须看外部教程**才能完成基础循环。（B1）
- ✗ 前 30 分钟**看不到任何威胁，也看不到任何目标**。（A1 的"忙碌但空"）
- ✗ 玩家死于**说不出原因**的情况。（B4）
- ✗ 用一个新区域充当进度，而它只是**换皮 + 更硬的怪**。（C2）

### Q6 暂缓范围（第一个原型明确不做）

- ✗ **不做多人同步 / 联机**（A2：1.5 天做联网 = 没做出游戏；A3：联机会让每项平衡变成双轨道拔河）。
- ✗ **不做 PvP 与反作弊**（D1：PvP 生存对玩家供给和稳定性有硬依赖，是项目死亡的高风险路径；B1：共同目标/地标问题未解）。
- ✗ **不做完整建造物理与结构承重**（把复杂度留在"能不能建"而非"以什么力学建"）。
- ✗ **不做大程序化地图**（A2 明确砍掉随机生成以换取核心机制时间）。
- ✗ **不同时开天气 + 体温 + 饥饿 + 精神多套系统**（A1：盘要少而精；A6：这类系统是**分期**加进去的）。
- ✗ **不做大量生物群系**（C2：换皮新群系是差评源；应先做"少而不同"）。
- ✗ **不做故事模式 / 多结局 / 长线 meta 进度**（A5 说明故事模式可后置，生存模式才是引擎）。

## 7. 证据强度自评

**总评：充分（对"首小时压力结构"与"流失原因"）／有限（对"具体数值"与"市场层"）**

| 被判断的字段 | 强度 | 依据 |
|---|---|---|
| 划界（资源压力 + 失败代价 vs 经营包） | **充分** | B2 明确把生存与"社群管理/放松农场"分开（敌对环境 + 个体存活）；A6/A5 的第一手陈述同向 → 两条独立来源 |

| 「第一件工具要立刻改变处境」 | **有限** | 直接来源仅 B1（H1Z1 的弓）；A1 的"盘"只间接支持。**标低证据，作为方向而非硬线** |
| 「首原型不做多人同步」 | **充分** | A2（一手复盘："1.5 天做出不是游戏的东西"）+ A3（坐骑/战斗双轨平衡）+ D1（PvP 依赖致项目死亡） |

| 「系统一次上太多会互相拉扯」 | **有限→充分** | A3（坐骑平衡反复翻）+ A6（营养/无聊分期上线）+ A1（盘要少而精）三处 |

**低证据清单（不得作为默认推荐）**：
- 「几分钟内拿到能对抗的第一件工具」的具体承诺 → **低证据**（仅 B1），只作方向。
- 「开局指令 ≤3 条」的**具体条数** → **低证据**（单一来源），保留为红线形态（"不靠外部教程"），不留成数字硬线。
- 「新区域换皮导致流失」→ 低证据（单条玩家原帖），建议列为可选优化项。
- 「第一夜留一只沙包怪」的默认值（`sv_first_night` 默认项）→ **低证据**（直接来源仅 A2 一条；B3 只间接覆盖"第一夜是记忆点"），作方向而非硬线。
- 任何「第一小时具体分钟数/资源投放量」→ **无来源，本包不给数值**。

## 8. 没能回答的缺口

1. **「第一夜应该多长」没有权威数字。** 来源只说"第一周期要能走完"，无人给出可执行的时长阈值。本包**只给形态，不给秒数/分钟数**。
2. **压力系统的数量上限**无可量化来源。A1 说"盘要少"，A6 是分期上线，但"首原型开 1 个还是 2 个致命压力"没有实测依据。
3. **自动化/便利功能该在什么时候给**没有来源。C1 抱怨"没有自动化"，但没人给出"第几小时该解锁自动拾取/传送"的标准。
4. **死亡惩罚的量化档位**（掉多少、是否坏档、回收还是清空）无来源，本包只保留"死亡要可读"这一层。
5. **Reddit 玩家视角缺失。** 本环境所有 reddit 镜像均被拦截（429/Anubis/403），玩家视角只能用 Steam 讨论区原帖替代；**r/ 子版"反复抱怨"的共性统计因此没有被收录**，属检索覆盖缺口。
6. **中文一手开发者复盘几乎缺失。** 中文来源在检索中多为媒体转述或攻略，未见中国大陆团队关于生存建造品类的开发者一手复盘。属覆盖缺口，非"没有"。
7. **本包所有判断均来自公开检索与卡片库蒸馏，未经任何真实玩家试玩验证。** 任何「这局会好玩」的说法都超出证据范围。

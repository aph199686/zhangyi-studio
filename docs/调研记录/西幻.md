# 调研记录：西幻（style.western-fantasy）

- 检索日期：2026-09-28
- 检索执行者：AI 陪练（WorkBuddy 会话），非人工试玩
- 本包用途：**张翼通用风格包**（与任何具体项目无关），来源均为公开检索 + 卡片库蒸馏
- 结论一句话：西幻的第一顺位不是「考据得准不准」，而是**这个世界是不是「自己的」**。这个风格池已经被中世纪欧洲模板挤满——骑士、城堡、修道院、龙与魔法是全世界玩家的共同默认值，所以**「像西幻」不构成卖点，「是哪个西幻」才是**。风格包只改呈现、文本与反馈三层，不碰胜负与回合规则；其中**画面层证据最扎实，文本层尚可，反馈层证据偏薄（须如实标低证据，不得用常识填充）**。

## 0. 划界（这个包吃什么、不吃什么）

**属于本包**：
- 题材调性落在「欧美中世纪/文艺复兴自然主义奇幻」这一脉：盔甲骑士、封建领主治下的村镇、修道院与钟楼、龙与地下城一类的神话生物、铁匠铺与酒馆。
- 包含三类常见子流：**写实低魔（低幻想、政治与民俗压过魔法）**、**史诗高魔（有魔法体系、有超自然规模）**、**黑暗哥特（衰败、压迫、血与宗教）**。
- 与「日式幻想/二次元」的区别不在有没有龙或魔法，而在**呈现语法**：西幻走自然主义与材质可信度（磨损的皮甲、风化的石墙），二次元走程式化与记忆点夸张。同一题材（如剑与魔法）按语法分家，**同一项目只打一个风格包**。

**明确排除（避免与相邻风格包重叠）**：
- **古风（武侠、仙侠、国潮）** → 已由 `style.guofeng` 承担。判据：**文化联想链条指向的文化根源是欧洲还是东亚**。带长剑的东方修士属古风，不属本包。
- **赛博朋克** → 由 `style.cyberpunk` 承担。西幻的自然主义与赛博朋克的人工化、高饱和霓虹是对立的呈现语法。
- **日式幻想／二次元** → 已由 `style.anime` 承担。
- **现代/写实题材的奇幻元素**（当代都市里加一个魔法）→ 若整体调性仍是当代写实，只是加了幻想元素，不构成本包（本包要求呈现语法整体落在西幻一脉）。

**边界声明（用于包数据 `boundary` 字段）**：
> 离线设计预设；依据公开检索与卡片库蒸馏（2026-09-28），未运行、未平衡、未试玩。只改呈现、文本与反馈，不定义胜负与回合规则。

## 1. 六个关键问题（先写在检索之前）

1. **玩家要什么**：玩家选这个风格时，真正在买的是什么？什么会让他们一眼判定「又一个换皮中世纪」并划走？
2. **第一小时**：开场第一小时，画面/文本/反馈各要让玩家感受到什么，才算「这是一部西幻」而不是「这是一部有龙的游戏」？
3. **流派分叉**：这类风格在做呈现时，通常裂成哪 3–4 条视觉流派？各自的取舍是什么？
4. **新手真实死法**：新人用这个风格，最常见的翻车方式是什么（不是「画得丑」，而是「上线被骂没特色/记不住/被指认成别的游戏」）？
5. **验收判据**：什么东西能证明「这个风格的呈现是对的」？可被外部观察，不靠「我觉得很有史诗感」。
6. **暂缓范围**：第一个原型**明确不做**什么？（用来防守风格投入失控）

## 5. 按六问蒸馏的判断

### Q1 玩家要什么

**要**：
1. **一个可辨认的「世界身份」**——A1 把这个排在第一动作：「找出你项目的身份是什么」。西幻的玩家默认值训练得极好，所以他们能瞬间分辨「这是它自己，还是又一个中世纪模板」。
2. **可读性优先于繁复**——C3 的反例说明玩家最终要的是「能认出敌人、能找到 NPC」；B4/B5 说明护甲与剪影承担的是**功能性可读**（职业、体型、威胁），不只是好看。
3. **连贯胜过单件精彩**——A3 明说「优先连贯性，而非单件资产的品质」；玩家读的是整体是不是一个世界，而不是某张立绘多精美。
4. **氛围有兑现、有区分**——C2 的正面参照是「把灰暗绑在叙事节拍上」：氛围手段要有节奏，玩家要的是「这里该暗」而不是「到处都暗」。

**不要（会立刻出戏/划走）**：
1. **「泛泛的中世纪奇幻」**——C1（棕灰一片）、C2（永阴天）、C4（廉价资产 + 填空套路）三例共同指向这个词。**被指认成「另一个换皮中世纪」是这个风格的死法第一名。**
2. **调性统一压迫可读性**——C3：为了棕灰统一，把敌人/NPC/道具和环境糊在一起，是功能性失败而非审美分歧。
3. **拼装感**——A2 明说最怕是「Frankenstein's monster」：各件资产单看不错，合起来不像一个世界。
4. **lore 倾倒**——B8 同类（见 §6 与 Q4）：把设定当说明书写给玩家背，玩家会「像在备考」。
5. **只为「像奇幻」而堆符号**——宗教、彩窗、骑士若只是「定位时间的廉价信号」（B2），而不承担任何功能性解释，就是装饰。

### Q2 第一小时

**必须做到**：
1. **第一屏打出这个世界的身份标记**，而不是先给一段通用中世纪村镇——依据 A1（先找身份、收窄色板）；参照 C5 的正面样本，身份标记常来自「地理与政治的具体关系」，而非某个孤立的奇幻地标。
2. **建立一套「材质可信 + 调性收窄」的视觉语法**：A3 给了它一个可测试的说法——用主色板 + 辅助色板建立层级；A1 给了收窄色板作为建立身份的关键一步。**目标不是色彩丰富，而是「看三个不同场景能认出同一个世界」。**
3. **界面/反馈在开场就示范「规则一致」**：A4 的 diegetic 落点——如果开场就有一个 UI 元素在虚构里有处安身（血条长在角色身上、地图是实体物件），玩家立刻建立「这个世界是自洽的」预期；若开场就是飘在屏幕上的通用 HUD，则丢掉这个信号。
4. **文本在开场遵守「先读得懂、再有诗意」**：A5——玩家的第一个名字/第一个头衔就要过关（连按十次随机都要像「属于这个世界的人」）。

**交叉验证**：「先定身份、收窄色板、保连贯」有 A1（一手访谈）+ A2（方法论）+ A3（方法论）三处独立表述 → 进默认建议。
「可读性优先于繁复」有 C3（辨识失败的一手案例）+ B4（剪影承担职业可读性）+ A3（连贯优先）三处独立 → 进默认建议。
「界面规则一致是沉浸信号」有 A4（diegetic 方法论）+ B6（UI 是叙事的一部分）两处 → 进默认建议。

### Q3 流派分叉（4 条视觉路线）

原型期通常会裂成这几条，**各自的第一屏取舍不同**：

| 路线 | 第一屏 / 首个取舍 | 代表 | 出处 |
|---|---|---|---|
| **写实低魔** | 用材质可信度（磨损皮甲、风化石墙）与政治/民俗关系建身份；魔法弱、世界真实感强 | 低幻想东欧/北境林地的区域化世界 | B2、C5、A1 |
| **史诗高魔** | 用超自然规模与有来源的魔法体系建身份；色彩与奇观更张扬，但要防「泛滥的符号」 | 大部头奇幻 RPG 的开放世界 | B1、B2、B5（BG3） |
| **黑暗哥特** | 用衰败、压迫、宗教权力建身份；把「灰暗」绑在叙事节拍上而非当默认底色 | 哥特吸血鬼政权一类的压迫性区域 | C5、C2（反面）、B5（Diablo 4） |
| **精致插画／蚀刻版画** | 用独特的手绘/版画语法建身份；资产少但风格强，天然规避「3A 通用感」 | 单塔手绘世界一类的插画驱动 | A1 |

**交叉验证**：四条路线各有独立来源；「黑暗哥特的灰暗要有叙事绑定否则即成 C2 反例」有 C5（正例）与 C2（反例）两处；「插画驱动是小团队建身份的高性价比路线」有 A1（一手）与 A3（小团队扛不住 PBR → 走程式化）两处方向一致。

### Q4 新手真实死法

按「死在哪个环节」排序，均可被外部观察：

1. **做成了「泛泛的中世纪奇幻」** → 上线被指认成别的游戏、记不住、划走。C1/C2/C4 三例共同指向，是这个风格的**第一死因**。
2. **调性统一压倒可读性** → 玩家在场景里找不到敌人/NPC/道具。C3 是最清楚的一手案例。
3. **拼装感 / 没有 style guide** → A2 明说最怕是拼成 Frankenstein's monster，第二常见是「风格指南执行不一致」。
4. **lore 倾倒与术语过载** → A5 的「需要脚注才解释得清的头衔属于 lore 笔记」判据；RPG 语境下更严重，因为玩家要**使用**这套词汇（见 §审慎：原作该论点是 TRPG 语境，游戏内可迁移但需标注外推）。
5. **氛围手段用成默认底色** → C2：灰暗若不作叙事绑定就成了单调，单调导致弃坑。
6. **技术/调性包装补偿资产薄弱** → C4：Forspoken 靠 RTX 掩盖廉价资产，Babylon's Fall 好风格被烂贴图吸干，两例都失败了。

### Q5 验收判据（可外部观察，不靠「我觉得很有史诗感」）

**画面层**：
- [ ] **身份测试**：把三个不同场景并排给人看，能否认出它们属于同一个世界？（A1 连贯性、A2 style guide）
- [ ] **联想指向测试**：把画面给代表性用户看，收集第一反应关键词，检查它是否稳定指向「你自己的那个西幻」，而不是「泛泛中世纪」——**若答案是后者，等于没做**（卡 `card-kl-036`，与 A1 身份判断一致）。
- [ ] **色板收窄检查**：存在写明的主色板 + 辅助色板，且三屏抽查都在其中（A1、A3）。
- [ ] **剪影/可读性检查**：把角色/敌人填成纯黑并缩到实际游戏尺寸，能否读出职业与威胁等级？（B4、B5）
- [ ] **对比度可读性测试**：在目标光照与典型移动速度下（不是静止截图）能否分辨敌人/NPC/可交互物？（C3 反面 + B7）

**文本层**：
- [ ] **命名可读性**：随机连抽十个名字，逐个确认「是一个能读通、且意象属于这个世界的人/物/地」（A5；与 `style.guofeng` 的随机名池质检同构）。
- [ ] **头衔/背景名脚注检查**：玩家可见的每个头衔，若需要一段解释才明白其社会职能，就应改掉（A5）。
- [ ] **重复耐久检查**：核心术语能否在正常对白里被反复使用而不显得笨重（A5）。

**反馈层（证据偏薄，以下为外推方向，非默认推荐）**：
- [ ] **「打破 UI」测试**：世界能否干扰你的界面？（护甲上的血条会受损吗？）若答案是「不能」，它就不是系统性的（A4，**该测试出自 diegetic UI 方法论，属分析视角，非厂商实测**）。
- [ ] **反馈与文化语境一致**：反馈文案的语域与世界观一致，避免现代网络语混入；纯数值飘字的可读性优先于修辞（**此条为外推的低证据方向**）。

**反例红线（触发即判负）**：
- ✗ 三个场景并排看不出属于同一世界（拼装感）。
- ✗ 用户联想测试稳定指向「泛泛中世纪奇幻」而非本作身份。
- ✗ 在实机光照/移动下分不出敌人、NPC 与环境（C3）。
- ✗ 没有色板文档，或资产抽查常跑出色板。
- ✗ 存在「需要脚注才能读懂职能」的玩家可见头衔（A5）。
- 依据：A1/A2/A3（身份与连贯）、B4/B5（剪影可读）、C1/C2/C3/C4（四类差评反例）、A4/B6（界面规则一致）、A5（命名纪律）。

### Q6 暂缓范围（第一个原型明确不做）

- ✗ **不做 PBR 级写实材质管线**（A2/A3：小团队扛不住，且写实会放大「通用感」——越写实越容易被拿去和 3A 比）。
- ✗ **不做全量奇幻生物/怪物图鉴**（先把世界身份与调性立住，怪兽种类不是身份来源）。
- ✗ **不做多群系大地图**（第一版只用一个区域验证「身份 + 可读性 + 连贯」三件事）。
- ✗ **不做完整魔法体系的可视化奇观**（高魔奇观是身份放大器，不是身份本体；先证身份站得住）。
- ✗ **不做全量 lore 文档 / 编年史**（A5 + lore 纪律：先保证玩家可见的文本读得通）。
- ✗ **不做复杂 diegetic 全界面改造**（A4：先在一个 UI 元素上验证「规则一致」是否成立，再谈全量）。
- ✗ **不做跨文化混搭**（先把一个文化池做纯，混搭是身份未立时的稀释行为——与 `card-kl-037` 的「文化元素要保持纯度」一致）。
- ✗ **不做局外长线/皮肤经济**（属局外系统，先扩局内呈现体量）。

## 7. 证据强度自评

**总评：充分（对「画面上调性/连贯/可读」判断）／有限（对「文本命名纪律」判断）／单薄（对「反馈层」判断）**

| 被判断的字段 | 强度 | 依据 |
|---|---|---|
| 「先找身份、收窄色板、保连贯」 | **充分** | A1（一手访谈）+ A2 + A3 三处独立，方向一致 |
| 「优先连贯性而非单件资产品质」 | 充分 | A3（明说）+ A2（Frankenstein 反例）+ A1（每件资产要像同一套风格） |
| 「泛泛中世纪是首要死因」 | **充分** | C1（棕灰差评）+ C2（「泛泛的中世纪奇幻」判词）+ C4（廉价资产 ×2）+ B1（默认值分析）四处独立，含两份媒体评测 |
| 「调性统一会压迫可读性」 | 充分 | C3（一手辨识失败案例）+ B4（剪影承担可读）+ B7（要在实机光照/速度下验证）三处 |
| 「配色板 + 视觉层级」 | 有限→充分 | A1（收窄色板）+ A3（主/辅色板建层级）两处独立，但均属「方法论共识」，非厂商实测数据 |
| 「diegetic/anchored UI 与规则一致」 | **有限** | A4（方法论，含自造三分法）+ B6（UI 是叙事一部分）+ B7（案例与取舍）三处，但**同属分析视角，缺开发者一手实测**；「打破 UI 测试」是单一来源提出的质检动作，标注为**方法论共识** |
| 「护甲剪影承担职业/威胁可读性」 | 有限 | B4（部分采信，自造术语不采用）+ B5（学术论文的三作对比）+ B7（可读性验证）三处，方向一致但量化标准缺失 |
| 「命名先读得懂再有诗意 / 头衔不需脚注 / 重复耐久」 | **有限（外推）** | 直接出处为 A5（单篇面向 TRPG 的命名方法论）。方向与 `style.guofeng` 的随机名池质检、`card-gd-063`（设定要有功能）互相独立印证，但**「游戏内玩家可见文本」的对照证据缺失**——A5 的「重复耐久」判据是在 TRPG 麦上语境提出的，迁移到单机游戏属**外推**。采信但标注为「方法论共识 + 外推」。 |
| 反馈层（UI 之外的反馈如何「带西幻味」） | **单薄** | 未找到「同一玩法两种西幻化反馈的对照」类来源。仅 A4/B6/B7 给了 diegetic 界面的方向，**反馈层其余部分为空白**。 |
| 具体产能/成本数字（做一套西幻风格要多少人月） | **单薄** | 未检索到可引用的量级来源；本包因此不给成本数字，只在 `defer` 给「不做什么」。 |
| 市场规模 / 题材偏好（哪种西幻子流更卖） | **单薄** | 仅有 C4/C5 的个案评测，**不构成市场判断**。标为「未采信的市场层空白」。 |

**低证据清单（不得作为默认推荐）**：
- 反馈层的一切具体做法 → **单薄，仅给方向，不给默认推荐**；包数据 `presentation.feedback` 须如实标「证据偏薄」。
- 「打破 UI 测试」「anchored UI」这类具体方法 → **有限（方法论共识）**，采信但标注为非厂商实测。
- 命名的「重复耐久」判据 → **有限（外推自 TRPG 语境）**。
- 成本数字、市场规模、子流偏好 → **单薄/空白，不采信**。
- 手游/主机平台上西幻风格的表现 → **无来源，保持为缺口**。

## 8. 没能回答的缺口

1. **「反馈层怎么西幻化」没有可引用的对照证据**。本包只在 diegetic UI 方向上有来源（A4/B6/B7），其余（音效、结算演出、状态反馈的文化重构）**无来源**。`presentation.feedback` 因此必须标低证据、只给方向。
2. **「多少元素算够、多少算堆」没有量化标准**。B1/B2 说惯例既是入口也是囚笼，A1 说先找身份、收窄色板，但**没有一条可量化的界线**说明「差异化到什么程度才既陌生又可读」。本包因此把问题转成可观察的联想测试判据（卡 `card-kl-036`），但**没有阈值**。
3. **中文一手开发者访谈缺失**：中文侧只有 B6 一份设计分析（且偏方法论）。属检索覆盖缺口，非「没有」。
4. **「写实 vs 程式化」的资源分界线没有权威数字**：A2/A3 都说小团队扛不住 PBR，但**没有给出团队规模/预算的分界**。
5. **本包所有判断均来自公开检索与卡片库蒸馏，未经任何真实用户样张测试。** 任何「这个调性会被玩家喜欢」的说法都超出证据范围。
6. **风格包与品类包的交互没有验证**：本包只描述呈现层，**「西幻 × 某个品类」组合后的实际效果无任何来源**，属结构性空白，与所有风格包一致。

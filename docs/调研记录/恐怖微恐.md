# 调研记录：恐怖与微恐治愈（品类包）

- **检索日期**：2026-09-29
- **包标识**：`genre.horror`（`shortTitle` 恐怖）
- **轴**：品类（恐惧作为玩法的规则层）；与已完成的恐怖氛围**风格包**分工：风格包管"不安怎么呈现"，本包管"恐惧怎么当玩法"。

## 六个关键问题

1. 玩家要什么？——校准过的恐惧，不是最大剂量的恐惧（倒 U 曲线实证）。
2. 第一小时该发生什么？——先建日常，再给环境级不安，最后才给真威胁，且首次近距离接触"慢得离谱"。
3. 流派分叉？——资源剥夺 / 追逐躲藏 / 信息剥夺调查 / 微恐治愈（恐惧作对比剂）。
4. 新手死法？——给玩家可靠权力、无对比堆砌、把晦涩当深度、重复消耗恐惧、拖沓、微恐两头不靠。
5. 怎么算对？——弃玩点归类（恐惧型 vs 挫败无聊型）、倒 U 校准、重复衰减测试、喘息兑现、一周记忆点。
6. 第一版暂缓什么？——大世界长流程（≤3 小时）、导演级追逐 AI、多结局、写实画面、理智值可视化、VR。

## 按六问蒸馏（关键判断）

- 恐惧是产品，惊吓是收据；剂量控制权是纯恐与微恐的分水岭（A3/D1/A2，≥3 源同向）。
- 默认节奏：第一段只做"正常"（教学伪装成日常劳动）→ 第一次不安是环境级不是生物级 → 首次真威胁后立刻给平静喘息（D2 结构）。
- 重复尝试会毁掉恐惧——怪物在玩家失败数次后应自行降级或消失（D2，廉价替代导演级 AI）。
- 微恐两头不靠的解法：安全**时间**替代安全**空间**，剂量权在玩家手里（A2/D4）。
- 宁短勿长三面同向：P.T. 三十分钟、Chilla's Art 一小时、Grip 建议三小时内。

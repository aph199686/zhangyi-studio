# 品类与风格调研（2026-09-28）

> 目的：为「下一个完整品类包」和「风格包系列」提供选择依据。素材来自本地知识库（只读）与 `cards/` 观点卡片库；所有判断均为复述，不含原文段落。本文件是调研结论，不代表任何包已开工。

## 一、下一个品类包：候选对比

### 模拟经营 —— 证据充分（约 8/10），建议优先

知识库有两篇在职策划级方法论（Township 全维度拆解、长线模拟游戏目标系统重构）、开罗「上帝模拟 vs 指挥模拟」范式分析、潜水员戴夫多玩法融合拆解，以及至少五篇玩家心理素材（赛博打工、扮演老板、超爽人生、陪伴感等）。能直接支撑品类包全部字段：

- **首局候选**：完成第一个「生产→收获→订单→扩张」最小经济闭环；撑过一次资源紧张；在有限地块上做第一次布局取舍。
- **细化题方向**：指挥模拟还是上帝观察；任务驱动还是玩家自建目标；要不要失败惩罚（品类标杆普遍不设）；装饰与创造比重；生产是否随离线时间自动进行（吸收挂机线索）。
- **验收点**：正反馈速度（行动→反馈线性对应）；引导结束后玩家有自发行为（不打扰观察法）；副系统与主循环数值不脱钩。
- **暂缓项**：仓库付费点、订单算法精调、复杂养成线、社交系统、多玩法缝合、UGC。
- **常见死法（有出处）**：惩罚机制与休闲定位冲突；前期任务过重挤压核心体验；黄金窗口强插副玩法造成留存悬崖（呼应 card-kl-009）；核心空洞只靠创造工具拉新。

### 棋牌博弈 —— 素材充足，可从旧候选升级

雀魂两份产品拆解、杀戮尖塔构筑两篇、Balatro 设计拆解、昆特牌三篇、卡牌数值课（愚者作游）、博弈结构论（明牌暗打、永劫博弈认识论、石头剪刀布纳什均衡）均在库。三个旧首局候选都能挂证据深化：

- 「识破破绽」挂 A→B→C 博弈链框架与不完全信息决策；「押上资源」挂「放弃一轮也是决策」与三选一前置随机；「利用规则反制」挂第三选择破纳什均衡与策略退化判据（card-gd-026）。
- 细化题：算费型 vs 过牌型分流；体系数量由单局选择次数反推（card-gd-030）；前置/后置随机分工。
- 验收点：战前可算清（card-gd-061）；暗牌类改为「不确定性可读」——玩家知道在赌什么、赌注多大。
- 暂缓项：PVP 匹配与 META 治理、暗调随机（card-gd-066 信用不可逆）、付费点、体系扩张。
- 缺口：纯心理博弈/诈唬类无专文；单人牌戏素材薄。若首局定位在「牌局构筑+信息博弈」则素材足够。

### 增量挂机/放置 —— 证据不足（约 5/10），暂不做独立包

有一篇高质量深研（桌面放置十款安利+五条设计原则）和 Cookie Clicker 节奏拆解，能支撑「循环与节奏」判断（休闲感+成长感双支柱、统一货币一套逻辑、爆点时机、机制解锁时刻表）；但**「首局」设计几乎无直接素材**，数值曲线无可操作框架，而首局目标与验收恰是品类包的核心交付。且「放置」更像节奏/结构属性而非独立品类（可与经营、RPG 缝合）——建议先作为经营包内的一道细化题（生产是否离线自动进行），将来补证据（两篇图片版 PDF 需 OCR、缺「idle 第一小时」一手拆解）后再议独立包。

### 品类需求背景（哪些新手最需要陪练）

- 离散机制品类（回合制、卡牌）技术风险最低，适合资源有限团队（card-gd-034）；连续机制（动作、射击）死法最贵且陪练能拦截的最少，更适合立项阶段劝退或降级。
- 肉鸽/DBG 证据最厚：低成本高留存适合小团队，痛点清单（失控感、沉没成本、build 不可臆想、难度曲线吞反馈）正是陪练可逐条拦截的。战棋（已做）与棋牌都在这个证据厚地带。
- 模拟经营/治愈系有趋势信号（微恐治愈、赛博打工），新手痛点在目标系统与节奏，不是技术。
- 新手团队通用纪律已有卡：小项目练手循环（card-kl-001/002）、核心玩法先及格再扩展（死亡细胞模块化）。

### 结论建议

**下一个完整品类包做「模拟经营」**（补全既有 `management` 轴，改动面小，证据最足）；棋牌升级紧随其后（素材已够，工作主要是把证据接进包结构）；挂机不做独立包，其线索并入经营包细化题。

## 二、风格包系列：素材厚度与建议顺序

> **进度更新（2026-09-28）**：第一梯队四包 + 蒸汽朋克/柴油朋克**已全部落地**（`style.guofeng` / `style.anime` / `style.western-fantasy` / `style.cyberpunk` / `style.steampunk`）。**在制第二梯队四个**：治愈系/cozy、像素/复古、恐怖氛围、硬科幻/太空——素材厚度普遍低于第一梯队，**均以网络检索为主、卡片库补充为辅**（卡片库对这四个主题命中稀疏：cozy 多为关键词巧合、像素 3 张、恐怖偏氛围不涉设计、硬科幻 5 张）。素材有效密度排序：**古风 > 日式幻想 > 西幻 > 赛博朋克**（第一梯队）；第二梯队实测均需外补，其中**硬科幻/太空最薄、恐怖氛围次薄**。所有包只填 presentation.visual / text / feedback 三槽 ＋ verification，不定胜负规则。

### 治愈系/cozy（第二梯队，需大量外补）

- 决定性的概念证据集中在「cozy 是什么」而非「cozy 游戏怎么做」（后者高度主观、来源多自承不设定义）。
- 可采信的一手/近一手方向：北欧 hygge（Lindé 2015：离家也像在家的理想化感受）；**对比生成 cozy**（安静咖啡馆 vs 门外闹市）；**匿名共处**的可读与不裹挟之平衡；**cozy ⊂ wholesome**（GDC 2023 一手：wholesome 可温和触及不 cozy 的题材，cozy 仅是一种感受）；**cozy 不是无挑战、是低压力**（太难即挫败、真钱交易摧毁 cozy 感、关系破裂深度劝退、不更新变单调）。
- 反模式清单可直接入核验：能量系统、FOMO 限时、付费墙、侵略性推送、PvP 恶意、强制维护责任、胁迫社交、欺骗背叛、炫富刻意感。
- **市场反例是关键**：「cozy 已僵化，多归因星露谷」的同质化批评 ＋ 一手开发者反叛信号（Grave Seasons 凶杀农场、Moonlight Peaks 毒性家庭/派系撕裂）→ **画风治愈不构成卖点**。
- 预期：**画面层充分、文本层有限、反馈层单薄**（如实标注，不得用常识填充）。

### 像素/复古（第二梯队，偏技术表现）

- 卡库命中 3 张，16-bit 漫谈系列在库。核心是**受限调色板下的可读性纪律**（色数预算、抖动、格点对齐、整数缩放）。
- 须在边界里划清：**复古 ≠ 像素**——CRT 扫描线/辉光/色偏属年代感另一条线；**像素是呈现技术层风格，可叠加任一题材**，本包不管题材。
- 与二次元（程式化夸张）、古风（文化联想）划界。

### 恐怖氛围（第二梯队，只做呈现层）

- **与恐怖品类包分开**：本包只管「怎么做 unsettling 的呈现」，不管追逐/解谜/资源管理玩法。
- 可采信方向：恐惧来自**预期而非画面**（jump scare 廉价、用多脱敏）；安全区/危险区对比与视野限制（手电/雾/门框）；声音为氛围主干（**此层须补一手来源，不得凭常识断言**）。
- 与治愈系交界（creepy-cozy）须在边界讲清归属。

### 硬科幻/太空（第二梯队，素材最薄）

- 卡库仅 5 张。核心技术判据：**技术可推演**（能追溯「为什么这样造」，无来源则标低证据）；尺度可视化与功能主义美学（NASA punk / 工业实用主义 vs 星战式浪漫科幻）；冷光与仪表化 UI 语域。
- 与蒸汽朋克（黄铜/蒸汽）、赛博朋克（霓虹/义体）在材质与年代上划界。
- **纪律**：若一手来源凑不齐，**降级为候选或明确标单薄**，不得为凑数硬做。

### 古风（最厚，先验证风格包契约）

- 素材：武侠市场研究（71 页）、宋朝文化考究、国潮游戏研究（58 页）、仙侠出海访谈（哥伦布 36 期）、封神日本认知、中国题材出海三关。
- visual：武侠/仙侠双元素谱系分档（年轻层边界更模糊）；侠客高认同气质关键词；出海版角色真实感（伤痕汗渍）与辨识度纪律（跨种族效应 card-ur-037）；时代自洽红线；国潮子模块=六维混搭+三种病灶（国而不潮/潮而不国/不国不潮）+联想测试（card-kl-036）。
- text：侠义内核的普世化转译（找对方等价物）；单线叙事与开场三问（card-ur-032）；世界观可信度清单；意译命名与读音设计；文化符号硬菜提前上（card-ur-038）；传统文化「翻译不搬运」（card-kl-068）。
- feedback：轻功位移是风格签名反馈；动作打击感是比较优势；水墨 UI 动效标低证据。通用底座补充。
- 已有卡片：ur-029/037/038、kl-021/022/036/037/038、kl-068、ns-047/065/066/096/097 等，现成率最高。

### 日式幻想

- 素材：日美出海题材叙事研究、突破次元壁（御宅需求链）、哥伦布 3/4/6 期、暗喻幻想 UI GDC、JRPG 文化内核；二次元市场与厨力研究已卡片化。
- visual：角色中心同心圆+萌要素数据库（card-ur-073）；纤细幼态谱系；日系 UI 密度与色彩规范（「杂乱感」非缺陷）；UI 即叙事四验收词；出海未成年外观红线（card-ur-025）。
- text：羁绊/集体内核（对照欧美个人英雄）；情感落点个人化；语气口癖本地化按重写备预算（card-ur-030/031）；触点密度胜设定篇幅（card-ur-055）；长文本节奏冲突的碎片化调和。
- feedback：按钮色彩可发现性；成长持续可见化；剧情代入优先；情感演出型战斗 UI。
- 缺口：「异世界/剑与魔法」细分的专门研究薄。

### 西幻

- 素材：欧美玩家眼中的西方魔幻（哥伦布 5 期全文）、日美研究欧美半侧、奇幻中世纪设定考、普拉切特谈奇幻、Kurvitz 世界构建。
- visual：中西识别标准不同——国内看外在元素、欧美看内核（card-ur-023）；准中世纪公约数；职业视觉原型链；写实重量感；面向国内可适度明亮化。
- text：世界观自洽清单（地区/种族/信仰/魔法规则）；魔法必须有规则；警惕 EFP；史诗英雄+YA 成长母题；欧美偏「反抗社会不公的普通人主角」；政治正确是不对称题（card-ns-060）。
- feedback：动作化反站桩是经验证的空白机会；法系演出华丽度签名；其余借通用底座，**此层证据薄需如实标注**。
- 已有卡片较少，是卡片库相对薄区。

### 赛博朋克（最后做，先补证据）

- 素材：低生活九维度清单、边缘行者指南（风格三规则+黑话职业）、夜之城设计分析、2077 UI 开发、酒保行动对白创作。篇数多但结构失衡：设定考据厚，表现层与市场研究薄。
- visual：「高科技，低生活」对位清单（九民生维度）；城市空间层级与区域「世界内功能」；世界空间 UI（广告/路牌/屏幕即环境叙事）。
- text：腔调三规则（风格重于实质/态度决定一切/活在边缘）；黑话职业词汇库；反权威+技术悲观+科技伦理；欲望驱动对白；情感的迸溅式表达。
- feedback：义体代价/故障风险反馈、操作即叙事（调酒模式）、环境反应层——**整体标证据不足**。
- 卡片库几乎空白（仅 card-kl-047 用 2077 做营销案例）。

## 四、证据缺口登记

1. 挂机「第一小时」与数值曲线：无一手拆解；两篇图片版 PDF 待 OCR。
2. 棋牌：纯心理博弈/诈唬、单人牌戏无专文。
3. 赛博朋克：市场定量研究、操作反馈层、本地化雷区均缺；边缘行者指南未读篇目可先内部消化。
4. 西幻 feedback 层、古风 UI 动效层证据薄，包内需如实标注。
5. 模拟经营缺「新手开发者真实失败案例」，成功产品素材需降维到第一版尺度。
6. 跨文化证据集中美/日/欧，东南亚薄，韩/中东/拉美空白。
7. 库存未穷尽：原神地图研究、服饰偏好、沉浸感、武侠剩余章节可按需回读。

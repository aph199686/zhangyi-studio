# 接力反模式清单（这些写法会翻车）

1. **一次丢 14 条任务**："这些 bug 你都修一下"——任务量超过单轮承受力，
   是上下文爆炸与会话崩盘的头号诱因。→ 拆批，2~3 条一批。
2. **依赖记忆**："我们上次说到……"——新会话里没有任何上次记录。
   → 给一行上下文锚点或直接粘上次结论。
3. **状态写死不核验**："当前版本 vX 就绪"而实际不是。
   → 把核验写成会话的第一步任务。
4. **只给禁止不给路径**："不要乱动"而不说"想动时怎么办"。
   → 助手要么卡死要么硬闯，出事后才告知。
5. **红线不具体**："注意别删错东西"——模糊禁令等于没有。
   → 具体到路径/类目。
6. **开场白即施工令**：没有"先熟悉、先核验、先出计划"的闸门。
   → 直接开改，改错范围才被发现。
7. **版本号/文档多重来源**：正文、交接词、状态文件各说各话。
   → 明确唯一来源，其余都是"待同步"。

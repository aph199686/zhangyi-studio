## card-gd-010 · 死亡惩罚可以被改造成叙事推进器——让每次死亡触发……

- **论点**：死亡惩罚可以被改造成叙事推进器——让每次死亡触发新的对话、线索和人物关系变化，玩家就不再回避死亡，甚至会主动赴死换取剧情。
- **场景**：叙事 / 叙事结构
- **批注**：哈迪斯的做法。前提是世界观能自洽解释"为什么死了能回来、回来还有新鲜事"，这是设定先行的工作，不是机制贴皮。对非循环结构的游戏迁移成本很高，但"枢纽区域随失败次数持续变化"这一点可以单独拆出来用。
- **出处**：[《死亡并非惩罚，而是重生 ——《哈迪斯》死亡机制深度解析》](https://www.gcores.com/articles/208922) · 机核 · 2025-12-26

## card-gd-049 · 区域开图锚点（神像、传送枢纽这类解锁点）摆在哪，……

- **论点**：区域开图锚点（神像、传送枢纽这类解锁点）摆在哪，等于替玩家选定了探索方向：放在区域中心，玩家由内向外辐射式开图；放在边角，玩家由外向内层层深入。这个落位应该按区域的叙事调性决定，而不是默认居中——一个闭关锁国、气氛诡谲的地方，把入口放到边角，让玩家从边缘往腹地钻，动线本身就在讲这个地方的性格。
- **场景**：机制 / 叙事 / 信息设计 / 叙事结构
- **批注**：杠杆极高：挪一个锚点就改了整片区域的动线与情绪，不动地形、不加内容，成本几乎为零。与 gd-038 分工清楚——那张管单个地标在一趟旅程里的可见节奏（远眺、遮挡、重现），这张管地标在全区域尺度上的落位。反面约束必须写死：中心式布局在新手区是对的（主城居中、四面环水外圈抱山、绝大多数传送点都能望见主城，安全感就是这么造出来的），边角入口只适用于要神秘感和压迫感的成熟区域，用在新手区等于亲手砸掉安全感。附带成本常被忽略：由外向内意味着玩家最先看到的是区域边缘，边缘景观必须撑得住第一印象，否则整片区域的口碑从入口就开始掉分——原文里那片地底区域的做法是先用一条强制收窄的单线通道压住，再豁然开朗地放开，用反差兑现第一印象。
- **出处**：《原神地图设计研究》（（内部资料·脱敏）） · 个人知识库 · 2022

## card-gd-053 · BOSS 战的转场演出不是奖励性插曲，它的职能是……

- **论点**：BOSS 战的转场演出不是奖励性插曲，它的职能是给难度上升发合法性证书：先用 BOSS 的台词与动作承认玩家上一阶段的战果（它暂且不敌），再让它通过某个看得见的手段获得强化、为下一阶段提供更强的前提，最后用特写强化变强观感并把镜头交还默认战斗视角。缺这层包装，阶段数值跳升会被玩家体验成作弊而不是压迫感升级。
- **场景**：叙事 / 机制 / 难度曲线 / 叙事结构
- **批注**：玩家先小胜、敌方再寻求强化、然后继续战斗，是主流大作转场演出的通用三段（《审判之眼》最终战是干净样本），可直接当验收问题用：这一段有没有说清 BOSS 为什么变强？与 gd-004 同构——惩罚要可归因，难度上升同样要可归因，而归因的载体就是演出。与 gd-024 分工清楚：那张管阶段用什么触发（血线还是时间轴），这张管触发之后那几十秒演什么。省力做法是把转场和场景更替绑定（换整块场地，或保留战场形状只改细节），场地更换是缓解战斗视觉疲劳最直观的手段。但长转场要剥夺操作权，多人副本里与不能有人站着看戏冲突，复用时要换包装形式——把转场做成需要全员参与的机制就是这一冲突的成熟解（FF14 的全员连坐式 QTE、按职能分工的拼刀 QTE，后者还顺带把 QTE 变成职能身份的高光时刻）。补社区测量口径（对公开产品的可复现测量）：普通阶段数分钟量级、最终阶段占整场四到五成、转场动画数十秒。
- **出处**：《战斗场面感研究》（（内部资料·脱敏）） · 个人知识库 · 2022-04

## card-gd-055 · 激发"想走进这个场景"的开关，是玩家当场在脑内预……

- **论点**：激发"想走进这个场景"的开关，是玩家当场在脑内预演"我会在里面做什么"，而不是素材精度：小型动态元素（扑棱翅膀的鹤、雪地上的车轮印、随风晃动的灯笼）给出场景可交互的承诺，神秘与留白让玩家脑补出读不透的后续故事。这两者能让体验意愿与品质评分脱钩——测试中氛围神秘感强的场景品质不及竞品，反而被玩家列为最想体验、印象最持久的那个；素材丰富但一动不动、没有视觉中心的场景，反被评为"元素太多分散注意力"。落地清单：每个重点场景配一个可描述的核心视觉点、至少一个动态交互元素、一个留白钩子；回访时玩家的记忆句式稳定为"核心视觉点+相应的感受"，这就是自传播的最小单位。
- **场景**：机制 / 叙事 / 玩家动机 / 体验节奏
- **批注**：证据语境是宣传片/场景视频测试，玩家仅凭画面就产生下载与体验意愿，因此结论同样适用于 PV 分镜与商店页素材的场景选取。与既有卡的关系："环境叙事三层"卡认定氛围式是最耐久的记忆层，本卡在欲望侧补了一环——氛围不止被记住，还直接转化为"想去"；"核心视觉标志三条件"卡强调标志与故事强关联，本卡强调可描述性与动态性，两者可合并成场景自检 checklist。留白钩子有兑现义务：玩家脑补的神秘若在游戏内永不回收，会转化为落差感（与"叙事诡计的伏笔必须回收"同理）。附加发现：与游戏内高频行为（BOSS 战前、门派日常、大世界探索）语义相关的场景最容易激发联想，场景的功能标签应该让玩家一眼读出"这里会发生什么"。
- **出处**：《什么样的场景能激发玩家的体验欲望（场景美术品质感知研究）》（（内部资料·脱敏）） · 个人知识库 · 2021

## card-gd-056 · 世界观规则要'生效'才产生代入感：设定集里逻辑自……

- **论点**：世界观规则要'生效'才产生代入感：设定集里逻辑自洽只是及格线，规则必须在三类交互中产生看得见的后果——在物体上生效（火能灼烧怪物也能烹饪食物）、在环境中生效（同一团火夜里提供照明、能融化冰雪）、在人物上生效（玩家对甲的行为间接改变乙对你的态度，NPC 之间还会自发结怨结交）。且玩家可操控、可影响世界走向的规则维度越多，自由度和沉浸感越强；判断一个世界'活不活'，看规则生效的维度数，不看设定集的厚度。
- **场景**：机制 / 叙事 / 叙事结构
- **批注**：与'可信的世界有验收标准'（细节一致性、每个偶然追问不落空）一卡互补而不重复：那张管静态一致，这张管动态生效——两者可以单独失守，考据扎实但世界对玩家行为毫无反应，和规则反馈充分但美术穿帮，是两种不同的沉浸破产。成本要诚实标注：人物层生效（动态 NPC 关系网）的实现成本远高于物体层和环境层，小团队应优先做前两层，人物层可用简单的态度数值模拟出'行为有后果'的感觉。'维度越多越强'是报告的单向论断，它没讨论成本面——规则维度失控同样是 bug 温床和平衡性灾难（涌现式玩法的调试成本随维度数超线性增长），这条边界是我补的反对意见。
- **出处**：《游戏沉浸感研究（SCI模型评估与设计案例）》（（内部资料·脱敏）） · 个人知识库 · 2019

## card-gd-057 · UI 消不掉时，把 UI 当世界观的承载物来做，……

- **论点**：UI 消不掉时，把 UI 当世界观的承载物来做，按三级优先处理：一级隐藏——非必须时刻不出现，仅在可交互时给提示（生命值做进角色背后的能量条、弹药只在抬枪时显示）；二级场景化——让场景内物品承担 UI 功能（成就收集系统做成书房里的实物陈列、商城做成可翻阅的商品画册），拉近玩家与场景的距离；三级风格化——界面整体风格向题材基调靠拢，做成产品的记忆点（女神异闻录5 的黑白红动感 UI 本身成为游戏标志；明日方舟用'神经连接系统'的叙事包装整个主界面，玩家操作 UI 的动作同时是在扮演角色）。功能复杂、无法隐藏也无法完全场景化的手游大多只能做第三级——那正是最该投设计资源的地方。
- **场景**：机制 / 叙事 / 信息设计
- **批注**：与'HUD 信息密度由操作负担决定'一卡分工明确：那张管放多少信息（动作游戏减 HUD、策略游戏堆信息），这张管信息以什么面目出现，两张不冲突，高信息密度界面同样可以做风格化。边界要写清：二级场景化牺牲可发现性和操作效率，重功能界面硬做场景化反而抬高认知负荷，所以三级是优先序不是信仰；三级风格化有执行门槛——风格必须与主题同源才成立（P5 的 UI 就是'青春对抗成人世界'主题本身），否则只是贴皮滤镜。报告还给了一个反向标杆：最沉浸的设计是无 UI，但'无 UI'在绝大多数商业游戏里不可实现，把它当上限参考而非目标。
- **出处**：《游戏沉浸感研究（SCI模型评估与设计案例）》（（内部资料·脱敏）） · 个人知识库 · 2019

## card-gd-062 · 网游剧情/任务系统的服务端权限要收敛到'这段进度……

- **论点**：网游剧情/任务系统的服务端权限要收敛到'这段进度完成没有'这一个问题上：剧情事件先按是否承载玩家进度状态分两类——镜头、特效、动画这类纯表现事件只在客户端执行，不存档、断线重连也不回填；功能解锁、入口开放这类进度事件由服务端权威、入库存档、每次登录同步。单人体验的支线副本更进一步放权：全部逻辑跑在客户端，服务端只管发起和完成记录；失败重试不做状态重置机制，直接让玩家重新进入副本。这一刀权限同时买到四样东西：断线重连时剧情流程不中断、弱网下的重复触发可合并对账、玩家流量与服务器开房成本下降、策划省掉一整层'重置事件'的配置工作。
- **场景**：机制 / 叙事 / 团队协作
- **批注**：放权的前提必须写死：被放权的全是 PVE、单人体验、作弊收益低的剧情内容——竞技结算或付费内容不能这样放权，隐含的交易是接受客户端逻辑可被篡改的可能性，换成本与体验流畅。'重进代替重置'比本案例更通用：能从零重启的内容，优先丢弃重建而不是原地修复——重置逻辑要枚举全部状态变量，是 bug 和配置表的温床，重建天然干净。配套细节值得抄：任务内指引做成非强制、非阻断的软检查（玩家操作某 UI 时才检查该 UI 是否处于当前剧情流程内，是则弹指引），而剧情任务本身线性、必须执行、不可中途跳过——硬约束放在任务进度上，软约束放在指引表现上，别反过来。
- **出处**：《第五人格剧情系统实现》（（内部资料·脱敏）） · 个人知识库 · 2021

## card-gd-063 · 世界观设定不是氛围装饰清单，而是玩法结构的解释书……

- **论点**：世界观设定不是氛围装饰清单，而是玩法结构的解释书：每条设定都该能回答一个具体的功能性疑问。第五人格的设定几乎全是这么推出来的——「反复翻阅日记、用演绎法还原旧案」同时解释了对局为什么能无限重复、玩家为什么能反复更换阵营；侦探身份给了主角反复阅读记录的动机；前推理小说家给幕后黑手举办庄园狂欢提供了动机；人格分裂解释了为什么所有玩家在同一个世界查同一件案子还能彼此联系；失忆桥段让玩家以为自己与主角信息对称（原文自承这是一种假象）；把时代定在维多利亚，理由甚至是压低通信与信息传播水平，好让世界同时容得下科学与神秘。验收动作很便宜：给设定集里每一条写一行「它解释了什么」，答不出功能问题的条目要么删掉，要么明确降级为装饰与彩蛋。
- **场景**：立项 / 叙事 / 叙事结构 / 核心循环
- **批注**：推理链的上游是一张约束清单：把不可让步的目标（恐怖题材的恐惧与紧张感、非对称对抗的差异化乐趣、题材受众稳定诉求集中且当时市面缺少同类产品）与不可改变的现状（移动端机能有限、触控精度不如键鼠、玩家游玩环境不可控因而声音传达极不稳、题材审核排斥写实血腥）并排列开，结论是核心情绪很可能被现状吃光。此时的动作不是下调情绪目标，而是换传达通道——从依赖视听精度的感官刺激转向心理恐惧与悬疑，参照物是寂静岭初代用浓雾回避机能限制、反而把限制熬成了系列标志。与 ns-002（世界设定三问）分工清楚：那张管开工前问什么，这张管写完之后逐条怎么验收；与 gd-056（规则要生效）也不重复：那张管规则对玩家行为有没有反应，这张管设定对玩法结构有没有解释力，两者可以各自单独失守。反对意见要认：并非每条设定都必须承重，纯氛围条目和彩蛋容器有独立价值——日记载体被明确当作方便后续自由插入各种经典恐怖题材彩蛋的可塑性容器，纪律是区分承重设定与装饰设定，而不是要求全部承重。另一个真实代价：功能先行的设定容易露出工具感，玩家会读出这是为了圆玩法编的；解法是让功能答案与文化直觉重合——失忆、人格分裂、深山庄园、维多利亚侦探都是现成的类型桥段，受众早已接受，解释玩法的同时不显得刻意。
- **出处**：《第五人格的设计推演之路》（（内部资料·脱敏）） · 个人知识库 · 2019

## card-gd-064 · 上线后新增的活动与功能几乎必然和既有世界观脱节，……

- **论点**：上线后新增的活动与功能几乎必然和既有世界观脱节，正确动作不是改设定去接——已公布的设定被推翻对剧情向玩家是伤害，而叙事内容的产能也追不上运营开发周期。可行解是把需求解构成「行为内核 + 文化内核」两层，再到世界观规范里推理出等价物：许愿这个行为放进十九世纪欧洲就是许愿池，七夕这个时间点借织女星即天琴座主星这一天文常量搭桥，春节联欢晚会对应到古希腊酒神节里不分阶级人人可参与的戏剧评选大赛。更关键的是，推理到位时它不只是贴皮，会反哺需求本身——第五人格的万圣节活动把点击开箱重构成连续点击模拟敲门讨糖，低频的冗余操作配上音效动效反而做出情境感；春节活动把抽奖的五个环节映射成搭台、安排演员、彩排、正式演出、评选之后，为剧中角色挑选扮演者这一步顺手补上了原需求最缺的玩家自主性。所以包装推理要过两道验收：在世界观里说得通，以及原需求里本来不好玩的那一点被推理顺手修掉了。
- **场景**：收尾 / 叙事 / 叙事结构 / 信息设计
- **批注**：四个节日活动案例（七夕、万圣节、春节、暑期花园解谜）走的是同一条链——提取节日关键词、在世界观里找对应行为、用场景物件当界面载体——跨案例收敛，方法可信度比单案例高。搭桥物有优先级：自然与天文常量最稳（日月星辰不受文化差异影响），其次是双方文化里都存在的行为形态（全民可参与的评选演出），最差是直接搬对方的文化符号（把春晚舞台放进欧洲庄园会当场穿帮）。成本结构值得单独记：这套推理把叙事产能压到界面文案级别，比新写设定便宜一个量级，是没有专职文案产能的小团队在运营期的现实解。反面风险是我补的：推理链条一长就只剩设计师自己看得懂，酒神节戏剧评选这一步必须解释才成立；节日活动的大众可读性优先于考据优雅，玩家一眼读出这是在过节比这符合世界观更重要，链条最好压在一跳以内。与 gd-057（UI 当世界观承载物）同族但管不同时间轴：那张管首发界面怎么入世，这张管上线之后源源不断的新需求怎么入世。与 ns-033（每个系统配一句剧情理由）是同一纪律的两档：那张是最低配的一句话包装，这张是带需求重构的完整推理。

## card-gd-070 · 镜头代入感不是一根'画质够不够好、特效够不够炫'……

- **论点**：镜头代入感不是一根'画质够不够好、特效够不够炫'的单一滑杆。按镜头传递的信息类型分两类，验收标准完全不同：观察类镜头（提供游戏基础信息、服务探索与操作）追求的是认知上的真实，即画面给出的信息是否符合玩家对这个世界的认知，这一侧最基础的杠杆就是镜头跟随移动本身（配合第一/三人称把目标强化出来），特效在观察侧只做按场景风格匹配的蒙版处理，不承担视觉刺激的职能；表现类镜头（技能演出等）追求的是逻辑上的真实，判据不是华丽度而是因果链在镜头里是否成立——特效释放源必须落在镜头目标区域内且清晰可见、特效以释放源为核心向外延展、作用对象清晰可见且产生效果后有受击表现，释放源、作用对象、特效本身三者缺一件，玩家就读不出'谁放的、打到了谁、发生了什么'。所以收到'镜头没代入感'这类反馈要先分诊：观察侧去修信息与跟随，表现侧去修因果可见性，给表现侧加特效量对逻辑断裂无效。
- **场景**：机制 / 叙事 / 信息设计 / 体验节奏
- **批注**：证据来自镜头基础研究的代入感分类章，表现侧的落地做法另有五款公开发行动作游戏（龙之谷、剑灵、洛奇等）的镜头特效规则整理做交叉支撑，共性明显。边界与反对意见：（1）两类镜头经常叠在同一帧里（战斗中一边跟随一边放技能），分诊问的是'哪一侧的验收标准被违反了'，不是把镜头拆成两个系统做。（2）表现侧的逻辑真实不等于写实——卡通渲染、像素风同样要求释放源/作用对象/特效三者在镜头里可读，风格化改的是质感，不是因果。（3）与 card-gd-051（打击感的视听预算不对称：攻击特效做减法、受击特效做加法）是同一诊断的两层，那张管粒子在屏幕上占多少，这张管摄像机有没有把因果拍清楚；实操顺序是先过这张（因果可读）再过 gd-051（预算分配），反过来会出现'特效很克制但看不出打没打到'。（4）与 card-gd-052（默认镜头是可测指标）分工明确：那张管静止状态下的取景远近，这张管镜头传的信息类型。（5）迁移成本不对称：观察侧近乎零成本（跟随移动加场景蒙版），表现侧要求技能有明确的判定时间轴，没有判定帧数据的纯表现型产品（音游、放置类）迁移价值很低。
- **出处**：《《游戏摄像机与镜头基础研究》》（（内部资料·脱敏）） · 个人知识库

## card-gd-073 · 打开界面、切换地图这类功能性跳转的硬切是代入感的……

- **论点**：打开界面、切换地图这类功能性跳转的硬切是代入感的断点；解法不是把界面画得更像世界里的物件，而是让镜头先做一次真实的空间位移把玩家『送过去』——跳转因此从『画面被换掉』变成『我走过去看』，玩家的注意力全程没有离开世界。施工要点三条：位移途中把主角透明化，免得角色本身挡住目标物；帧预算大致前六成给镜头推进、后四成给界面动效补全，两段连续播放才不像卡顿；地图与区域转移按『玩家还剩多少操作权』分三档（Loading 加进场动作 → 播放转移动画但允许调整观景视角 → 全程可手动控制镜头与动作），档位越高越贵也越不断线，而狭小通道这类本来就该慢下来的转移，是买高档最划算的地方。

- **批注**：与 gd-057 分工清楚：那张给 UI 沉浸的三级形态（隐藏／场景化／风格化），这张管把玩家送进那个形态的过渡动作——静态界面做得再场景化，若仍用硬切打开，收益会被断点吃掉一截。适用前提必须写死：手法只在『界面在世界里有对应实体』时成立（任务公告板、地图桌、货架、营地），找不到实体的界面（设置、邮件、充值）硬配运镜只会拖慢操作，正是 gd-057 说的二级牺牲可发现性与效率；可执行的筛查动作是把界面清单过一遍，逐个问『它的世界实体是什么』，答不上来的直接放弃场景化。频率闸门：镜头推进段是纯表演时间，高频开关的界面（背包、技能栏）不适合，留给低频且有仪式感的入口，否则玩家第三次开背包就开始嫌慢。证据强度：帧数与分段比例来自对公开游戏的摄像机反求估算（公开产品无官方参数），量级与『推进在前、补全在后』的顺序可用，精确帧数别当验收标准。观察样本是两个把这套做到底的公开产品：《怪物猎人》系列把任务公告板、地图、进出营地、用餐全部走镜头推进加淡入淡出，连爬隧道这种狭小转移也保留手动控制的镜头；《荒野大镖客 2》把商店做成能从货架上直接取物、菜单只是备选的快速浏览方式。与『死时间要填内容』的思路（加载页放角色漫画）是两条并行解：那条掩盖等待，这条取消等待的观感，成本更高的这条只在跳转本身算体验的一部分时才值得。与 gd-070 分工：那张管实时镜头的代入感分诊（观察/表现两类），这张管界面与地图跳转这一特例断点；与 ns-070/ns-071 分工：那两张管前期分镜与景别职务，本卡管运行时实现。

## card-kl-028 · "我在故事里是谁"（自我寄托）是内容向品类里被系……

- **论点**："我在故事里是谁"（自我寄托）是内容向品类里被系统性做废的需求维度：用户偏好自己是作品的核心角色、或与核心角色有重要联系，但大量产品把玩家放在"第一人称却无人格"或"第三人称旁观者"的位置上——只给一个身份称谓，不给能动性，主线剧情与玩家名义上的身份毫无关系，代入感自然是零。这一维还是立项期的不可逆决策：主线一旦按"玩家不在场"写死，后期要补主角代入就只能新开一条剧情线、让玩家以另一个身份重新加入，旧剧情无法回头改。

- **批注**：补救有两条现成路径。一是让主角本身有故事、可操控、可养成——《碧蓝幻想》让玩家扮演的主角带三名可替换队友，装备系统为主角特有、队友只吃加成，用系统把"我是核心"做实而不只是用台词说。二是玩家不上场，但给一个在世界观里说得通的功能性身份（例如设定为能激发角色隐藏能力的人），让故事的悬念和谜团围绕玩家展开——关键是"合理化"，不是加戏。反面教材是硬塞：《崩坏3》早期剧情与玩家扮演的主角毫无关系，中期让角色突然与玩家身份互动，因毫无铺垫而显得刻意，最终只能靠新开剧情线（玩家可操控一个新身份角色）补救，等于承认旧主线作废。还有一条零成本的校准动作：去社区看玩家实际怎么称呼角色——《闪耀暖暖》官方把玩家定位成同辈伙伴，女性玩家却普遍把角色当"女儿"、自称"妈妈"，官方定位与玩家自发认领的关系位错位本身就是机会点；判据是"与现实情感需求越相近，越容易形成自我想象"。与 ur-032（开场三问"我在哪我是谁我要做什么"）不是一回事：那张管开场信息交代得清不清楚，这张管玩家在整个叙事结构里有没有位置和行动权——开场把"你是谁"讲清楚，仍可能讲的是"你是个旁观者"。适用边界：强内容、强角色驱动的品类成立度最高；纯竞技或纯策略品类里玩家本来不期待叙事身份，硬加强主角会挤占玩法资源。

## card-ns-087 · 想让角色在玩家记忆里留下烙印，机制是让他失去而不……

- **论点**：想让角色在玩家记忆里留下烙印，机制是让他失去而不是让他得到——人只对已经失去的东西持续估值，所以要造记忆点就得让玩家真的丢掉点什么。而丢掉必须是不可逆的才有重量，这直接推出一条反主流的约束：结局的发散度要收着做。多结局恰恰把失去变成了可逆（换条线读个档，死掉的人还在），代价有两层——悲剧的重量被消解，角色印象也互相抵消（同一个角色上一周目痛哭流涕、下一周目欢声笑语，玩家最后记不清他是谁）。所以角色的核心命运应当是注定的，自由度给过程（怎么走、怎么表态、谁陪在身边），不给终点（他最终是谁、落在什么下场）；设计师要的是清晰而深刻的人物认知，不是模棱两可。

## card-ns-088 · 角色内心的剧烈波动最好交给一个无台词的身体细节去……

- **论点**：角色内心的剧烈波动最好交给一个无台词的身体细节去承载，而不是写成台词：一记攥紧的拳、一次俯身安抚倒下的坐骑再颤抖着夺走它的力量——全程零台词，玩家照样读出了不舍与愤怒。由此得出一条产能纪律：对白量与角色塑造质量不成正比，过量时甚至成反比。对白极少的魂系作品里，玩家靠细节反推出 BOSS 的背景与经历，自发形成了考据社群；反过来，很多手游把角色对白写得又长又多，效果是出戏和累赘。验收方法很便宜：把这段的台词全部消音，看观众还能不能读懂情绪——读不懂，就说明台词一直在替演出打补丁。
- **场景**：叙事 / 角色塑造 / 信息设计 / 体验节奏
- **批注**：与 ns-005 的分工要切清：那张的载体是场景里的物件（成对的戒指、往来信件），靠玩家主动翻找与联想拼出故事，属环境叙事，可以被错过；本条的载体是角色自己的身体（微表情、动作），在演出瞬间被直接看到，不需要玩家去搜。两者可叠用，但产能账完全不同——物件是关卡与文案的活，身体细节是动画与演出的活。小团队最常犯的错正是拿堆对白去补动画预算的不足，方向补反了。
ns-024（AVG 演出的核心是视线与心理管理，让观众不看台词也读懂心理）是同一条原理在静态资源媒介上的版本，本条是 3D 与动画媒介上的版本，共用上面那个消音验收问题。

## card-ns-089 · 角色驱动的产品里，人设是唯一能拿来抵系统债的资产……

- **论点**：角色驱动的产品里，人设是唯一能拿来抵系统债的资产，而且这个方向不可逆：玩家会为一流的主角人设容忍糟糕的关卡、平庸的养成和不合理的怪物数值（《尼尔：机械纪元》是常被举的例子——开放世界与养成被普遍诟病，销量与知名度却不受影响），但没有玩家会为一流的开放世界去容忍一个无感的角色。所以立项时一旦判定产品属于角色驱动，人设的投入优先级应当排在系统完善度之前。前提是认清这里的人设是一个复合体：造型、动作设计、演出、音乐全在里面——只把设定文档写厚，不构成任何对冲资产。

与 ur-039（外在只是及格线，差异化押内在）有一处需要辨明的张力：ur-039 管单个角色内部的资源分配，警告别把差异化预算全砸在服装长相上；本条管产品层面的资产对冲，而对冲资产恰恰包含 ur-039 判为及格线的外在层——那个白色短发、黑色短裙的造型本身就是最强的传播物与同人素材。两者不矛盾：ur-039 回答怎么让角色被喜欢，本条回答怎么让产品被记住和被谈论，后者对外在的依赖明显更高。

## card-ns-091 · 概念层的原型二创要同时满足两条互相拉扯的约束：一……

- **论点**：概念层的原型二创要同时满足两条互相拉扯的约束：一是可考据——认领一个已有的人物或文化原型，白拿大众认知与信服度，也给后续拓展留好接口；二是不走寻常路——原型一旦被抛出，大部分人能想到的那个方案就已经注定平庸。两条不矛盾的解法是换取材坐标：不在原型的本体属性上做加法（火焰妖怪就把浑身画满火），而是去原型传说里'它出现时的场面'取画面。素材里的实例是把一则海上怪火传说做成一名在海面舞台上演唱的歌姬，千帆点灯聚拢的景象复现了传说中接天连海的火光，再让'名字本身也是一种咒'把歌姬与大妖怪合成一人——考据红利来自场面的还原，不俗来自本体的置换。

- **论点**：角色塑造拆成三层才好施工：内在（性格、思想、喜好）、外在（身份地位、成长环境、当下处境——这一层不是长相，而是角色所处的那个世界）、行为（做什么、说什么、怎么做、怎么说）。三层里只有行为是玩家能接收到的：内在与外在写得再完整，只要没落成游戏里可观察的行为，就永远停在设定文档里，不会成为角色的一部分。两个可执行推论：人设档案必须包含世界侧字段（他是谁、在哪长大、此刻被什么困住），只填性格栏的档案等于把塑造工作推给编剧临场发挥；设定评审要加一道转译工序——逐条问'这条设定在哪一次具体行为里被表现出来'，答不出来的要么删掉、要么明确降级为背景资料。内在的呈现还要'无处不在，又应当处处不在'：靠玩家自己感悟出来的性格才有共鸣，把人物性格直接宣讲出来只会突兀。

- **批注**：术语冲突先划清：ur-039 说的'外在特征'指长相身材服装，本卡的'外在'指世界侧（身份、环境、处境），两者不是一回事——ur-039 管资源分配（外在求及格、差异化押内在），本卡管字段构成与可见性，可叠用。与 ns-049 批注那句'悖论要落在行为选择上才是角色，只写在设定文档里就是中二病'同源，但那张的主论点是原型乘悖论，本卡把'落成行为'从批注升成一道正式评审工序并给出问句。反对意见要认：设定文档不是废物，它是多人执笔时保持一致性的地基（ns-037 的人设档案正是这个用途），本卡反对的是把'写完设定'当成'塑造完成'，不是反对写设定。迁移成本低（一句评审问题加档案加三栏），但长线运营产品角色多、执笔人多时逐条转译的工作量会明显上升，现实做法是只对主要角色与高曝光角色做全量，边缘角色只查一条代表性行为。

## card-ns-094 · 故事主旨与角色是互相成就的，不是谁服务谁：主旨通……

- **论点**：故事主旨与角色是互相成就的，不是谁服务谁：主旨通常是宏观命题，宏观到玩家体会不到，必须有一个具体角色用自己的走向把它演出来；反过来，一个设定平淡、本来不容易出彩的角色，只要故事线与主旨高度一致，玩家认同世界观与主旨的同时就会认同他——喜爱是从主旨那边过户过来的。《古剑奇谭3》的岑缨是干净样本：主旨是'传承'，而她是神魔乱战主角团里唯一的凡人，没有长寿也没有妖力，只对记录与研究感兴趣，恰恰因此最贴近玩家；结局再用一套连环画讲完她此后一生把所学传给年轻人，落点闭合回主旨，这段收尾比主线高潮更被记住。落地动作：定完主旨后先问'谁来演它'，并且让那个角色的结局再落回主旨一次。

# 叙事即机制（判别法）

## 总纲

删掉这段叙事，游戏照常运转 → 它是皮肤。
皮肤不丢人（好看的皮肤有价值），但要在评审里登记为皮肤。
冒充机制的皮肤才是问题——它让你误以为游戏有深度。

## 叙事可以承担的五种机制功能

| 功能 | 叙事怎么承担 | 自检问题 |
|---|---|---|
| **信息传递** | 规则、线索、世界真相通过剧情/对话/环境释放，而非说明书 | 玩家是通过"经历"还是"阅读"学会规则的？ |
| **动机供给** | 玩家行动的理由来自在乎（救人、复仇、回家），而非分数 | 把分数藏起来，玩家还想继续吗？ |
| **情绪节奏** | 紧张/松弛/释然由叙事节拍控制，与玩法难度曲线互相咬合 | 剧情的低谷和玩法的低谷撞在一起了吗？（不该撞） |
| **教学引导** | 教学是角色在情境里带你做，不是弹窗念说明书 | 教学段落里，是"人"在教还是"系统"在教？ |
| **重玩价值** | 每次失败/通关释放新的叙事碎片，死亡本身是叙事引擎 | 玩家第二局的动机里，有没有叙事成分？ |

一段叙事承担的功能越多，它越是机制。一个功能都不承担的，
就是皮肤——要么承认它，要么删了它。

## 机制也可以承担叙事

反过来同样成立：机制本身是叙事。淘汰不只是规则结算，
它可以被设计成"退场仪式"；结算页不只是分数板，
可以被设计成"郑重其事的落幕"。
**机制即叙事的高级形态：玩家什么都没读，却感觉自己经历了一个故事。**

判别口诀：叙事即机制，机制即叙事——两头都通，才算咬合；
只通一头，是贴合；一头都不通，是两张皮。

## 叙事独有的病灶：玩家不在乎

立项时如果定义了叙事方向的病灶，通常长这样：

- "同类游戏的剧情玩家全跳过"（信息传递失败）
- "角色死了玩家内心毫无波澜"（动机供给失败）
- "通关之后什么都不记得"（情绪节奏/余韵失败）

叙事方案必须像机制方案一样，挂在具体病灶上接受裁决。
"这段剧情很感人"不是论点，"这段剧情负责让玩家在第三章开始在乎 XX，
解决 P2"才是。

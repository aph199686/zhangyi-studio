# 机制评审闸门（过闸问题清单）

每个机制进入裁决前，逐条过闸。任何一条答不上，就是裁决书里的一记否决或装饰章。

## 闸门一：病灶

"它解决哪个病灶？"——必须引用病灶编号（P1/P2/P3）。
答不上 → 装饰章。没有例外。增益字段里写"提升体验""更丰富"等于没答。

## 闸门二：内核

"它放大内核，还是外挂系统？"

| 信号 | 判断 |
|---|---|
| 机制让游戏的核心发动机更强（推理更深、抉择更难、信息更值钱） | 强化内核，优先 |
| 机制挂在内核外面自转（与核心玩法互不成就的养成/收集/任务列表） | 外挂系统，默认可疑 |
| 去掉它，游戏还是那个游戏 | 外挂。它大概率是装饰 |
| 去掉它，游戏塌了 | 内核的一部分 |

判别口诀：**强化内核 vs 堆系统。** 堆系统是独立开发者最常见的死法——
每个系统单独看都"合理"，合起来没有一个拔不出来。

## 闸门三：推演

推演三件事，写进裁决书：

1. **诱发行为**：玩家有了它会做什么？（包括你没打算让他们做的）
2. **涌现反应**：它和已有机制碰在一起会发生什么？（组合技、死循环、
   最优解塌缩——"所有人都只玩这一种"是涌现失败的头号症状）
3. **情绪曲线**：玩家做这些行为时是什么情绪？这个情绪是你设计的吗？

推演不出来 ≠ 机制神秘，是设计师没想完。想完再来。

## 闸门四：代价

每个优势换一个明确的代价。检查表：

- 这个机制让什么变强了？→ 什么作为交换变难/变贵/变危险了？
- 有没有"无代价纯收益"？→ 那它要么是幻觉（你没看到代价），
  要么会被玩家滥用到你被迫削弱它（届时得罪所有人）。

## 闸门五：可预判性

凡是系统施加给玩家的损失（淘汰、惩罚、资源扣减）：

- 玩家能提前算出来吗？算不出来 = 天灾，玩家只会觉得被游戏针对。
- 玩家能采取规避动作吗？不能规避 = 处刑，不是博弈。
- 修正方向：把判定依据从私密信息改为公开可算的信息
  （例：不用手牌点数判定淘汰，改用弃牌堆——玩家能算，才愿意博弈）。

## 附：开关思维

玩家群体可能对半分裂的机制（有人爱有人恨），做成**开关、默认关**。
开关的好处：争议机制不绑架核心体验；开与关的使用率本身就是
最便宜的用户研究。

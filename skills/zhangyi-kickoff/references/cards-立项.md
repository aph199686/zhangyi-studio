## card-gd-002 · 当设计卡住、说不清该加什么机制时，从"希望玩家此……

- **论点**：当设计卡住、说不清该加什么机制时，从"希望玩家此刻感到什么"出发：先列出能产生这种情绪的玩家行为，再倒推能催生这些行为的机制。
- **场景**：立项 / 机制 / 体验节奏
- **批注**：前提是目标情绪定义得足够具体——"无助的恐怖"能推出"无攻击能力+持续追击+资源匮乏"一整套机制，而"恐怖"推不出任何东西。另外美学层终究是主观的，逆推之前必须先回答"这游戏为谁做"，否则推出来的机制服务的是想象中的玩家。
- **出处**：[《透过MDA，得见游戏设计之道》](https://www.gcores.com/articles/216575) · 机核 · 2026-06-30

- **批注**：原文解法也可操作：全局先做区域规划（地貌势力分区），随机点做分类归槽，再把资源按区切割投放（如汽油分区制造路线博弈）。张力：随机投放是重玩性的廉价来源，并非原罪——罪在随机先于结构，先分区后随机，随机才有意义。对开放世界和生存类，这其实是立项期的前置决策：固定地图还是程序生成，决定了叙事密度能做多少。

## card-gd-034 · 选型核心机制时先判断它落在连续-离散光谱的哪一端……

- **论点**：选型核心机制时先判断它落在连续-离散光谱的哪一端：离散机制（回合制、CCG）靠策略深度取胜，单次操作失误不致命，创新靠规则组合就能做、技术风险低；连续机制（竞速、动作射击）的体验上限被手感调校和物理模拟成本锁死。资源有限的团队去做连续型，等于主动选了最贵的战场。
- **场景**：立项 / 机制 / 核心循环
- **批注**：反对意见要写清：连续型一旦手感调出来，操作壁垒和沉浸感是离散型给不了的（驾驶手感本身就是卖点），这条只适用于创新效率维度，不是体验天花板的高低排序。另外连续-离散是光谱不是二分，MOBA 就卡在中间，既要操作又要策略，别拿二分法硬套。

## card-gd-040 · 判断商店是转换器还是真交易，看资源是否真实双向转……

- **论点**：判断商店是转换器还是真交易，看资源是否真实双向转移：固定汇率的商店（钱消失、货出现）本质只是转换器，不存在套利空间；想要跑商、区域价差、玩家驱动的经济行为，商人必须有真实的资金与库存并据此调价——价差是被设计出来的行为发生器。
- **场景**：立项 / 机制 / 经济系统
- **批注**：真交易的维护成本高一个量级：要防玩家搬空商人、防通胀、给商人资金池做再生机制。单机里价差经济是风味系统（巫师3），网游里它是通胀火药桶，选型属于立项期决策，做了一半再回头改代价极大。这条同时是诊断工具：玩家抱怨'商店没意思'，多半是想要交易感的游戏只做了转换器。

## card-gd-044 · 实体书加 APP 这类跨媒介解谜产品，内容主体必……

- **论点**：实体书加 APP 这类跨媒介解谜产品，内容主体必须留在实体端：拼装、折叠、叠加、透视、拆解这些手上动作占了谜题的一半以上，数字端只承担三件事——给出道具的轮廓特征、收取答案、演过场剧情。所以整个盒内清单都要按能不能当谜题面板来审，而不是按物流成本来审：外盒图案、缓冲海绵背面的刻痕、文件袋的卡扣、伪装成赠品的那张门票，全都是内容。玩家对着几十件道具反复翻找的动作本身就是玩法，前提是翻找有回报。
- **场景**：机制 / 立项 / 核心循环 / 信息设计
- **批注**：数字端故意不点名道具、只给轮廓特征，是这套分工的关节：一旦 APP 直接说用哪一件，实体就退化成一次性道具，翻找乐趣归零。把关键件伪装成赠品是最便宜的 aha 时刻，也是最容易翻车的设计——玩家真把赠品当废料扔了或弄丢，游戏就永久卡死，此时难度不由谜题决定而由玩家的收纳习惯决定，必须有分级提示兜底。翻找要有回报这点与 card-pp-003（探索奖励要匹配付出成本）同向：如果大半道具是纯装饰，玩家很快学会不要翻，堆料就从内容变成噪音。反过来，软件小游戏该压到很小比例——那是这个形态里唯一可被纯数字游戏完全替代的部分，做多了等于自废不可替代性，也解释了为什么这类产品该把钱花在纸艺机关而不是 APP 开发上。
- **出处**：《IP向游戏互动解谜书拆解研究》（（内部资料·脱敏）） · 个人知识库 · 2022

## card-gd-050 · 衡量一张地图的内容量，口径应该是单位面积的探索时……

- **论点**：衡量一张地图的内容量，口径应该是单位面积的探索时长，不是探索点数量——加探索点是线性花钱，把每个点要花的时间拉起来才是乘数。三条乘数杠杆：纵向折叠空间（掏空山体、多层箱庭、洞与洞连通，同一坐标叠出多个层级）；给赶路标价的环境压力（持续掉血的寒冷与雷暴，把探索切成准备、突进、撤回的回合）；把内容的发现难度档位上移（从显而易见挪到有遮蔽、解谜后才显示）。一块小得多的地图因此能撑起接近的探索时长。
- **场景**：立项 / 机制 / 体验节奏
- **批注**：证据来自同一款游戏的区域演进：面积远小于新手平原的山地区域，靠立体结构加环境压力把单个探索点的耗时明显抬高，总探索时长却接近；而更早一版的向地下拓展只做了一半——挖出地下密室却只放怪镇守，被判定为空洞，说明纵向折叠的每一层都必须配真内容，空层比不挖更糟（它把内容不足直接暴露给玩家）。与 gd-033 有张力，要划界：那张管放什么、放多密（密度×门槛三层配比），这张管每个点值多少时间，两者相乘才是体验总量，别互相否决。统计前先定口径（山上和山内算不算两层、空中高台和地面算不算两层、什么算一个探索点），口径不定，区域之间的对比全是噪音。适用边界要认：这三条都偏向已有能力的老玩家，纵向折叠和环境压力会同步抬高新手梯度，必须配进入闸门（见本批新手梯度卡）与任务链引导；另外位移工具要跟得上——地形复杂度上去之后，没有上天入地的位移机关，复杂度就会退化成无效赶路时间。
- **出处**：《原神地图设计研究》（（内部资料·脱敏）） · 个人知识库 · 2022

## card-gd-063 · 世界观设定不是氛围装饰清单，而是玩法结构的解释书……

- **论点**：世界观设定不是氛围装饰清单，而是玩法结构的解释书：每条设定都该能回答一个具体的功能性疑问。第五人格的设定几乎全是这么推出来的——「反复翻阅日记、用演绎法还原旧案」同时解释了对局为什么能无限重复、玩家为什么能反复更换阵营；侦探身份给了主角反复阅读记录的动机；前推理小说家给幕后黑手举办庄园狂欢提供了动机；人格分裂解释了为什么所有玩家在同一个世界查同一件案子还能彼此联系；失忆桥段让玩家以为自己与主角信息对称（原文自承这是一种假象）；把时代定在维多利亚，理由甚至是压低通信与信息传播水平，好让世界同时容得下科学与神秘。验收动作很便宜：给设定集里每一条写一行「它解释了什么」，答不出功能问题的条目要么删掉，要么明确降级为装饰与彩蛋。
- **场景**：立项 / 叙事 / 叙事结构 / 核心循环
- **批注**：推理链的上游是一张约束清单：把不可让步的目标（恐怖题材的恐惧与紧张感、非对称对抗的差异化乐趣、题材受众稳定诉求集中且当时市面缺少同类产品）与不可改变的现状（移动端机能有限、触控精度不如键鼠、玩家游玩环境不可控因而声音传达极不稳、题材审核排斥写实血腥）并排列开，结论是核心情绪很可能被现状吃光。此时的动作不是下调情绪目标，而是换传达通道——从依赖视听精度的感官刺激转向心理恐惧与悬疑，参照物是寂静岭初代用浓雾回避机能限制、反而把限制熬成了系列标志。与 ns-002（世界设定三问）分工清楚：那张管开工前问什么，这张管写完之后逐条怎么验收；与 gd-056（规则要生效）也不重复：那张管规则对玩家行为有没有反应，这张管设定对玩法结构有没有解释力，两者可以各自单独失守。反对意见要认：并非每条设定都必须承重，纯氛围条目和彩蛋容器有独立价值——日记载体被明确当作方便后续自由插入各种经典恐怖题材彩蛋的可塑性容器，纪律是区分承重设定与装饰设定，而不是要求全部承重。另一个真实代价：功能先行的设定容易露出工具感，玩家会读出这是为了圆玩法编的；解法是让功能答案与文化直觉重合——失忆、人格分裂、深山庄园、维多利亚侦探都是现成的类型桥段，受众早已接受，解释玩法的同时不显得刻意。
- **出处**：《第五人格的设计推演之路》（（内部资料·脱敏）） · 个人知识库 · 2019

## card-gd-075 · 3D 视角的俯仰限制里，真正被压住的几乎总是仰视……

- **论点**：3D 视角的俯仰限制里，真正被压住的几乎总是仰视角上限，而它的第一约束不是操作手感，是场景资产的完成度与渲染预算——给玩家抬头的自由，等于承诺他能看清建筑顶部、山体背面、模型底面和天空盒的质量。所以视角限制清单必须和场景美术的完成度清单放在一起评审：仰角压到多低，就宣告了哪一批资产可以按『看不见』的标准降级甚至省略，这是一笔可以主动去省的钱，而不是被动接受的技术债。反过来，如果题材卖点里本来就包含仰望（巨物、高耸建筑、天空、神性场面），压低仰角就是自我阉割，必须先付资产钱再谈镜头。别只把它当技术限制读：收窄视角同时是叙事控制权，是把玩家视线锁在导演要的那一格画幅里。

- **论点**：评估一个 IP 值不值得联动，必须把笼统的热度拆成两个独立维度分别打分：大众知名度（当地知晓这个 IP 的人群范围）决定联动能拿到多少曝光，核心受众规模（愿意持续关注乃至为它付费的人数）决定转化率和付费效果。两维错位是买错标的主因——只有知名度、没有受众规模的标的（文物、博物馆、老掉牙的经典作品）转化天然弱，它的联动价值在品牌宣传与公关，不能按拉新付费报预期；反之受众粘性强但知名度低的小众标的，只适合画像高度重合的产品。配套两条选择纪律：口碑是底线不是加分项，只要不触政治、抄袭、作者私德这类硬负面，争议本身对联动效果影响有限，不必为高口碑付溢价；标的的影响力呈金字塔分布，真正进入大众视野的是极少数，那条线才是联动能产出显著效果的门槛，门槛以下的标的按成本与画像契合度选，不要按万一爆了选。
- **场景**：立项 / 市场定位 / 用户研究
- **批注**：两维还要配上产品侧的配对规则才可用：大盘高 DAU 产品配高知名度 IP，画像独特的小而美产品配受众重合的中腰部 IP，在成本与影响力之间找平衡。顶级 IP 稀缺且首发合作门槛高，优先给畅销榜前列、知名度高的产品，随着合作次数增加标准才逐步下放到中部产品，发行方在业界的声誉可以为新产品争取提前合作的机会——所以顶级 IP 联动更多是产品地位的结果，不是原因。类型层有一条机理解释值得记：联动这套打法生长于 ACG 文化圈，圈内标的之间的相互转化远高于圈外，因为用户圈层重叠、交叉渗透率高，实际投放也以动漫为主、游戏 IP 其次，世界观浅但人设强的虚拟偶像同样有效；真人影视向虚拟形象的转化两头不讨好，实践中多退化为宣传资源互换，期待不宜高；小说类 IP 没有现成视觉设定，美术要从零建立形象，恰好丢掉联动最大的时效红利——省下美术从零开发新概念的时间，而小说受众想象空间大，有限预算的产出很难让他们满意。张力要写清：材料认为受众画像重叠度与世界观融洽度不是决定性要素，契合度越高只是锦上添花越多，这与 kl-024（IP 自带乐趣偏向，错位是最常见死法）直接冲突。我的判断是按产品类型分岔：泛用户大盘产品里契合度确实只是放大器，画像越窄权重越高——材料自己给了反例，几款女性向产品与纯二次元 IP 联动反响平平，反而与贴近目标人群现实生活的女性消费品牌合作效果更好。另外文物文创、潮牌实物联名这类合作没有统一评估口径，转化更多取决于联名实物本身的质量，别把文化产品的两维模型硬套上去。与 kl-023 分工不重复：那张管剔除自来粉之后的净吸引力估值，这张管估值该拆成哪两个维度、以及哪些维度只做门槛筛查。原文含大量榜单统计、销量分布与报价区间数字，按保密闸全部舍弃，只保留方向性判断。
- **出处**：《IP联动从入门到精通》（（内部资料·脱敏）） · 个人知识库 · 2021

## card-kl-064 · 给 IP 联动报预期时，基准线是一次同量级的常规……

- **论点**：给 IP 联动报预期时，基准线是一次同量级的常规版本活动更新，不是破圈爆款：联动往往用少于一次大更新的内容量拿到相近的效果，性价比来自这里，超出部分是 IP 影响力与契合度带来的加成，不是底盘。所以联动是锦上添花，救不了运营基本盘——联动吸引来的玩家在留存和表现上并不特殊，最终仍由游戏本身的玩法、品质与受众契合度决定。排期上按生命周期换目标而不是换口号：产品初期要拉新，选时下新兴、知名度高、被联动次数少的 IP；稳定运营期要维持活跃与付费并吸引回流，选经典大众加时下热门；晚期要降本提利润，以复刻和低成本 IP 为主。还要认一条不对称的衰减规律：随着产品老化、同一个 IP 被别人联动和被自己复刻的次数增加，联动的拉新能力会持续衰减，而吸引回流的能力在长期内保持稳定——老产品的联动应当按回流工具排期，不该再按拉新工具报 KPI。
- **场景**：立项 / 体验节奏 / 市场定位
- **批注**：配套的排期纪律比结论更值钱：一次联动从 IP 梳理评估、商务接触到开发上线常以季度到年为单位，且美术素材要因监修专门定制、很难复用，开发成本高于常规版本、返工不确定，所以联动不该打乱原有版本计划，而是作为大版本之间的填充——它能减缓数值膨胀速度、延长生命周期，为带数值膨胀或全新机制的大版本争取打磨时间；只有本身足够热门的 IP 才值得当一个大版本来规划。预告期不宜过长，画饼太久反而消耗新鲜感与期待（数周量级即可，不必拉到数月）。热门 IP 的联动之间要留间隔，中间穿插中腰部 IP。联动内容用作买量素材能降低获客成本，联动期可适当加大投放（该结论来自投放侧监测，只取方向不取幅度）。复刻要提前当资产谈：IP 的培育周期远长于市场的消耗速度，复刻因此是常态而非将就，它的价值有三层——限定返场对当时没收齐或后来入坑的玩家仍有吸引力、无新内容时基本不需重新监修因而周期短且可控、可以当版本真空期的内容储备；所以首次谈判就该把复刻权与素材复用范围写进去。若 IP 本身有新作，可以蹭其宣传档期加入新内容当一次新联动做，但新内容要重新监修，档期不确定性上升。还有一条常被忽略的风险因子：授权方的联动成熟度决定排期，不只是价格——常做对外授权、指引与反馈明确的版权方能显著省时间（某个 EVA 量级的 IP 之所以能与大量产品联动，与出品方早年宽松的授权监修策略和它在核心圈层的影响力都有关），联动经验少的版权方容易出临时要求与意外状况，评估时要单独打分。与 kl-053 的张力必须写明：那张说联动拓圈靠反差，这份材料观察到的所谓破圈联动（头部产品抢下当年最热 IP 的首发）本质是强强联合，是产品地位换来的，不是可复制的破圈方法论；两条都成立，但中小产品照抄抢顶级热门 IP 的打法，买到的往往是曝光而不是转化。与 kl-029（内容是吸量与长线留存变量）互补：联动是一次性的外部内容注入，长线仍要靠自有内容供给。
- **出处**：《IP联动从入门到精通》（（内部资料·脱敏）） · 个人知识库 · 2021

## card-kl-065 · 联动选品的第一问不是『我的用户是谁、他们小时候看……

- **论点**：联动选品的第一问不是『我的用户是谁、他们小时候看什么』，而是『我的产品在玩家心里有多厚的文化、厚在哪一维』：先量玩家在这个游戏上投给文化层（剧情、世界观、人物造型、同人）的注意力，按厚薄分档，档位直接决定联动的苛刻度与方向。文化极厚的产品养出了自带文化的死忠群体，对联动的审判最严，实践上几乎只能联同一世界观体系内的作品（FGO 的历史联动基本落在型月世界内部）；文化厚但不到极致的产品，要求集中在世界观、画风、人设三项契合（阴阳师的联动集中在同一类妖怪题材）；文化中等（有世界观构建但没有同人氛围）的产品各维要求均衡，情怀权重反而抬到最高（梦幻西游一系靠童年 IP 唤起情怀）；文化薄的产品辨识度不足，对联动对象包容性最强，但只看知名度与热度（天天爱消除联哆啦A梦这类全民 IP）。所以玩家在意的那几个维度（知名度、近期热度、情怀、世界观契合、画风契合、人设造型）不存在通用权重表，权重是产品文化类型的函数——借别家产品的『首要判据』来给自己选联动对象，是最典型的选品错误。
- **场景**：立项 / 验证 / 市场定位 / 用户研究
- **批注**：分档变量是可测的，不必拍脑袋：一道『玩这个游戏时你会花多少注意力在它的文化上』加一组品牌印象题（特色辨识度、当下话题性、讲究剧情世界观的程度、同人丰富度、核心群体忠诚度），就能把自家产品放进某一档，成本远低于选品会上的口味之争。权重的算法也值得复用：不要直接问『这方面多重要』，用『会不会看重（选择该项的人数占比）× 看重程度（评分）』相乘，两问相乘能滤掉口头重要但实际不看的项目。两处张力必须写明：一，与『挑联动 IP 的首要判据是对方高光时刻落在核心用户的童年/少年期』这条判断直接冲突——按本框架，情怀权重高只在文化建设中等的产品上成立，文化极厚产品的玩家要的是世界观契合，文化薄产品的玩家要的是知名度，情怀在两端都不是首要判据；二，与『受众画像重叠与世界观融洽不是决定性要素、契合度只是锦上添花』那条行业经验冲突，调和口径就是这张卡本身：契合度的权重随自家文化厚度上升，文化越薄它越只是放大器，文化越厚它越是硬门槛。第三，本框架只管玩家侧接受度，不管商务侧的授权难度、监修成本与档期，两套网要一起过。适用边界：分档结论来自运营期文化型手游的玩家问卷与公开联动史对照，买断制单机、以及本来就不做运营期联动的产品不适用；档位也不是终身制，产品自身的文化建设推进后档位会移动，联动策略要跟着重估。
- **出处**：《IP联动选取策略研究》（（内部资料·脱敏）） · 个人知识库 · 2018

## card-kl-066 · 联动价值是乘法不是加法：一个备选 IP 值不值得……

- **论点**：联动价值是乘法不是加法：一个备选 IP 值不值得联，等于『知晓率 × 契合度』，其中知晓率是门控项而不是并列的加权项——一旦知晓率低到圈外基本无人认识的程度，玩家对这个 IP 在世界观、画风、人设、情怀上的评分与他们对联动活动的推荐意愿之间就不再有任何显著关系，契合度全盘作废。所以选品动作必须是先门槛过滤、再契合度排序：商务递来一长串备选时，先用『我们的玩家里有多少人知道它』砍掉一批，砍完剩下的才配逐个比契合维度；顺序反过来就会出现选品会上的经典事故——所有人都在夸某个调性完美的小众 IP 有多契合，而它根本带不来任何可测的效果。评级也要按乘法结果归一化：把理论满分定为一，所有备选落到同一把 0~1 的尺子上再分档，不同量级的 IP 才可横向比较，也才能把『知晓率不达标』做成一票否决的最低档而不是靠扣分蒙混过去。
- **场景**：立项 / 验证 / 市场定位 / 用户研究
- **批注**：门槛存在、以及门槛以下契合度失去预测力这两条，来自对两款公开运营产品玩家的问卷验证；具体阈值与样本口径属内部数据，不引，只取结构判断。这套乘法与 card-kl-023（评估 IP 导量价值要先剔除自来粉）同族：都在防止把某个单项高分误读成整体价值，kl-023 剔掉的是玩法与题材自带的人，这张剔掉的是低知晓率下的契合度幻觉。与『把热度拆成大众知名度与核心受众规模两维、门槛以下的标的按成本与画像契合度来选』那条判断有真实冲突：那条认为低知名度的小众标的仍可依靠画像重合成立，本条的问卷结果不支持——知晓率过低时连画像重合都救不了推荐意愿。我的调和：两者量的不是一回事，画像重合在商务侧仍有价值（授权成本低、圈层口碑好、存量玩家惊喜），但在拉新与推荐意愿侧无效，所以小众 IP 只能按品牌公关与存量活跃报预期，绝不能按导量报 KPI。附带一条可复用的择期纪律：知晓率与热度都是时变量，同一个 IP 在不同排期下分值不同，绑定对方的势能节点（新作发售宣传期、系列周年、真人影视上映档期）能让联动白吃对方的曝光——公开案例是日本一款战棋手游把与某 3A 系列的联动排在对方新作的宣传窗口内，把与经典漫画 IP 的联动排在周年月。局限：乘法模型的理论满分设定与分级线都依赖具体产品的数据校准，换产品必须重新标定，不能直接搬用别人算好的分值；且知晓率要按目标市场分别量，同一个 IP 在不同地区的知晓率可以差一个档。
- **出处**：《IP联动选取策略研究》（（内部资料·脱敏）） · 个人知识库 · 2018

## card-kl-067 · 联动的频次能改写玩家对联动的评判标准：有一类产品……

- **论点**：联动的频次能改写玩家对联动的评判标准：有一类产品把联动做成常态化节奏（每一两个月就一次），联动本身因此成了产品标签和它特有的一层文化，此时玩家对联动对象几乎不再有契合度要求，只看人气够不够大。反过来，低频联动的产品每一次联动都会被当成一次重大的文化表态来审判，选错一个就是事故。所以『该不该在意契合度』不只由产品的文化厚度决定，还由你把联动放在什么频次上：想要选品自由度，就得先付出常态化排期的成本，把『什么都能联』养成玩家已经接受的产品性格；一年只联一两次的产品去学高频联动者的选品逻辑，只会两头挨骂——既拿不到自由度带来的曝光节奏，又丢掉了低频联动应有的调性收益。
- **场景**：立项 / 收尾 / 市场定位 / 体验节奏
- **批注**：现象有据：日本两款头部长青手游在一年窗口内的联动排期几乎月月不断，标的横跨少年漫、深夜动画、主机游戏、经典特摄各种调性，玩家把它们当成『联动游戏』来看待，契合度争议基本不出现。但『频次改写预期』是我从这个现象推出的因果解释，原材料只描述了这类特例的存在，没做玩家预期的前后对照，按方向性判断采信、别当实证用。前置条件要写死三条：一，玩法底盘必须足够耐玩，联动只是皮层的持续供料，玩法本身不耐玩时高频联动只会加速审美疲劳；二，商务与美术产能要撑得住常态化排期，授权谈判常以季度计、素材还要过监修且难以复用，没有专门的联动管线做不到；三，这条路要求产品本身文化辨识度弱、或定位偏娱乐化，与文化厚的产品互斥——深文化产品做高频联动是稀释世界观，不是积累标签。与本批前一张（文化厚度决定联动苛刻度）构成一个有意思的环：文化厚度决定苛刻度，而高频联动本身能人造出一层『联动文化』，反过来把苛刻度压下去——也就是说苛刻度不完全是既定属性，它可以被排期策略改写。与 card-kl-053（联动出圈靠反差、敌人是高大上）互补而不重复：那张讲单次联动怎么选对象才破圈，这张讲把联动做成节奏之后选品自由度从哪里来。风险提示：常态化会把单次联动的边际效果摊薄，且一旦频次掉下来，被养宽的预期不会立刻收回，产品会同时失去两条路线的好处。
- **出处**：《IP联动选取策略研究》（（内部资料·脱敏）） · 个人知识库 · 2018

## card-kl-068 · 把传统文化放进游戏的正确姿势是『翻译』而不是『搬……

- **论点**：把传统文化放进游戏的正确姿势是『翻译』而不是『搬运』：硬核传统文化的欣赏门槛与审美距离是客观属性，原样复刻进游戏不会降低它，反而容易叫好不叫座。游戏 IP 自己就是玩家最熟的语言——把文化拆碎，化整为零埋进角色造型、待机动作、技能动作与特效、音效、念白这些玩家天天接触的最基础触点里，用游戏的内容去讲文化，文化传达只做暗线、游戏本体才是主线。落地动作：每个文化元素进场前先问『它能不能翻译成玩家的游戏内日常语言』，翻译不了的就别硬塞；能翻译的也懂分寸、不用力过猛，点到为止反而加深印象。
- **互引**：ns-065｜同源材料两切面：两份同出《从原神云堇看如何用传统文化反哺游戏IP》；本卡管立项姿势（「翻译而非搬运」总纲），那张管现场手法（降门槛两译法：形式置换＋内容先行）；两卡并读，不互相替代；原样复刻反例与两案克制/翻车细节见本卡批注。
- **场景**：立项 / 叙事 / 市场定位 / 角色塑造

## card-kl-069 · 跟有专业门槛的亚文化圈层（汉服圈、戏曲圈、国漫圈……

- **论点**：跟有专业门槛的亚文化圈层（汉服圈、戏曲圈、国漫圈这类有明确 KOL 和考据标准的圈子）做联动，收益有时效窗口、风险却随时间上升：产品运营早期这批核心用户还没被洗过时，圈层合作能带来精准导量；一旦他们大多已在你的用户池里，继续做同类联动的拉新收益就很薄，而圈内人会拿专业标准公开审查你的产出——形制不对、考据不严、合作方在圈内本身有争议，都会被逐条纠正并扩散成对外的负面观感。所以圈层联动立项前要过两问：这个圈子的核心用户我洗过没有？我的考据与合作方能过圈内专业审查吗？两问都不利时，改用不带圈层归属的公共文化内容（古人衣食住行、公共历史题材）在游戏内做融合，受众更宽、审查更松。

## card-kl-070 · 用福利激励（分享集赞换道具）驱动的活动自传播，传……

- **论点**：用福利激励（分享集赞换道具）驱动的活动自传播，传出去的是激励本身而不是活动内容：玩家转发时只讲外观好不好看、能不能白拿，被安利回来的人根本不知道这是一场什么主题的活动；官方账号讲文化内核的物料热度也远低于同档期其他内容，转发量高的清一色是抽奖帖。所以内容型活动的传播必须拆成两条线分开考核——福利线（能拉量、能赚口碑，但传递不了主题）和内核线（只能靠本来就认同这个内容的人自发去讲，且要求你选的合作对象自带更大更核心的受众群）。把福利线的传播量记成内核线的成果，会得出这场联动传播很成功的误判，进而误配下一场的预算。

## card-kl-071 · 同一场文化联动要同时喂饱两拨人，而他们看的是完全……

- **论点**：同一场文化联动要同时喂饱两拨人，而他们看的是完全不同的维度，一个杠杆满足不了两边：大盘玩家最在意联动外观的获取方式（能不能免费或低门槛拿到），对品质感的关注排在获取方式之后——外观做得再精致也不如“免费”两个字有刺激；真正在意文化还原度的只有本来就关注这块内容的那一小撮人，且越关注越看重还原度。所以联动资源要两条线各自给足：把大部分联动外观做成免费可得（这是满意度与口碑的主来源），再为核心关注者单独做一条还原度线（可逛可交互的文化场景、有讲解的 NPC、经得起考据的形制）。只砸品质不砸获取门槛，会同时丢掉大盘的满意度和核心的认同。
- **场景**：立项 / 经济系统 / 信息设计 / 玩家动机
- **批注**：适用边界：这条在联动产出以外观为主的内容型产品上验证。与外观驱动品类的付费逻辑（外观渴望由展示结构产生、付费外观本身就是核心营收物）直接冲突——把联动外观全免掉等于砍营收；可行的折中是联动主件免费、同主题的衍生件（配套动作、场景、更华丽的版本）走付费展示结构。还原度线的成本比想象中低：材料里评价最高的做法只是一个可逛的街区加逐项介绍的手艺人 NPC；反过来玩家最常见的抱怨是只堆文字不给实物展示、没人会看字——还原度的载体优先用可看可交互的物件，文字说明只做兜底。与 card-ur-048（考究动机是被内容打动后的后置行为）互补：那张说别指望元素本身点燃考究，这张给出元素该怎么摆、给谁摆。与 card-ur-049（考究内容当定向增强器而非主卖点）一致，两张合起来说明还原度线该按核心受众的穿透来算回报，不该写进大盘获客 KPI。与 card-kl-068 的“翻译而非搬运”有一处必须辨明的张力：那份材料里高还原的戏曲展演（搭戏台、搬整出复刻演出、投放还原戏服）被判为失败，本批的高还原（可逛的街区、逐项讲解的手艺人 NPC、形制考据的外观）却拿到最高满意度。差别在还原度的呈现形态——玩家能按自己节奏进出、随时退出的环境式还原门槛低，要求玩家坐下来看完一整场高门槛展演的还原门槛高。所以这张卡的还原度线指的是前者，不要拿它去正当化硬核展演。

## card-kl-072 · 挑选联动/代言 IP 的首要判据不是这个 IP ……

- **论点**：挑选联动/代言 IP 的首要判据不是这个 IP 当下有多热，而是它的高光时刻是否落在核心用户群体的童年/少年期——联动真正唤起的是情怀，不是当下的注意力。有消费力和决策权的存量主力用户，对应的是他们当年追过的动漫、游戏、影视作品；按『现在什么火』而不是『核心用户小时候看什么』来选联动，等于把泛人群的记忆误当成自己用户的记忆，情怀牌打空。选联动 IP 先对齐核心用户的怀旧窗口，再谈契合度与成本。

## card-kl-073 · 决定联动效果考核口径的第一步不是选 IP，而是判……

- **论点**：决定联动效果考核口径的第一步不是选 IP，而是判断自己在这段关系里是弱势方还是强势方。弱势方联动是借势导量，按新增与转化考核；强势方联动几乎不可能靠对方带量，它的真实职能是给存量玩家一个新上线理由、以及维系渠道与生态关系，只能按活跃与参与率考核。强势方的外部联动频次还会天然走低直至停投——当促活跃的边际收益撑不起授权费与多方协调成本时，联动就从排期里消失。拿导量 KPI 去考核强势方的联动，会同时误判效果和误配预算。
- **场景**：立项 / 收尾 / 市场定位
- **批注**：证据来自对一款头部MOBA两年联动排期的复盘：它对外部IP与产品的联动频次远低于对自有赛事生态的联动，复盘口径明确写着量级更大的产品较少靠联动为自身宣传引流、主要目的是促活跃，且到观察期末尾外部联动直接归零。与 card-kl-023（IP导量价值要剔除自来粉）分工：那张教你算弱势方视角下的净导量，这张先问你有没有资格谈导量。与 card-kl-053（反差联动才能出圈）是张力而非矛盾：反差破圈是中腰部与弱势方的手段，头部产品做反差联动的收益本就不在圈层扩张上，用出圈标准验收它同样是错口径。边界要写死：强势方指用户盘子与话题势能明显压过对方，不是收入高就算；双方量级接近时联动本质是互换用户，仍按导量考核。反向推论也要认账——如果你是弱势方，对方肯联动的理由往往正是你能替它促活跃，谈判筹码按对方的职能算，不要按自己的期待算。

## card-kl-076 · 一个 IP 的价值可以按层拆开分别定价：把复用性……

- **论点**：一个 IP 的价值可以按层拆开分别定价：把复用性最高、也最难独占的规则层（玩法框架、数值语法、判定方式）免费开放，让它变成整个品类的默认语法，收费点收缩到情感与内容存量所在的世界观层和角色层。做 IP 策略时第一个要回答的问题不是授权费定多少，而是哪一层放出去能变成行业标准——所有借用规则层的作品都在替你做免费的市场教育，而具体战役设定、角色与商标依然只能付费取得。
- **场景**：立项 / 市场定位
- **批注**：证据链是公开的开放授权条款：核心数值系统以系统参考文档的形式在开放游戏许可下释出，商业与非商业发行者都能免费修改和补充，只有具体战役设定需要向版权方取得授权。结果是这套规则从一款产品长成了一个品类标签：大量从未取得授权的作品（永恒之柱、神界原罪2 这一类）也在沿用它的语法，而被遗忘的国度、龙枪这些具体战役仍然是可收费资产。材料自己把它总结成三种不同的东西——一个商标、一套可被沿用的规则系统、一类具体世界观设定，这个拆法就是本卡的骨架。反方要认账：这套打法的前提是规则层本身复杂到值得别人抄，以角色情感为唯一资产的 IP（偶像企划、番剧）拿不出可开源的规则层，硬套只会得到免费的东西没人要、收费的东西没人买。第二笔账是控制权：规则层一旦开放，品类语法就不再由你解释，后来者的低质产品会把品牌形象钉死在最刻板的符号上（骰子加地下城），这份稀释是开源的真实成本，材料只记录了收益侧。与 card-kl-023（评估 IP 导量价值要剔除自来粉）方向相反但不冲突：那张是买方的估值纪律，这张是卖方的价值放大策略，同一份 IP 报告里两种视角都要有。与 card-kl-024（IP 自带乐趣偏向）互补并推进一步——乐趣偏向恰恰住在可以免费送出的规则层里，所以选玩法时受限的是世界观与角色，不是机制。迁移到自建 IP 的最小动作：把设定集拆成规则、世界、角色三册，先决定哪一册愿意让别人白用。

## card-ns-089 · 角色驱动的产品里，人设是唯一能拿来抵系统债的资产……

- **论点**：角色驱动的产品里，人设是唯一能拿来抵系统债的资产，而且这个方向不可逆：玩家会为一流的主角人设容忍糟糕的关卡、平庸的养成和不合理的怪物数值（《尼尔：机械纪元》是常被举的例子——开放世界与养成被普遍诟病，销量与知名度却不受影响），但没有玩家会为一流的开放世界去容忍一个无感的角色。所以立项时一旦判定产品属于角色驱动，人设的投入优先级应当排在系统完善度之前。前提是认清这里的人设是一个复合体：造型、动作设计、演出、音乐全在里面——只把设定文档写厚，不构成任何对冲资产。

- **批注**：这条最容易被误用成系统做烂没关系，所以边界要写死：抵扣有额度，且只抵特定类型的债。它能抵的是体验摩擦类缺陷（关卡单调、养成浅、数值不合理导致清怪耗时），抵不了调性违和（ns-012：角色与世界调性冲突的杀伤力最大，是沉浸感的硬地基），更抵不了核心循环不成立。这套逻辑与 gd-054（氛围与构图能中和穿模贴图感，但原谅区间不是无限的，缺少可掩盖内容的场景直接被判无法接受）是同构的，只是把尺度从单个场景抬到整个产品——两张卡合起来给出的通用纪律是：先保不可原谅项，再谈用长板掩盖可原谅项，顺序反了两头都空。《尼尔》被诟病的是开放世界与养成，它的动作手感与音乐是顶级的，而那部分本身就是人设复合体的组成，不是被抵扣的债。把人设救系统读成可以不做好玩，是这张卡最危险的误读。

与 ur-039（外在只是及格线，差异化押内在）有一处需要辨明的张力：ur-039 管单个角色内部的资源分配，警告别把差异化预算全砸在服装长相上；本条管产品层面的资产对冲，而对冲资产恰恰包含 ur-039 判为及格线的外在层——那个白色短发、黑色短裙的造型本身就是最强的传播物与同人素材。两者不矛盾：ur-039 回答怎么让角色被喜欢，本条回答怎么让产品被记住和被谈论，后者对外在的依赖明显更高。
证据强度自审：核心证据是单一作品的公开口碑与市场表现加作者的个人观感，属方向性判断而非可量化结论。反例真实存在——同样人设突出但系统崩坏到无法通关的作品照样死，说明抵扣额度有下限，且下限由品类的可玩性刚需决定。
与 kl-029（内容不是营收变量而是吸量与长线留存变量，同品类横向对比里内容好坏与收入榜排序相关不强，别指望好内容救营收）表面冲突，实则口径不同，合并时要说清：kl-029 是跨产品的横截面统计（内容强的产品不见得营收高），本条是单个产品内部的取舍（同一款作品里人设能盖住系统短板）。两者可以同时成立——人设帮你被记住、被谈论、被长线回流，但不保证你在畅销榜上跑得赢数值做得更好的对手。所以本条的正确用法是排优先级，不是许营收承诺。
迁移边界：只适用于角色驱动品类（动作冒险、二游、卡牌、AVG）。竞技与策略品类的玩家本来不期待叙事身份，人设抵不了平衡性与匹配机制的债；工具型产品同理。

## card-ns-091 · 概念层的原型二创要同时满足两条互相拉扯的约束：一……

- **论点**：概念层的原型二创要同时满足两条互相拉扯的约束：一是可考据——认领一个已有的人物或文化原型，白拿大众认知与信服度，也给后续拓展留好接口；二是不走寻常路——原型一旦被抛出，大部分人能想到的那个方案就已经注定平庸。两条不矛盾的解法是换取材坐标：不在原型的本体属性上做加法（火焰妖怪就把浑身画满火），而是去原型传说里'它出现时的场面'取画面。素材里的实例是把一则海上怪火传说做成一名在海面舞台上演唱的歌姬，千帆点灯聚拢的景象复现了传说中接天连海的火光，再让'名字本身也是一种咒'把歌姬与大妖怪合成一人——考据红利来自场面的还原，不俗来自本体的置换。
- **场景**：立项 / 叙事 / 角色塑造
- **批注**：边界纪律是原文那句'戏说不胡说，改编不乱编'：背离原型精神内核、或与原型之间毫无传承联系的二创只会让人尴尬——可考据不是拿来蹭个名字，考据必须落在精神内核的传承上。与 ns-049（主流文化原型×内在悖论）分工要划清：那张管角色'是什么人'的概念层张力（原型保大众缘、悖论保记忆点），本卡管'从哪里取材'的坐标问题，两者可叠用——先按本卡换坐标避开俗套，再按 ns-049 焊一个悖论进去。与 ns-018（文学造型=这个角色会做什么事）互补：文学造型给动作面的一致性，本卡给形象来源。与同批视觉记忆点卡同根不同层：判断同源（第一反应=平庸），动作不同（一个嫁接异质元素，一个转移取材坐标）。可考据这条有公开的成功量级佐证——把亚瑟王做成少女骑士的那条线（FGO 的 Saber）说明一次坐标得当的原型二创能撑起整个产品级 IP。迁移成本要诚实标：换坐标取材要求设计者真读过原型的一手描述（传说原文、史料），只看过二手改编的人换不出坐标，所以原文把'积累'说成设计元素的唯一来源不是鸡汤而是这条手法的前置条件。反例风险：场面化取材会牺牲一眼可读，玩家看到歌姬未必立刻读出这是那则怪火传说，需要靠命名、台词或场景把考据链接回去（本例正是靠名字完成的），链接不上就只剩一个漂亮但没有来源的角色。

- **批注**：这套法的价值是把"机会点"从灵感变成可穷举的格子：先画格子再找空位，比先有创意再找理由可信。空白格还要按验证成本分档——相邻领域或海外已有成功先例的（换装+社交在虚拟形象社交和舞蹈网游里验证过，解谜+代入在日本有可引进的成品）远比任何地方都无先例的便宜，后者等于"做第一个吃螃蟹的人"。方法自带一次漂亮的后验：报告标记的男性向占比最高的空白组合（探索/高自由+代入剧情），正是《原神》后来占住的位置。配套还有一个便宜的先验检查——新品类值不值得做，先看"潜在玩家土壤"在不在，用社区平台上目标游戏之间的关注重合度就能量出来：在位产品已经把用户驯化聚集好了，新进者才有承接对象，土壤不存在时，光有点子会死在冷启动上。反对意见：两两组合会产出大量现实中互斥或无承载方式的组合，穷举本身没有意义，必须先按占比截断；占比数据有时效，格子会被时间填满，迁到新市场必须重新采集，不能照抄结论。与 kl-058（拆解—重组—加规则）分工：那张在规则层重组玩法、产出机制创意，这张在需求层配对人群、产出品类空位。与 ur-010（时光机推演窗口期）互补：那张判断"什么时候进场"，这张判断"进哪个格子"。

- **论点**：联机≠社交：二次元产品里的联机/组队功能大多只是无需配合的并行刷素材（队友体验与AI队友无异）或伤害叠加式的数值合作，战斗内核仍是单人向的，并不满足社交需求；配套的 Kano 调研也显示，核心二次元玩家要的并不是组队玩法本身——对组队他们只是「并不排斥」，真正倾向的是和平的聊天氛围（表情包、弹幕、少刷屏）与小型公会规模这类低压力社交形态。因此立项与机制评审时，不能用联机功能数当社交满足度的代理指标——'社交+成长变强'作为高机会点需求组合，要靠专门的社交设计去满足（和平的聊天氛围、表情包与弹幕、小型公会规模），而不是多塞几个联机副本。
- **场景**：立项 / 机制 / 用户研究
- **批注**：证据是同一份调研的两个头部动作二次元产品拆解：一家的联机被玩家自己形容为队友可有可无、多人局本质是各刷各的素材；另一家的多人战本质是伤害叠加（极少数BOSS存在轮流放减益的合作方式），玩家追求的高难RAID与团战聊天区里充斥的是贡献问责与排班抱怨——联机在场，社交缺席。跨页互证：非二次元侧的成功社交案例（舞蹈网游聊天室、虚拟形象聊天）说明社交需求要靠聊天与形象表达承载；后一页的核心二次元社交偏好（要和平聊天氛围、表情包弹幕、反感喇叭刷屏、倾向小型公会——过小社交负担重、过大淹没在人群中）给出了替代设计的方向；报告框架页也把'社交向（社交+装扮、成长变强）'列为市场空白。与 ur-060（年轻玩家的社交需求是存在式的）互补：那张讲低压社交怎么设计（压力梯度），这张讲判定口径——别把联机功能数当社交满足的代理指标。边界：适用于刷素材向/数值向联机；竞技品类里真配合本身能生产社交关系，是例外。材料基于约2020年的产品格局，具体案例会过时，但'功能在场≠需求满足'的代理指标错判结构可长期复用。此判断曾因OCR语义断裂+单页孤证被拦，经人工复核原图页与前后页后确认成立。

## card-ur-082 · 动画短片/CG 把新用户导进游戏的转化杠杆不是'……

- **论点**：动画短片/CG 把新用户导进游戏的转化杠杆不是'讲完一个好故事'，而是两个机关：一是玩法预告——片中对游戏标志性技能、武器、职业能力、变身玩法做同构展示（角色重现游戏内招牌技能时，老玩家情怀引爆、新观众产生'想亲手体验这种战斗和自由度'的冲动）；二是情绪悬念——强烈悲情（牺牲、背叛、绝境背水一战）让观众意犹未尽，产生'进游戏亲自体验故事全貌'的动力，留钩子比讲完整更能转化。配套纪律：片中被预告的玩法幻想必须与游戏实际体验同构——有悲壮战争 CG 把玩家按'无双割草'的预期导进游戏、实际不符的真实反例，错位预告转化的用户从入坑第一天就带着预期落差。
- **场景**：立项 / 叙事 / 市场定位 / 玩家动机
- **批注**：证据是座谈会里玩家自述的真实影视转游戏经历汇编（守望先锋'双龙'、最终幻想15电影、黑神话悟空演示、使命召唤6 CG 等公开作品），回溯性自述带幸存者偏差——玩家只记得打动自己的瞬间，但'玩法预告+情绪悬念'的结构在多作品间稳定复现。与 gd-055（想走进场景=当场脑内预演）分工：那张管场景素材的'想去'，这张管角色叙事素材的转化结构——一个是空间预演，一个是行为与命运预演，可作 PV 分镜的并列检查清单。职业特色是玩法预告的隐藏变量：同批概念测试里'普通职业'被判'很难想象看了动画就想玩这个游戏'，能力幻想新颖的职业（如操控灵魂）反而直接生成了解意愿——选哪个角色做破圈先锋，本质是选哪个职业幻想做预告。与 ns-048（IP 留白决定改编空间）的张力：叙事层可以留白造悬念，玩法幻想层必须清晰同构，两本账不能拿'留白'当偷懒理由。
- **出处**：《角色塑造概念测试定性报告》（（内部资料·脱敏）） · 个人知识库

## card-gd-023 · 无法建模的纯机制技能（金身类，收益被太多变量耦合……

- **论点**：无法建模的纯机制技能（金身类，收益被太多变量耦合），放弃数值建模，改用二分法定价：先定一个保证有人用的低价值下限（顺便测bug），再找一个彻底没人用的上限，然后取中值反复收敛，直到使用率和强度数据落进期望区间。
- **场景**：验证 / 难度曲线
- **批注**：这是探针思维在数值上的应用：承认模型失效，拿真实使用率当收敛信号。两个前提别漏：一、使用率要等玩家理解沉淀后才可信，新装备前两周的数据多半是噪音；二、二分法收敛的是当前环境的价值，环境一变（gd-013 的生态位真空）就要重校——所以二分法不是一次性工具，是常驻监测回路。
- **出处**：《如何做好MOBA装备数值平衡？0基础小白也能搞懂！》（（本地全文库）银河系洞察基地内容合集） · 微信公众号·银河系洞察基地 · 2024-07-23

## card-gd-027 · 使用率、胜率是现象不是解释：高使用率至少有四种成……

- **论点**：使用率、胜率是现象不是解释：高使用率至少有四种成因——数值超模、端口广（万金油接口，如小电滚木）、协同深（所处体系正热门）、环境逼迫（反制热门策略的刚需）；胜率高还可能是反向因果（手钻悖论：会买手钻的局本来就快赢了）。按表面数据动刀，最常误伤的是大量卡组赖以运转的基础接口。
- **场景**：验证 / 难度曲线
- **批注**：与 ur-007（声量不等于人数）是同构的统计素养：数据回答是什么，机制理解回答为什么，动刀前先把现象归因到结构。配套原则：同一张卡在不同构筑制度下不是同一东西（自由构筑、BP、动态构筑、三选一），跨模式套用同一平衡标准必然误判——平衡结论永远要带模式前缀。实操：削弱前先问它是终端还是接口，接口型选项的削弱冲击面远超数据显示。

## card-gd-048 · 紧挨新手区的高难度区域必须自带进入资格闸门：玩家……

- **论点**：紧挨新手区的高难度区域必须自带进入资格闸门：玩家会把地理上离得近读成现在该去，任务引导再顺手一送，新人就带着没成型的阵容闯进劝退区，挫败当场变成流失。别指望玩家自己读懂难度信号——怪物等级、持续掉血的环境压力这些信号对新手是不可读的，能靠它们主动绕路的是老玩家。闸门的可选形态：接取等级门槛、能力与装备检查、或干脆把高难区在地理上隔开（跨海、分批解锁）。
- **场景**：机制 / 验证 / 难度曲线 / 体验节奏
- **批注**：反例是原神雪山：对已经玩了一阵、阵容成型的老玩家难度合适（探索顺序跟着版本走，前面还有活动任务铺路），对刚出蒙德主线的新人却是寒冷值加高等级怪的双重碾压——而雪山就贴在蒙德边上，新人接了营地里几个任务就往上冲，官方后来补了接取等级门槛。与 gd-035 有明确张力，必须划界：那张主张软门控（怪强、资源匮乏，让玩家自己选择绕路），这条指出软门控的前提是玩家读得懂难度信号，而新手期恰恰读不懂（老玩家那句看见寒冷值就知道暂时不该来，是经验红利不是设计生效）。所以门控强度要按玩家阶段分档：新手区周边用硬闸门，成熟区交给软门控。空间隔离往往比等级门槛更体面（稻妻用海域分隔加分批解锁，物理上就够不着），代价是失去世界连续感。显性闸门（弹窗提示等级不足）还会被老玩家嫌管得宽，能藏进任务接取条件里就别做成系统提示。

## card-gd-052 · 默认镜头不是审美参数而是可测指标：用角色建模在画……

- **论点**：默认镜头不是审美参数而是可测指标：用角色建模在画面中的占比来量化，对齐同品类竞品的区间做验收。更关键的是缩放方向由战场信息负载决定、不由战斗重要性决定——敌方单位少（单挑 BOSS）就拉近换代入感，敌人体型大到会遮挡战场判断就反而拉远；杂兵战多、节奏快的产品默认视角必须比单挑向产品更远。所以这场战斗更重要因此镜头要更近，是错误推理。
- **场景**：机制 / 验证 / 信息设计 / 体验节奏
- **批注**：同一批竞品测量里两个相反方向同时成立：BOSS 战因敌方单位少、信息负载低，默认视角比杂兵战更近（刺客信条英灵殿进 BOSS 战会明显拉近）；而面对超大体型敌人时收集对象无一例外反向拉远，理由既是防止体型挡住战场判断，也顺带把敌人气势做出来——拉远同样是提升场面感的手段，这一点最容易被忽略。可辨识但不该抄的例外：为魄力把角色占比推到极高的战神式取景属于风格选择，代价是情报获取。两条配套手法：镜头跟随要留延迟，即刻跟随会让战斗视角频繁更替、观感反而下降；角色居中或居左都成立，居右不符合观看习惯。与 ur-014 同族（信息量与代入感的权衡），分工是那张管 HUD 占屏、这张管取景远近。补社区测量口径（对公开产品的可复现测量，OCR 转录，使用前建议自测复核）：角色建模画面占比多在 5%–8% 区间以内。

## card-gd-054 · 玩家对场景品质的评价本质是感知层→情绪层→解释层……

- **论点**：玩家对场景品质的评价本质是感知层→情绪层→解释层的三层信息内化：缺陷一旦低于玩家的品质基准线，内化被阻断，认知滞留在感知层，玩家会反复咀嚼缺陷并与见过的竞品比较，差评就此定型；反之，把交互视觉反馈、明确的主题诠释和氛围构图前置到画面里，等于把情绪层与解释层信息前置，玩家会进入"原谅区间"、选择性忽略同样的缺陷——"不如我见过的XX，但是我觉得很真实，很感动"。所以美术预算有限时，优先投资能掩盖缺陷的动态反馈与主题明确度，素材精度的打磨顺位靠后。
- **场景**：机制 / 验证 / 信息设计 / 玩家动机
- **批注**：适用边界：模型来自场景视频的受控对比测试（玩家只看素材不上手），实机中可操作交互对缺陷的掩盖作用只会更强，方向上保守可用。反例与限度：原谅区间不是无限的——测试中同样是穿模和贴图感，有氛围与构图中和的场景被容忍，"缺少能掩盖缺陷的内容"的场景直接被列进无法接受；纯色渲染这类强氛围手段在不同经历玩家间评价分裂，占比不宜多。与既有"沉浸感的地基是感知合理"卡形成互补而非冲突：那张卡说调性违和不可原谅，本卡说品质缺陷可被原谅——先保调性统一，再谈用氛围掩盖精度缺陷，顺序不能反。
- **出处**：《什么样的场景能激发玩家的体验欲望（场景美术品质感知研究）》（（内部资料·脱敏）） · 个人知识库 · 2021

## card-gd-058 · 游戏内创作类玩法（拍摄工具、电台直播、建造、任务……

- **论点**：游戏内创作类玩法（拍摄工具、电台直播、建造、任务与地图编辑器这类 UGC 主导玩法）的成败在首发那一刻就基本锁定，靠后续迭代救不回来：第一波来试的玩家已经包含了这个玩法的全部核心受众，他们被首发缺陷劝退后产出质量随之下滑，后来者碰到优质内容的概率变低，玩法对热度的贡献就一路衰减；而玩家根本不读更新公告，第一次尝试花掉的新鲜感和耐心也不会退还。所以首发前的验收只押一个指标——核心创作环节的自由度是否达到玩家手上已有外部工具的水平（能不能暂停续录、能不能在想要的景别里做动作、单次时长够不够用），曲库、滤镜、封面、标题这些同样会被玩家提到却不构成流失原因的功能，全部留到后续版本迭代。

## card-gd-059 · 把用脑子以弱胜强当卖点的策略/战棋产品，卖点寿命……

- **论点**：把用脑子以弱胜强当卖点的策略/战棋产品，卖点寿命不取决于策略深度，而取决于策略空间被放进哪一种内容：只放进一次性关卡（高难挑战本、剧情本）等于给策略玩家发一张限次体验券——可重复的日常本与养成本一旦全部由数值门槛把守，策略型玩家的实际寿命就等于一次性关卡的消耗时长。底层判据是心流：玩家的能力必须被持续验证，而把数值门槛精确到属性不达标必定过不去，等于把策略能力从验证清单里删掉，玩家读到的规则是只有策划允许动脑的关卡才能动脑。
- **场景**：机制 / 验证 / 核心循环 / 玩家动机
- **批注**：证据来自公开运营的战棋手游《天地劫》：它被拆解出的两大优势正是重策略轻操作与数值投放精确，但精确性反噬了卖点——伤害公式与属性投放比例可控到策划能预算出每关要求的攻防差，加上高难BOSS普遍免疫减速与控制类效果，可用策略被压缩成加攻减防这类基础属性操作。写作者本人是重度策略玩家，约三周即接近流失（n=1 自证，但机制推导独立成立，且与市面上以战中策略为主内容的产品在长线运营中逐渐转向数值验证的观察一致）。解法方向（同一材料给出）：把策略解空间搬进可重复内容——做局内养成型 roguelike 复用已有关卡资产以爬塔形式开放，把养成投放从局外搬进局内，一套关卡同时喂数值玩家和策略玩家（明日方舟是参考对象，战棋与塔防的玩法相似性够）；或把难度选择权交给玩家（自选修饰词条的合约式难度），用组合数换内容量。张力：与 gd-029（数值投放和挑战难度是同一条曲线的两面）方向相反——那张要求敌人强度锚定构筑基准，这张警告锚得太精确会掐死策略验证；与 gd-019（减法伤害公式适配高付费MMO）互证代价面：公式带来的精确投放能力，同时也是付费墙的施工工具。与 ur-028（卖策略空间而非数值深度）互补：那张说策略空间更好卖，这张说不卖也得留，否则核心受众三周走光。反对意见要认账：数值门槛是长线付费的现金流基础，本卡不是主张取消门槛，而是主张给策略留一条绕过门槛的窄路——窄到什么程度不伤付费，材料没有给出答案。
- **出处**：《天地劫产品拆解》（（内部资料·脱敏）） · 个人知识库

## card-gd-061 · 凡把算得清当核心乐趣的玩法（战棋、回合制、卡牌、……

- **论点**：凡把算得清当核心乐趣的玩法（战棋、回合制、卡牌、塔防），战前信息的可预演性是玩法地基而不是 UI 优化项。硬验收标准只有一条：玩家能否在不实际执行的前提下，算出这次行动的结果与代价。三项最常漏——预估必须等于实际结算，战前显示的伤害与剩余血量跟真实结算不符，玩家就不再信任任何数字；代价必须完整披露，敌方反击与被动触发的伤害也要进预估，否则所谓最优解是被隐藏信息坑出来的；威胁范围必须低成本可读，只标普攻距离、技能射程要玩家逐个单位点开逐个技能去查，计算成本就会高过收益。任一项缺失，玩家的最优解从计算退化成用数值碾过去，策略设计的全部投入被信息层清零。
- **场景**：机制 / 验证 / 信息设计 / 核心循环
- **批注**：案例是《天地劫》借鉴《火焰纹章 风花雪月》的战棋战斗——框架抄到了，信息层没抄到：伤害预估与实际结算存在可见偏差、敌方反击伤害战前不显示、安全地块与危险地块难以辨别，面板只给普攻范围而技能射程需玩家自行点开计算。材料的结论很直白：算不动就不算了，直接靠数值碾过去。这对策略产品是自杀路径，因为它把付费数值变成唯一可行的通关手段，反过来又给数值墙加了一层合法性（与本批策略卖点寿命那张卡互为因果）。验收动作很便宜：让测试者在不点执行的情况下口述本次行动的结果与代价，口述与实际不符之处就是信息层缺陷清单，可直接排进迭代。与 ur-014（HUD 信息密度由操作负担决定）需要区分口径：那张的操作负担指执行频率与操作难度，适用于动作类；回合制的负担不在执行而在预演，所以标准不是信息密度而是可计算性——信息可以很少，但必须准、全、便宜可得。与 gd-037（玩家反复误用时先怀疑可供性而非玩家理解力）同族，本卡给出策略品类的具体判据。边界必须写清：PVP 与刻意保留隐藏信息的博弈（战争迷雾、暗牌、心理战）里算不清是设计意图，此时该验收的不是信息完备性，而是不确定性的可读性——玩家至少要能知道自己正在赌什么、赌注多大。

## card-kl-066 · 联动价值是乘法不是加法：一个备选 IP 值不值得……

## card-ns-061 · 美术做场景的顺序和玩家读场景的顺序是反的：美术从……

- **论点**：美术做场景的顺序和玩家读场景的顺序是反的：美术从解释层出发——策划给功能和剧情需求，定下整体风格与想给玩家的感受，最后才落到具体元素；玩家从感知层进入——先看到元素，再产生情绪，最后才用既往经验解释这是什么地方、发生过什么。所以美术在自己意图最清楚的那一层做自检，必然高估'玩家读到了我的意图'。要让解释层真的被读到，只能在感知层先立一个一眼能抓住的视觉核心；而且要记住花了最多钱的那个模型不会自动成为视觉核心，得靠摆放位置、出场顺序和周边元素的压制把它做成核心，并且用眼动或访谈单独验证一次。

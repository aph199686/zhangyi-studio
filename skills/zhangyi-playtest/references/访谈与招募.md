# 访谈与招募（深访工序 + 招募漏斗）

> 素材来源：能力单元 01（深度访谈规程）、02（玩家招募与样本甄别）。
> 标注"张翼推断"的条目是面向独游的降级建议，不是原材料内容。

## 深访之前：先判定问题性质

- [ ] 要回答"是什么 / 多少"→ 走定量；要回答"为什么"→ 走定性（深访）。
- [ ] 复杂问题定性×定量结合：定性为定量找维度，定量为定性测程度。
  单一方法不够用时，在设计里写明两种方法各自回答哪一半问题。

## 找对人：2W3H 拆解

- [ ] **Who** 找谁：能成为典型画像的代表性用户，不是随手抓到的人。
- [ ] **Why** 为什么找：这条必须能接到测试目标上，接不上就是旅游。
- [ ] **Where / How / How many** 在哪找、怎么找、找多少：
  线上去有流量的地方——社区论坛、玩家群、社交媒体、内容平台评论区、
  应用商店评论；线上打捞后预约深谈。
- [ ] 接触姿态：自然包装身份、融入对方语境，不以"官方调研"姿态压人。

## 访谈提纲（必须写，不许裸聊）

写提纲的四个理由，贴在提纲首页：防遗漏关注点 / 减轻临场压力 /
多人执行口径一致 / 保证质量下限。

原则：尽量不设选择题；问题从开放到逐步收紧；组织好顺序与时间分配。

六类错误自查（写完逐条过）：

1. [ ] 术语对玩家太专业——"流失原因"这种行话要换成玩家语言。
2. [ ] 顺序不合经历时间线——先问离开的原因，再问回来的情境，别倒着问。
3. [ ] 问题过于封闭——能答"是/否"就完的问题挖不出东西。
4. [ ] 比较类问题没指明具体游戏——"比之前玩的好吗"必须点名是哪款。
5. [ ] 相近问题顺序诱导——先问"希望改什么"再问"为什么回来"，答案会串味。
6. [ ] 漏了人口学信息——年龄、职业等基本字段必须留位。

## 执行与控场

技巧三件事：

- [ ] 回应玩家：让其愿意说下去。
- [ ] 控制顺序：不被带跑，也不硬拽回提纲。
- [ ] 善于倾听：听比问重要。

雷区（原材料标注"雷区"但清单细节散失，以下三条为上下文可确认部分，
**完整清单待补**）：

- [ ] 不诱导式提问。
- [ ] 不连续追问令人生畏。
- [ ] 不替玩家总结他没说过的意思——把话塞进对方嘴里是最隐蔽的造假。

## 内容加工：故事化，不记观点记场景

- [ ] 用故事丰富访谈记录：还原玩家的具体行为场景，而不是只记观点结论。
- [ ] 输出分三层标注：**玩家说的原话 / 观察到的行为 / 研究员的推断**。
  三层混写 = 把自己的猜测穿上玩家的外衣，触天条。

## 招募漏斗（所有真人测试的前置闸门）

```
需求定义 → 报名初筛 → 投放招募 → 回收初筛 → 查重与甄别 → 测前邀约
```

### 1. 定义招募需求

- [ ] 游戏经历要求写到最细：玩过什么品类、什么深度、什么付费档位。
- [ ] 明确本次要哪类样本：常规玩家 / 特殊玩家（领域 KOL、高付费、
  内容创作者、轻度玩家、行业专家）。研究问题决定人群——
  传播潜力找 KOL，付费研究找高付费，世界观剧情研究找深度内容消费者。

### 2. 报名初筛问卷

- [ ] 必含字段：可测试时间、地点/方式、基本要求、游戏经历、联系方式、
  人口学信息、隐私说明。
- 注意：问卷**设计方法**本身是素材盲区（题目编写原则、量表、清洗规则
  均无依据），此处只有字段清单，别在这里展开方法论。

### 3. 投放招募

- [ ] 泛用户走大众社区 / 社交平台 / 玩家群；定向人群走定向邀约与邮件。
- [ ] 文案红线：不暴露自己产品的关键未公开信息；写清隐私政策。
- [ ] 海外合规红线：跨境数据不直接导出、不绕过合规路径直接接触海外玩家
  （独游可行的海外低成本路径原材料缺失，**待补**，不要现编）。

### 4. 回收与初筛

- [ ] 围绕"玩家类型 × 游戏经历"两个轴筛。
- [ ] 报名量不足时电话/私信甄别补量。

### 5. 查重与甄别（样本污染的硬闸门）

- [ ] 查重：重复参测冷却期一般三个月。
- [ ] 甄别四维度：人口学 / 游戏经历 / 表达能力 / 基本素养；
  对不同回应预备不同话术。
- [ ] 甄别标准三级：能用（关键问题先行筛掉硬不符）→ 好用（辅助信息判断）
  → 易用（综合过程判断）。

### 6. 测前邀约

- [ ] 电话/短信/私信多通道确认时间地点与注意事项。
- [ ] 正式测试准备保密协议（NDA）环节。

## 独游降级注记（张翼推断，非原材料）

- 没有招募渠道预算时：本地玩家群、同好社区、展会/校园/社区聚会拦访、
  线上随机邀约都可作样本池；但**朋友局不算外部样本**——朋友给的是
  面子不是反应，只能在报告里标注为"便利样本"并降级结论效力。
- 样本量等比缩小可行，缩了就必须在报告里标注置信度下降，
  不许拿 8 个人的结论装 30 个人的口径。
- "外包执行""邮件投放""电话甄别补量"对独游大多不成立，
  降级为私信/社群直接触达，但查重冷却期和甄别四维度**不许降级**——
  那是结论可信度的底线，不是资源问题。

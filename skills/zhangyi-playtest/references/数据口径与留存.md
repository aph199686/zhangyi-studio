# 数据口径与留存（口径陷阱 + 分段归因 + 流失三板斧）

> 素材来源：能力单元 06（数据指标与留存流失分析）。
> 标注"张翼推断"的条目是独游降级建议。

铁序：**先统一口径再谈分析。** 数据说玩家走了但没人知道为什么、
访谈说了一肚子理由但无法验证——双向断链都是跳过口径直接归因造成的。

## 口径陷阱自查（看到任何数字先过这一节）

- [ ] 基础指标：新增、留存（登录比）、回流；记住**一般讲的留存率
  都是新增的留存率**。
- [ ] 留存率分母会被刷量干扰：异常新增摊薄分母。可用"有效用户"门槛
  （如登录两天以上）优化分母。
- [ ] 在线时长参考意义有限，不做核心论据。
- [ ] 商业化口径：NPS = 推荐者比例（9–10 分）− 贬损者比例（0–6 分）；
  LTV = LTA × ARPU；回本率 = LTV / CPI（CPI = 单个导量成本）。
  回本率低于 1，买量即亏损。
- [ ] 没有现成关键指标时自己构建指标。分析链路：
  拆解问题 → 保证数据质量 → 多角度对比 → 汇聚证据下结论。

## 留存分段归因（先看曲线形态再开方）

不同段的流失是不同的病，吃不同的药：

| 段落 | 先查什么 |
|---|---|
| 次留不好 | 品质、前期上手、核心体验与玩家预期是否匹配 |
| 三留不好 | 内容丰富度、短期目标是否建立 |
| 7 留及之后不好 | 耐玩性：持续新鲜内容或有效成长预期是否成立 |

- [ ] 对照留存曲线典型模式（细分长流式 / 一波流式 / 长耐玩模式）
  判断产品处于哪种健康形态——别拿一波流的曲线要求长耐玩的指标。

## 流失定位三板斧（按序使用，互补短板）

1. **数据漏斗**：用等级通过率 / 时间通过率 / 任务通过率找流失节点
   （任务通过率最常用）。
   短板要写明：只能定位"在哪流失"，定位不了原因。
2. **定量访谈**：对流失玩家做访谈并定量统计，区分**广泛性问题**
   （多数人表达不满）与**深度问题**（最核心的流失原因）——
   两者常不一致，都要报。
   短板要写明：存在委托方不信任用户主观反馈的情况。
3. **数据假设**：先用定性摸清流失原因，再把每个原因翻译成可计算的
   数据口径回验。示例口径（翻译的格式，照这个格式写你自己的）：
   - "性能流失" → 曾遇到极低帧率且未开启下一局；
   - "强引导流失" → 停留在强制引导界面且点击了引导以外区域后流失；
   - "初印象流失" → 首局未完成即流失且无性能问题。
   产出物是一张"一级原因 → 二级原因 → 计算方式"对照表。

## 耐玩性诊断（长线留存专项）

- [ ] 耐玩性 = 内容新鲜 + 持续成长。成长出口可以是数值积累、收集、
  技巧，也可以是非数值出口（装扮、成就、社交地位）。
- [ ] 两大典型困境：目标数值太易填满（有限数值 vs 无限追求）；
  目标验证形式单一（有限成就感模式 vs 无限新鲜感需求）。
- [ ] 对症手段库：开新坑/新系统、周期性等级阶段、赛季制重置、
  非数值收集与装扮线——每个手段标注消耗速度风险：
  新游戏内容最难做但消耗最快，开新系统需谨慎评估。

## 证据汇聚与报告纪律

- [ ] 每个结论标注：口径怎么算、样本从哪来、是漏斗现象还是玩家自述
  还是回验结果。
- [ ] 定性结论必须尝试定量回验后，才升级为问题清单条目。
  回验不了的就留在"假设"层，不许偷渡。

## 独游降级注记（张翼推断，非原材料）

- 无埋点/无数据平台时，漏斗退化为"关键节点人工统计 + 访谈为主"，
  必须在报告标注口径来源是人工统计。
- 三板斧顺序不变，但第三板斧的"数据回验"在小样本下精度天然不足
  （分母小的二项指标区间很宽）——回验不过先怀疑样本量，
  别急着否定定性结论，也别急着肯定它。
- 没有竞品留存数据可对照时，曲线形态判断以自己的版本间纵向对比为主，
  横向对标只引用公开来源，并在口径里注明。

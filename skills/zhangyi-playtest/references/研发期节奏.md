# 研发期节奏（五站路由 + 运营期跟进）

> 素材来源：能力单元 07（研发期分阶段用研节奏）、08（运营期用研跟进）。
> 标注"张翼推断"的条目是独游降级建议。

研究动作必须绑在研发的生死节点上。动作与节点错配是最典型的浪费——
Demo 期测耐玩、封测期才想起来验证目标玩家，都是这条纪律的反面教材。

## 总图：五站路由

```
立项前：验"谁买单"
  → Demo 期：尖叫度——核心体验超预期的瞬间存不存在
  → 研发中期：保上手与品质
  → 封测期：铁序校验——留存 > 优势市场 > 付费 > 导量
  → 运营期：新增/流失/回流三线跟进
```

- [ ] 每站结束都问：本期结论是否触发了回退（回 Demo 重验方向 /
  回开发期改体验）。研发用研是回环，不是单行道。

## 第一站 · 立项前：验"谁买单"

- [ ] 先判市场位置：按市场增长 × 市场份额四象限（攻坚入局 / 快速攻占 /
  主力营收 / 小而美）明确打法假设。
- [ ] 分两种情形切入：产品无明确思路 → 研究"该品类用户如何切入、
  还有哪些机会点"；产品有明确思路 → 验证"你的思路谁买单、
  在市场上是否可行"。
- [ ] 目标玩家描述用"投入 × 体验"模型：玩家可接受的投入
  （环境条件：时间/设备/消费能力；能力要求：反应/记忆/操作）
  + 看重的核心体验（吸引因素：画风题材玩法；
  沉浸因素：社交/收集/代入/竞技）。游戏选择理由 = 画风 + 题材 + 核心乐趣。
- [ ] 两条铁律防自嗨：不以单一维度量度成败；不以个人眼光揣测群体——
  "我自己就是目标玩家"不是论据。
- [ ] 人群规模初判：用乐趣标签组合的偏好/排斥调研估算各标签组合的
  人群盘子，识别互斥组合（某画风偏好 × 某强对抗玩法偏好互斥的组合
  是雷区）。
- [ ] 产出：目标玩家适配度与规模评估、市场竞品与设计点、方向建议。

## 第二站 · Demo 期：尖叫度

- [ ] 尖叫度测试（规程见 `测试与对齐.md`）：核心玩家第一小时会不会尖叫。
- [ ] 必做清单：尖叫度测试、竞品与市场状况调研、目标玩家验证
  （已有定义则验证适配度与规模；无定义则提供选择方案并评估）、
  画风题材研究、潜在玩家边界探索、产品亮点吸引力评估。
- [ ] 产出：尖叫度报告 + 方向建议。低分回核心体验设计，不急着加内容。

## 第三站 · 研发中期：保上手与品质

- [ ] **难题 1 · 上手**：可用性测试 + 上手分析，检验玩家"会不会、懂不懂、
  行不行"；新手引导按 `测试与对齐.md` 的引导自查清单过一遍；
  关注引导三层次：操作教学、信息教学、目标赋予（乐趣引导）。
- [ ] **难题 2 · 品质**："基础体验不够好"时按固定链路上推——
  整理玩家舆论反馈 → 总结可能问题 → 把定性问题变成定量问题
  （问卷量化影响面）→ 归因到具体设计要素 → 添加竞品对比佐证。
  （素材范例：大量玩家反馈眼部不适 → 问卷量化 → 归因到亮度切换幅度、
  视角过近转动频繁、可交互物与背景对比度低三类设计要素。）
- [ ] **难题 3 · 设计争议**：不做裁判做分析——针对目标玩家定量分析利弊；
  不同人群利弊不同就分人群呈现，把取舍交还给产品决策。
- [ ] 必做清单：新手体验保障、基础体验保障、里程碑评估验收
  （画风/品质感/玩法/耐玩性）、高价值玩家深测。
- [ ] 产出：上手门槛评价、可用性问题清单、用研小结、
  长期留存手段的替代建议。

## 第四站 · 封测期：铁序校验

**留存 > 优势市场 > 付费 > 导量。顺序不许乱。**

- [ ] **留存**：按 `数据口径与留存.md` 的分段归因与流失三板斧执行。
- [ ] **优势市场**：用"题材+玩法在各地的覆盖率 × 当地玩家规模"预估
  各地潜力人群；同步做本地化适配跑查——隐私条款、机型匹配、
  下载与付费习惯、支付与社交接入渠道、推荐位文案本地化、
  当地氪金法规、翻译质量、敏感要素与文化反感点。
- [ ] **付费**：画消费体系图（消费类型 × 内容关联是否成体系）；
  跟进竞品付费推动形式；监控付费可持续性（各付费层级占活跃比例的
  周变化）；评付费体验（随机挫败是否有兜底、需要时能否买到需要的、
  过期商品是否及时更新、对不同付费档位是否协调、对低付费玩家是否
  隐藏付费深度）；监控付费口碑六因素——付费自由度、影响范围、
  影响程度、回报率、开发者姿态、历史付费经历。
- [ ] **导量**：分自吸量（画风题材/玩法类型/图标/名字/简介/口碑 NPS）
  与买量（渠道选择/用户选择/营销素材/卖点文案）两侧诊断；
  用回本率（LTV/CPI）判断买量是否可持续；用来源问卷定位用户从哪来、
  为什么进来。
- [ ] 产出：留存分析报告、付费对标与优化建议、口碑舆情监控结论、
  传播能力评估。

## 第五站 · 运营期：三线跟进（框架级，细节待补）

> **诚实声明**：原材料运营期部分渲染缺页，本节是框架级内容——
> 三条跟进线与口径纪律可信，但版本排期与系统级优化的操作细节
> 缺失在案，执行时需用真实项目回填，不许照着框架编细节。

- [ ] 心智校准：研发期用研验证方向与品质；运营期用研服务三个目标——
  玩家量（新增）、延长生命周期（留存/回流）、付费增长。
  警示性问题常备：买量越多会不会反而越亏？（回本率低于 1 即亏损。）
- [ ] **新增线**：监控新增来源与质量；新玩家上手与首日体验问题跟进
  （走查 + 漏斗，见前两份 references）。
- [ ] **流失线**：周期性流失归因（三板斧）；新增流失原因登记进问题清单
  并跟踪迭代。
- [ ] **回流线**：研究回流情境与动机——玩家为什么回来、回来的体验
  是否接得住；回流活动的体验评估。
- [ ] 版本节奏：每个版本/活动节点前评估更新内容的目标匹配度
  （服务拉新、留存还是付费）；节点后数据验证 + 舆情监控 +
  问题清单跟进。
- [ ] 固定产出：周期性留存/流失/回流小结、版本效果验证报告、
  付费体验与口碑监控记录。所有结论标注样本与口径，
  与历史周期同口径对比。

## 独游裁剪建议（张翼推断，非原材料）

- 资源不够全做时：Demo 期保留尖叫度 + 竞品调研；封测期保留留存 +
  付费口碑；其余砍掉并在裁决书诚实声明里写明没做。
- "优势市场"对单语言独游可整节豁免，但要在声明里写豁免理由，
  不许默默跳过。
- 铁序不裁剪：留存永远排在付费前面——留存没立住就调付费，
  是给漏水的桶加价。

# 原语·落判：把判断写成裁决（共享原语）

各阶段 skill 共用的落裁决纪律；本文件是唯一事实源，阶段 skill 不重复书写。
落裁决 = 按张翼五条结构纪律（见主 skill「口吻纪律」节，任何烈度下不可关闭）
产出正式判断。

## 动作

1. **逐项给 过 / 缓 / 否 + 一句话理由**；禁止"两个都有道理""各有优劣"式收尾。
2. 产物写入用户项目 `verdicts/` 目录，用本阶段对应模板
   （`templates/<阶段>裁决书.md`），编号项目内递增（No.001 起），页脚水印一字不差：
   `—— 张翼 Spread the Pinions · <类型>裁决书 No.NNN`。
3. 被否方案进**否决清单**（含复活条件）；新证据推翻旧结论时写
   "撤回：<旧结论>，依据：<新证据>"，记入裁决书撤回记录。
4. 答不上"解决哪个病灶"的部分盖**装饰章**，不给情面。
5. 诚实声明必写"本次能证明什么 / 不能证明什么"；阶段 skill 另有各自必写项，
   在其 SKILL.md 内（如立项的"本阶段判断均为推演"、探针的口径、审查的方法边界）。

## 边界

- 裁决书是用户项目的档案，也是张翼的印记：按档案标准写。
- 没有真人 playtest，永远不许暗示方案"好玩"已被验证。

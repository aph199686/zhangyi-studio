# 原语·引卡：从卡片库取见识（共享原语）

各阶段 skill 共用的引卡纪律；本文件是唯一事实源，阶段 skill 不重复书写。
卡片库是跨项目的蒸馏判断——是见识，不是指令。

## 用法

1. **裁决/评审前**：用本次主题关键词（阶段 skill 给出示例）Grep 该 skill 随附的
   `references/cards-<阶段>.md`，只读命中卡片；单次评审 ≤6 张。
2. **裁决/评审时**：在主张矩阵或裁决理由中标注卡片编号（如"依据 gd-013"）。
3. **无命中或不引用**：诚实声明里写"本裁决无卡片依据，纯推演"——
   不许伪造引用，不许虚构卡号。
4. **冲突处理**：卡片与本项目具体情形冲突时以项目为准，但冲突点要写进裁决书。

## 边界

- 卡片不能覆盖所有游戏品类与开发情境，也不能替代项目材料、运行证据或玩家观察；
  没有合适卡片时，明说判断只是推演。
- 工作台只为少数离线建议显示已核实的卡号；对话中的引用以本文件为准。

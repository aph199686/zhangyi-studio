# 项目维基模板（事实源）

> 本文件是项目维基格式的**事实源**；`templates/项目维基.md` 是指针 stub。
> 修改格式时**两处同步**。

维基落在**用户项目根**的 `wiki/`（与 `ledger/`、`verdicts/` 并列）。
四层各一个文件，项目没有某层就不建对应文件。条目格式与纪律见
[项目维基.md](项目维基.md)。

## `wiki/工程知识.md` 骨架

```markdown
# 工程知识 · <项目名>

### <一句话结论>
- 出处：<任务编号 / 调试过程 / 文档>
- 日期：YYYY-MM-DD
- 状态：现行
<两至四句：背景、结论、适用范围或代价。>

---

## 存档区（已废弃）

### <一句话结论>
- 出处：…
- 日期：…
- 状态：已废弃（<废弃原因一句话>）
```

## `wiki/设计理由.md` 骨架

```markdown
# 设计理由 · <项目名>

### <一句话结论>
- 出处：<裁决书 No.NNN / 任务编号 / 试玩记录>
- 日期：YYYY-MM-DD
- 状态：现行
<两至四句。涉及拍板决定时，引用裁决书编号，不复制正文。>
```

## `wiki/世界与内容.md` 骨架

```markdown
# 世界与内容 · <项目名>

### <一句话结论>
- 出处：<设定文档 / 任务编号>
- 日期：YYYY-MM-DD
- 状态：现行
<两至四句。>
```

## `wiki/验证证据.md` 骨架

```markdown
# 验证证据 · <项目名>

### <一句话结论>
- 出处：<试飞批次 / 探针编号 / 运行核验>
- 日期：YYYY-MM-DD
- 状态：现行
<两至四句：样本、口径、结论；不伪造玩家声音。>
```
